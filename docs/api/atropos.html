atropos

Atropos — a hypothesis-killing framework for quantitative research.

Atropos is the Fate who cuts the thread of life: every candidate hypothesis enters the pipeline alive and leaves it with exactly one verdict — SURVIVED, KILLED, or INCONCLUSIVE. The package bundles the tools that do the cutting: preregistration, null controls, incremental regression, robustness batteries, walk-forward evaluation, Monte Carlo risk envelopes, and ensemble pipelines that chain every stage in adversarial order.

The two front-door functions are re-exported at the package level::

from atropos import generate_prereg, run_full_pipeline

The ML kill chain and the unified wrapper are module-level entry points (no package re-exports):: from atropos.ml_training import run_ml_kill_protocol; from atropos.kill_chain import run_full_kill_chain. Importing atropos.ml_ensemble has a documented side effect: it registers the composite "ensemble" model in MODEL_REGISTRY and seeds its DEFAULT_TRAINING_CONFIG["model_params"] entry.

Every module is also importable directly, e.g.::

Run python -m atropos.<module> for the synthetic demo bundled with each module (for example python -m atropos.ensemble_pipeline).

 969    ----------
 970    data : dict with ``returns`` (per-period forward returns), ``signal``

 987    ``config`` is a JSON-serializable copy: a callable ``model`` shows up
 988    as ``"<callable>"`` while the pipeline itself runs the real factory.
 989    """

 992    al, n_obs = _align_inputs(data)

 995    has_panel = al["panel_signal"] is not None

1002                _stage_by_id(stages, 1).get("repackaging")
1003            )
1004            cost_kill = killed_stage == 5 and bool(
1005                _stage_by_id(stages, 5).get("results", {}).get("cost_breach")
1006            )
1007            if repack:
1008                verdict = "REPACKAGING"
1009                reason = (
1010                    "the new signal adds nothing beyond known momentum / "
1011                    "known features"
1012                )
1013            elif cost_kill:
1014                verdict = "COST_DEATH"
1015                reason = _COST_DEATH_REASON
1016            else:
1017                verdict = _KILL_VERDICTS[killed_stage]
1018                reason = _KILL_REASONS[killed_stage]
1019        else:
1020            has_warn = any(stage["status"] == "WARN" for stage in stages)
1021            verdict = "SURVIVES_WITH_WARNINGS" if has_warn else "SURVIVES"
1022            reason = None
1023        # context-dependent skip summary: after a kill the remaining
1024        # stages are moot; a survivor simply lacked panel data for the
1025        # optional stage 7
1026        skip_summary = (
1027            "not run: candidate killed earlier"
1028            if killed_stage is not None
1029            else "not run: optional stage (no panel data)"
1030        )

1032        stages.extend(
1033            {
1034                "stage": skipped,

1038                "results": {},
1039            }

1041        )

1044            if al["returns"] is not None

1046        )

1049            "n_obs": n_obs,
1050            "date_range": (str(index.min()), str(index.max())),
1051            "overall_verdict": verdict,
1052            "killed_by_stage": killed_stage,
1053            "kill_reason": reason,
1054            "stages": stages,

1063                "name": _STAGE_NAMES[skipped],
