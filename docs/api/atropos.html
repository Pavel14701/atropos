atropos

Atropos — a hypothesis-killing framework for quantitative research.

Atropos is the Fate who cuts the thread of life: every candidate hypothesis enters the pipeline alive and leaves it with exactly one verdict — SURVIVED, KILLED, or INCONCLUSIVE. The package bundles the tools that do the cutting: preregistration, null controls, incremental regression, robustness batteries, walk-forward evaluation, Monte Carlo risk envelopes, and ensemble pipelines that chain every stage in adversarial order.

The two front-door functions are re-exported at the package level::

from atropos import generate_prereg, run_full_pipeline

The unified kill chain (run_full_kill_chain) joins them at the package level, together with the curated backtest golden path: simulate → rank → normalize → admission → metrics. The lambdarank oracle lives in atropos.ranking and needs the optional [ranking] extra. The unified ML protocol stays module-level (from atropos.ml_training import run_ml_kill_protocol). Importing atropos.ml_ensemble has a documented side effect: it registers the composite "ensemble" model in MODEL_REGISTRY and seeds its DEFAULT_TRAINING_CONFIG["model_params"] entry.

Import cost: the re-exports above pull in atropos.ml_ensemble transitively, so import atropos — and any atropos.* submodule import, which executes the package __init__ first — also loads the scikit-learn stack (~1.7 s on a cold interpreter) and performs that registration. There is currently no lighter import path for the public front doors.

Every module is also importable directly. Run python -m atropos.<module> for the synthetic demo bundled with each module (for example python -m atropos.ensemble_pipeline).

1272
