atropos.strategy

Strategy-level composition: legs + portfolio policy, one shape.

A strategy is tuple[LegSpec, ...] + PortfolioPolicy -- ONE abstraction so momentum, pairs and multi-leg options are the same object for feature analysis. An iron condor is 4 legs + an independent policy + caps; a pairs trade is 2 legs (independent or netting); a momentum system is 1 leg. The object shape does not change with the leg count, so every strategy's trades flatten into the same analysis-ready frame (records_to_features(), the bridge from "what the strategy did" to "what Atropos analyzes").

Anti-patterns this module forbids:

  • strategy-as-backtest -- a StrategySpec is a pure DECLARATION; the Book (atropos.book) is the only simulator. Positions, cooldowns, concurrency and costs live there, never here.
  • multi-leg-as-special-case -- composition is homogeneous: independent legs run one fresh Book each (run_book) so they cannot interact; the shared families delegate to the Book's own portfolio walk (Book.walk_portfolio). This module adds policy and diagnostics, never a second simulator.

Composition paths: "independent" isolates the legs; "netting" / "sequential" / "priority" share ONE position pool and equity ledger inside a single walk (sequential and priority have NO offsetting -- opposites coexist; netting is its own combination). Exposure ENFORCEMENT (the caps are diagnostics, not admission control) and universe enforcement (survivorship filters, calendar gating) are deferred (KNOWN-ISSUES section 14).

  81@dataclass(frozen=True)
  82class PortfolioPolicy:
  83    """How a strategy's legs share one book.
  84
  85    ``combination="independent"`` runs each leg in a FRESH Book
  86    (:func:`atropos.book.run_book`) so legs cannot interact:
  87    positions from different legs COEXIST -- a long-X and a short-X
  88    leg both hold at the same time and each accrues its own PnL
  89    (this is NOT netting: no offsetting, no margin netting, no
  90    position merging).  ``combination="sequential"`` /
  91    ``"priority"`` / ``"netting"`` delegate to the ONE shared-state
  92    walk (:meth:`atropos.book.Book.walk_portfolio`): a single
  93    position pool and equity ledger -- sequential and priority have
  94    NO offsetting (opposites coexist), netting closes opposite
  95    intents.  The caps are validated here but only REPORTED as
  96    diagnostics by :func:`run_strategy` -- enforcement is deferred.
  97
  98    Args:
  99        borrow_bps_annual: REQUIRED annual short-borrow rate in bps;
 100            ``>= 0`` (a cost, never a credit).  ``0`` is allowed --
 101            it disables short-cost modeling and the Book warns.
 102        funding_bps_annual: REQUIRED annual funding rate in bps;
 103            ANY finite float is legal (sign-carried: ``> 0`` means
 104            longs pay, ``< 0`` means shorts pay).
 105        periods_override: optional explicit bars-per-year for the
 106            carry accrual; ``None`` derives from the bundle's
 107            calendar (checkpoint W3-1).
 108        combination: how legs combine -- ``"independent"`` (fresh
 109            Book per leg), ``"sequential"`` (shared walk, entry
 110            competition in declaration order), ``"priority"``
 111            (shared walk, highest ``LegSpec.priority`` first) or
 112            ``"netting"`` (shared walk; an entry intent opposite in
 113            direction to an open position on the same instrument
 114            closes it and is itself consumed).  Unknown values
 115            raise ``ValueError`` (the runtime check exists so
 116            dynamic callers die loudly too).
 117        max_concurrent_positions: soft cap on simultaneous open
 118            positions; must be >= 1.  Exceeding it is reported as a
 119            diagnostic note, never enforced in the MVP.
 120        max_gross_exposure: soft cap on gross open exposure in R
 121            units; must be finite > 0.  Not enforced in the MVP.
 122        max_net_exposure: soft cap on net open exposure in R units;
 123            must be finite > 0.  Not enforced in the MVP.
 124
 125    Raises:
 126        ValueError: on an unknown ``combination``, a
 127            ``max_concurrent_positions`` below 1, or a non-finite /
 128            non-positive exposure cap.
 129
 130    Example::
 131
 132        >>> policy = PortfolioPolicy(
 133        ...     borrow_bps_annual=500.0, funding_bps_annual=100.0
 134        ... )
 135        >>> (policy.combination, policy.max_concurrent_positions,
 136        ...  policy.max_gross_exposure, policy.max_net_exposure)
 137        ('independent', 10, 2.0, 1.0)
 138        >>> netted = PortfolioPolicy(
 139        ...     borrow_bps_annual=500.0,
 140        ...     funding_bps_annual=100.0,
 141        ...     combination="netting",
 142        ... )
 143        >>> netted.combination
 144        'netting'
 145        >>> try:
 146        ...     PortfolioPolicy(
 147        ...         borrow_bps_annual=500.0,
 148        ...         funding_bps_annual=100.0,
 149        ...         combination="random",
 150        ...     )
 151        ... except ValueError as error:
 152        ...     "combination must be one of" in str(error)
 153        True
 154    """
 155
 156    borrow_bps_annual: float
 157    funding_bps_annual: float
 158    periods_override: float | None = None
 159    combination: str = "independent"
 160    max_concurrent_positions: int = 10
 161    max_gross_exposure: float = 2.0
 162    max_net_exposure: float = 1.0
 163
 164    def __post_init__(self) -> None:
 165        """Reject unknown combinations and validate the soft caps."""
 166        validate_number("borrow_bps_annual", self.borrow_bps_annual)
 167        if self.borrow_bps_annual < 0.0:
 168            raise ValueError(
 169                "borrow_bps_annual must be >= 0 (a short-borrow cost),"
 170                f" got {self.borrow_bps_annual!r}"
 171            )
 172        validate_number("funding_bps_annual", self.funding_bps_annual)
 173        if self.periods_override is not None and not (
 174            np.isfinite(self.periods_override) and self.periods_override > 0.0
 175        ):
 176            raise ValueError(
 177                "periods_override must be a positive finite float when"
 178                f" given, got {self.periods_override!r}"
 179            )
 180        if self.combination not in _VALID_COMBINATIONS:
 181            valid = ", ".join(repr(name) for name in _VALID_COMBINATIONS)
 182            raise ValueError(
 183                "PortfolioPolicy: combination must be one of"
 184                f" {valid}, got {self.combination!r}"
 185            )
 186        validate_int(
 187            "PortfolioPolicy.max_concurrent_positions",
 188            self.max_concurrent_positions,
 189            minimum=1,
 190        )
 191        gross = validate_number(
 192            "PortfolioPolicy.max_gross_exposure", self.max_gross_exposure
 193        )
 194        if gross <= 0.0:
 195            raise ValueError(
 196                "PortfolioPolicy.max_gross_exposure must be finite > 0,"
 197                f" got {gross}"
 198            )
 199        net = validate_number(
 200            "PortfolioPolicy.max_net_exposure", self.max_net_exposure
 201        )
 202        if net <= 0.0:
 203            raise ValueError(
 204                "PortfolioPolicy.max_net_exposure must be finite > 0,"
 205                f" got {net}"
 206            )

 209@dataclass(frozen=True)
 210class UniverseSpec:
 211    """Declared trading universe (MVP: informational metadata only).
 212
 213    Validated and echoed into the strategy summary so runs are
 214    self-describing.  ENFORCEMENT is deferred: no survivorship
 215    filters, no calendar gating, no entity resolution -- the symbols
 216    and the calendar name do NOT restrict what a run trades
 217    (KNOWN-ISSUES section 14).
 218
 219    Args:
 220        symbols: non-empty tuple of unique, non-empty symbol strs.
 221        calendar: session-calendar name (informational label only).
 222
 223    Raises:
 224        ValueError: on an empty symbol tuple, a non-str or empty
 225            symbol, repeated symbols, or an empty calendar name.
 226
 227    Example::
 228
 229        >>> universe = UniverseSpec(symbols=("ES", "ZN"), calendar="CME")
 230        >>> (universe.symbols, universe.calendar)
 231        (('ES', 'ZN'), 'CME')
 232        >>> try:
 233        ...     UniverseSpec(symbols=("ES", "ES"))
 234        ... except ValueError as error:
 235        ...     "symbols must be unique" in str(error)
 236        True
 237    """
 238
 239    symbols: tuple[str, ...]
 240    calendar: str = "24/7"
 241
 242    def __post_init__(self) -> None:
 243        """Validate the symbol tuple and the calendar label."""
 244        symbols = tuple(self.symbols)
 245        if not symbols:
 246            raise ValueError(
 247                "UniverseSpec.symbols must be a non-empty tuple of"
 248                " non-empty strs"
 249            )
 250        for symbol in symbols:
 251            if not isinstance(symbol, str) or not symbol:
 252                raise ValueError(
 253                    "UniverseSpec.symbols entries must be non-empty"
 254                    f" strs, got {symbol!r}"
 255                )
 256        if len(set(symbols)) != len(symbols):
 257            repeated = sorted(
 258                symbol for symbol in symbols if symbols.count(symbol) > 1
 259            )
 260            raise ValueError(
 261                f"UniverseSpec: symbols must be unique, repeated:"
 262                f" {sorted(set(repeated))}"
 263            )
 264        object.__setattr__(self, "symbols", symbols)
 265        if not isinstance(self.calendar, str) or not self.calendar:
 266            raise ValueError(
 267                "UniverseSpec.calendar must be a non-empty str, got"
 268                f" {self.calendar!r}"
 269            )

 272@dataclass(frozen=True)
 273class StrategySpec:
 274    """A strategy: named legs plus a portfolio policy and a universe.
 275
 276    ONE shape for every composition: ``legs`` must be a non-empty
 277    tuple of :class:`atropos.legs.LegSpec`, and EACH leg is audited
 278    with :func:`atropos.legs.validate_features_declared` at
 279    construction -- a strategy with an inconsistent leg is dead on
 280    arrival, not at run time.  Leg names must be UNIQUE across the
 281    strategy: ``run_book`` keys its records by leg name, so a
 282    duplicate would silently collide.  The MVP policy is
 283    an explicit REQUIRED ``PortfolioPolicy`` (the carry policy is
 284    declared, never defaulted) and the MVP universe is an unset
 285    placeholder.
 286
 287    Args:
 288        name: non-empty strategy name (echoed into the summary).
 289        legs: one or more legs; each is feature-contract audited.
 290        portfolio: how legs share the book (REQUIRED -- the carry
 291            policy is declared, never defaulted).
 292        universe: informational universe metadata (enforcement
 293            deferred).
 294
 295    Raises:
 296        ValueError: on an empty or non-str name, a non-LegSpec entry,
 297            a leg failing :func:`atropos.legs.validate_features_
 298            declared`, an empty legs tuple, or duplicate leg names.
 299
 300    Example::
 301
 302        >>> from atropos.legs import (
 303        ...     Compare, EntrySpec, ExitSpec, InstrumentRef, LegSpec,
 304        ... )
 305        >>> leg = LegSpec(
 306        ...     name="momo_long", direction="long",
 307        ...     entry=EntrySpec(Compare("mom", ">", 0.0)),
 308        ...     exit=ExitSpec(signal=Compare("mom", "<", 0.0)),
 309        ...     instrument=InstrumentRef("field", {"field": "mom"}),
 310        ...     features_used=("mom",),
 311        ...     rationale="momentum persistence",
 312        ... )
 313        >>> strategy = StrategySpec(
 314        ...     name="demo", legs=(leg,),
 315        ...     portfolio=PortfolioPolicy(
 316        ...         borrow_bps_annual=500.0, funding_bps_annual=100.0
 317        ...     ),
 318        ... )
 319        >>> (strategy.portfolio.combination, strategy.universe.symbols)
 320        ('independent', ('unset',))
 321        >>> try:
 322        ...     StrategySpec(
 323        ...         name="demo", legs=(leg, leg),
 324        ...         portfolio=PortfolioPolicy(
 325        ...             borrow_bps_annual=500.0,
 326        ...             funding_bps_annual=100.0,
 327        ...         ),
 328        ...     )
 329        ... except ValueError as error:
 330        ...     "leg names must be unique" in str(error)
 331        True
 332    """
 333
 334    name: str
 335    legs: tuple[LegSpec, ...]
 336    portfolio: PortfolioPolicy
 337    universe: UniverseSpec = UniverseSpec(symbols=("unset",))
 338
 339    def __post_init__(self) -> None:
 340        """Validate the name, audit every leg, pin name uniqueness."""
 341        if not isinstance(self.name, str) or not self.name:
 342            raise ValueError(
 343                f"StrategySpec.name must be a non-empty str,"
 344                f" got {self.name!r}"
 345            )
 346        legs = tuple(self.legs)
 347        if not legs:
 348            raise ValueError(
 349                f"StrategySpec {self.name!r}: legs needs at least one LegSpec"
 350            )
 351        for leg in legs:
 352            if not isinstance(leg, LegSpec):
 353                raise ValueError(
 354                    f"StrategySpec {self.name!r}: legs entries must be"
 355                    f" LegSpec, got {type(leg).__name__}"
 356                )
 357            validate_features_declared(leg)
 358        leg_names = [leg.name for leg in legs]
 359        if len(set(leg_names)) != len(leg_names):
 360            repeated = sorted(
 361                name for name in leg_names if leg_names.count(name) > 1
 362            )
 363            raise ValueError(
 364                f"StrategySpec {self.name!r}: leg names must be unique"
 365                " across the strategy (run_book records are keyed by"
 366                f" leg name), repeated: {sorted(set(repeated))}"
 367            )
 368        object.__setattr__(self, "legs", legs)

 393# ---------------------------------------------------------------------------
 394# run + flatten (the strategy -> book -> analysis path)
 395# ---------------------------------------------------------------------------
 396def run_strategy(
 397    strategy: StrategySpec,
 398    md: MaterializedData,
 399    *,
 400    cost: CostModel = DEFAULT_COST,
 401    gates: bool = False,
 402) -> dict[str, Any]:
 403    """Run one strategy spec through the Book and summarize it.
 404
 405    Dispatch on ``strategy.portfolio.combination``:
 406    ``"independent"`` hands the legs to :func:`atropos.book.run_book`,
 407    which runs each leg in a FRESH Book so legs cannot interact;
 408    ``"sequential"`` / ``"priority"`` / ``"netting"`` delegate to
 409    :meth:`atropos.book.Book.walk_portfolio`, the ONE shared-state
 410    walk (single position pool, shared equity ledger).
 411    ``"sequential"`` and ``"priority"`` have NO offsetting -- a long
 412    and a short on the same instrument both hold and each accrues
 413    its own PnL; ``"netting"`` is its own combination (an entry
 414    intent opposite to an open position on the same instrument
 415    closes it and is itself consumed).  The policy's caps are NOT
 416    enforced on either path: the leg-count cap and the per-bar
 417    gross/net cap breaches land in ``result["policy_notes"]`` as
 418    diagnostics only -- enforcement is deferred (KNOWN-ISSUES
 419    section 14).  Before summarizing, the records' leg attribution
 420    is verified (every record must belong to a declared leg) and the
 421    per-leg trade counts are recounted from the records against the
 422    run's ``per_leg`` map; the REAL isolation pin lives in the
 423    tests.
 424
 425    Args:
 426        strategy: the strategy spec (legs audited at construction).
 427        md: the materialized bundle every leg consumes.
 428        cost: the cost model handed unchanged to the Book (each
 429            fresh Book, or the shared walk's Book).
 430        gates: when True, run the portfolio kill gates
 431            (:func:`atropos.portfolio.portfolio_gates`) with
 432            ``min_trades=20``, ``n_trials=5`` and
 433            ``prereg_hash=None``.  The gates' ``daily_ev`` input is
 434            CALENDAR-DAY, NOT per-bar: each trade's ``pnl_net_r`` is
 435            bucketed by its exit day (``exit_ts.normalize()``) and
 436            summed per day.  The report's ``prereg_hash`` is
 437            therefore None and the ``"gates UNVERIFIED (no
 438            prereg_hash)"`` note fires; no hash is ever fabricated.
 439
 440    Returns:
 441        The UNIFIED result -- the same keys for every combination:
 442        ``"records"`` (per-leg TradeRecord lists), ``"equity_r"``
 443        (total net R), ``"per_leg"`` (per-leg counts and net R),
 444        ``"exposure"`` (``{"concurrent": [...], "net": [...]}``, one
 445        entry per decision bar; for the shared modes the walk's own
 446        authoritative series, for ``"independent"`` reconstructed
 447        from the closed-trade ledger where a trade occupies
 448        ``[entry_bar, exit_bar]`` inclusive), ``"equity_curve"``
 449        (per-bar cumulative net R, credited at exit bars, ``0.0``
 450        before the first close), ``"policy_notes"`` (the summary's
 451        boundary notes extended with the shared walk's warnings
 452        verbatim, the cap-breach diagnostics and, when ``gates``
 453        ran, the UNVERIFIED note; ``summary["policy_notes"]`` keeps
 454        its stable base list), ``"gates"`` (a
 455        :class:`atropos.portfolio.GateReport` when ``gates=True``,
 456        else ``None``) and ``"summary"`` (a
 457        :class:`StrategySummary`).
 458
 459    Raises:
 460        ValueError: when leg attribution is lost (a record keyed by,
 461            or carrying a ``leg_name`` different from, a name outside
 462            ``strategy.legs``) or the run's per-leg trade counts
 463            disagree with the recount from the records.
 464
 465    Example::
 466
 467        The entry gates sit at +/- 1.0 because ``StopSpec("price",
 468        0.9)`` is an ABSOLUTE price: with the N(0,1)-scaled
 469        ``mom_signal`` as instrument, a long gate at ``> 0`` could
 470        fire on instrument values in ``(0, 0.9]`` where that stop is
 471        degenerate (LegEngine raises).  The example asserts on
 472        structure (keys, attribution, count consistency), not on
 473        exact trade counts.
 474
 475        >>> from atropos.data_contract import MaterializedData
 476        >>> from atropos.legs import (
 477        ...     Compare, EntrySpec, ExitSpec, InstrumentRef, LegSpec,
 478        ...     StopSpec, TargetSpec,
 479        ... )
 480        >>> bars = pd.date_range("2024-01-01", periods=6, freq="D",
 481        ...                      tz="UTC")
 482        >>> close = pd.Series([1.0, 1.2, 0.8, 1.1, 1.3, 0.9], index=bars)
 483        >>> md = MaterializedData(
 484        ...     outcome=pd.Series(0.0, index=bars),
 485        ...     features=pd.DataFrame(
 486        ...         {
 487        ...             "mom_signal": [2.0, -2.0, 2.5, -2.5, 2.2, -2.2],
 488        ...             "open": [0.99, 1.19, 0.79, 1.09, 1.29, 0.89],
 489        ...             "high": [1.21, 1.21, 0.95, 1.21, 1.31, 1.05],
 490        ...             "low": [0.97, 0.99, 0.75, 0.95, 1.09, 0.85],
 491        ...             "close": close,
 492        ...         },
 493        ...         index=bars,
 494        ...     ),
 495        ...     controls=pd.DataFrame(index=bars),
 496        ...     index=pd.DataFrame(
 497        ...         {"ts": bars, "entity": "", "split": "train"}, index=bars
 498        ...     ),
 499        ... )
 500        >>> long_leg = LegSpec(
 501        ...     name="momo_long", direction="long",
 502        ...     entry=EntrySpec(Compare("mom_signal", ">", 1.0)),
 503        ...     exit=ExitSpec(
 504        ...         stop=StopSpec("price", 0.9),
 505        ...         target=TargetSpec("price", 1.1),
 506        ...         signal=Compare("mom_signal", "<", 0.0),
 507        ...     ),
 508        ...     instrument=InstrumentRef("field", {"field": "mom_signal"}),
 509        ...     features_used=("mom_signal",),
 510        ...     rationale="momentum persistence on the daily grid",
 511        ... )
 512        >>> short_leg = LegSpec(
 513        ...     name="momo_short", direction="short",
 514        ...     entry=EntrySpec(Compare("mom_signal", "<", -1.0)),
 515        ...     exit=ExitSpec(
 516        ...         stop=StopSpec("price", 0.9),
 517        ...         target=TargetSpec("price", 1.1),
 518        ...         signal=Compare("mom_signal", ">", 0.0),
 519        ...     ),
 520        ...     instrument=InstrumentRef("field", {"field": "mom_signal"}),
 521        ...     features_used=("mom_signal",),
 522        ...     rationale="momentum reversal on the daily grid",
 523        ... )
 524        >>> strategy = StrategySpec(
 525        ...     name="momo_pair",
 526        ...     legs=(long_leg, short_leg),
 527        ...     portfolio=PortfolioPolicy(
 528        ...         borrow_bps_annual=500.0,
 529        ...         funding_bps_annual=100.0,
 530        ...         periods_override=252.0,
 531        ...     ),
 532        ...     universe=UniverseSpec(symbols=("synthetic",)),
 533        ... )
 534        >>> result = run_strategy(strategy, md)
 535        >>> summary = result["summary"]
 536        >>> (summary["strategy_name"], summary["n_legs"])
 537        ('momo_pair', 2)
 538        >>> (summary["combination"], summary["universe_symbols"])
 539        ('independent', ['synthetic'])
 540        >>> required_summary = {
 541        ...     "combination", "equity_r", "leg_isolation_check",
 542        ...     "n_legs", "n_trades", "per_leg", "policy_notes",
 543        ...     "strategy_name", "universe_symbols",
 544        ... }
 545        >>> required_summary <= set(summary)

 673def records_to_features(
 674    records: list[Any],
 675    feature_keys: tuple[str, ...] = (
 676        "leg_name",
 677        "entry_ts",
 678        "direction",
 679        "size_r",
 680        "pnl_net_r",
 681        "exit_reason",
 682    ),
 683) -> pd.DataFrame:
 684    """Flatten TradeRecords into one analysis-ready frame.
 685
 686    This is the BRIDGE from "what the strategy did" to "what Atropos
 687    analyzes": one row per trade, the record's scalar fields
 688    selected by ``feature_keys`` as columns (dict-valued keys --
 689    ``features_at_entry`` / ``features_at_exit`` / ``diagnostics``
 690    -- are never raw columns), PLUS the entry feature snapshot
 691    expanded with an ``entry::`` prefix so ``orthogonal_check`` /
 692    ``bucket_scan`` / ``feature_importance`` can consume the trades
 693    directly.  Causal importance is NOT served by this frame:
 694    causal tools need features re-generated from the data, not a
 695    snapshot copied at entry time.
 696
 697    Args:
 698        records: TradeRecord dicts (as returned under ``"records"``
 699            by :func:`run_strategy`).
 700        feature_keys: which scalar record fields become columns; the
 701            ``entry::`` expansion is always added on top.
 702
 703    Returns:
 704        The analysis-ready frame.  Empty records give an empty frame
 705        with exactly the ``feature_keys`` columns (the ``entry::``
 706        columns are data-dependent and therefore absent).
 707
 708    Raises:
 709        ValueError: when a record is not a TradeRecord-like mapping.
 710
 711    Example::
 712
 713        >>> records = [
 714        ...     {
 715        ...         "leg_name": "momo_long", "entry_ts": "2024-01-02",
 716        ...         "direction": "long", "size_r": 1.0,
 717        ...         "pnl_net_r": 0.4, "exit_reason": "target",
 718        ...         "features_at_entry": {"mom_signal": 1.5, "atr": 0.5},
 719        ...         "features_at_exit": {"mom_signal": 2.1},
 720        ...         "diagnostics": {"predicate_row": {"mom_signal": 1.5}},
 721        ...     },
 722        ...     {
 723        ...         "leg_name": "momo_short", "entry_ts": "2024-01-03",
 724        ...         "direction": "short", "size_r": 1.0,
 725        ...         "pnl_net_r": -0.2, "exit_reason": "stop",
 726        ...         "features_at_entry": {"mom_signal": -1.2},
 727        ...         "features_at_exit": {"mom_signal": -0.4},
 728        ...         "diagnostics": {},
 729        ...     },
 730        ... ]
 731        >>> frame = records_to_features(records)
 732        >>> len(frame)
 733        2
 734        >>> "entry::mom_signal" in frame.columns
 735        True
 736        >>> frame["entry::mom_signal"].iloc[0]
 737        np.float64(1.5)
 738        >>> empty = records_to_features([])
 739        >>> len(empty)
 740        0
 741        >>> list(empty.columns)[:3]
 742        ['leg_name', 'entry_ts', 'direction']
 743    """
 744    rows: list[dict[str, Any]] = []
 745    entry_columns: list[str] = []
 746    for position, record in enumerate(records):
 747        if not isinstance(record, Mapping):
 748            raise ValueError(
 749                f"records[{position}] must be a TradeRecord-like"
 750                f" mapping, got {type(record).__name__}"
 751            )
 752        row: dict[str, Any] = {}
 753        for key in feature_keys:
 754            value = record.get(key)
 755            if isinstance(value, Mapping):
 756                continue  # dict-valued keys never become raw columns
 757            row[key] = value
 758        snapshot = record.get("features_at_entry")
 759        if isinstance(snapshot, Mapping):
 760            for feature_name, feature_value in snapshot.items():
 761                if isinstance(feature_value, Mapping):
 762                    continue
 763                column = f"entry::{feature_name}"
 764                row[column] = feature_value
 765                if column not in entry_columns:
 766                    entry_columns.append(column)
 767        rows.append(row)
 768    if not rows:
 769        return pd.DataFrame([], columns=list(feature_keys))
 770    return pd.DataFrame(rows, columns=list(feature_keys) + entry_columns)

 776def _recount_and_verify(
 777    strategy: StrategySpec,
 778    records: Mapping[str, list[Mapping[str, Any]]],
 779    per_leg: Mapping[str, Mapping[str, Any]],
 780) -> dict[str, int]:
 781    """Verify leg attribution and recount trades per strategy leg.
 782
 783    Both dispatch paths key records by leg name (a fresh Book per
 784    leg, or the shared walk's one pool); here the records must still
 785    carry honest attribution: a record stored under one leg's name
 786    must name exactly that leg, and the run's ``per_leg`` counts
 787    must match the recount.
 788
 789    Returns:
 790        Trade count per declared leg name (0 for a leg with no
 791        records), in ``strategy.legs`` order.
 792
 793    Raises:
 794        ValueError: with ``"leg attribution lost"`` when a record is
 795            keyed by an unknown leg name or its ``leg_name``
 796            disagrees with its key, and on any per-leg count
 797            disagreement between ``per_leg`` and the recount.
 798    """
 799    leg_names = {leg.name for leg in strategy.legs}
 800    counts: dict[str, int] = {leg.name: 0 for leg in strategy.legs}
 801    for leg_name, leg_records in records.items():
 802        if leg_name not in leg_names:
 803            raise ValueError(
 804                "leg attribution lost: records are keyed by"
 805                f" {leg_name!r}, which no leg of strategy"
 806                f" {strategy.name!r} declares"
 807            )
 808        for record in leg_records:
 809            attributed = record.get("leg_name")
 810            if attributed != leg_name:
 811                raise ValueError(
 812                    "leg attribution lost: a record stored under"
 813                    f" {leg_name!r} carries leg_name={attributed!r}"
 814                    f" (strategy {strategy.name!r})"
 815                )
 816        counts[leg_name] = len(leg_records)
 817    for leg_name, count in counts.items():
 818        book_entry = per_leg.get(leg_name)
 819        book_count = (
 820            0 if book_entry is None else int(book_entry.get("n_trades", 0))
 821        )
 822        if book_count != count:
 823            raise ValueError(
 824                f"strategy {strategy.name!r}: leg {leg_name!r}"
 825                f" n_trades {book_count} from run_book per_leg !="
 826                f" recount {count} from records"
 827            )
 828    return counts

 831def _build_summary(
 832    strategy: StrategySpec,
 833    counts: dict[str, int],
 834    per_leg: Mapping[str, Mapping[str, Any]],
 835    equity_r: float,
 836) -> StrategySummary:
 837    """Assemble the :class:`StrategySummary` from verified parts."""
 838    summary_per_leg: dict[str, dict[str, float]] = {}
 839    for leg in strategy.legs:
 840        book_entry = per_leg.get(leg.name)
 841        pnl_net_r = (
 842            0.0
 843            if book_entry is None
 844            else float(book_entry.get("pnl_net_r", 0.0))
 845        )
 846        summary_per_leg[leg.name] = {
 847            "n_trades": float(counts[leg.name]),
 848            "pnl_net_r": pnl_net_r,
 849        }
 850    return StrategySummary(
 851        strategy_name=strategy.name,
 852        n_legs=len(strategy.legs),
 853        n_trades=sum(counts.values()),
 854        equity_r=equity_r,
 855        per_leg=summary_per_leg,
 856        combination=strategy.portfolio.combination,
 857        universe_symbols=list(strategy.universe.symbols),
 858        policy_notes=_policy_notes(strategy),
 859        leg_isolation_check=True,
 860    )

 887def _open_series(
 888    records_by_leg: dict[str, list[dict[str, Any]]],
 889    n_bars: int,
 890) -> tuple[list[int], list[float], list[float]]:
 891    """Per-bar open-position series rebuilt from CLOSED-trade records.
 892
 893    A trade occupies ``[entry_bar, exit_bar]`` inclusive (its
 894    ``entry_bar`` / ``exit_bar`` keys, positions on the decision
 895    grid).  ``concurrent`` counts the open positions at each bar,
 896    ``net`` sums ``direction * size_r`` over them (``direction`` is
 897    ``+1`` long / ``-1`` short) and ``gross`` sums ``abs(size_r)``
 898    over them.  This is a RECONSTRUCTION from the closed-trade
 899    ledger, not the walk's live ledger -- the shared modes keep
 900    their own walk's concurrent/net series as authoritative.
 901
 902    Returns:
 903        ``(concurrent, net, gross)`` -- one entry per bar, zeros
 904        where nothing is open.
 905    """
 906    concurrent = [0] * n_bars
 907    net = [0.0] * n_bars
 908    gross = [0.0] * n_bars
 909    for leg_records in records_by_leg.values():
 910        for record in leg_records:
 911            entry_bar = int(record["entry_bar"])
 912            exit_bar = int(record["exit_bar"])
 913            signed = int(record["direction"]) * float(record["size_r"])
 914            for bar in range(entry_bar, exit_bar + 1):
 915                concurrent[bar] += 1
 916                net[bar] += signed
 917                gross[bar] += abs(signed)
 918    return concurrent, net, gross

 921def _equity_curve_from_records(
 922    records_by_leg: dict[str, list[dict[str, Any]]],
 923    n_bars: int,
 924) -> list[float]:
 925    """Per-bar cumulative net R, credited at each trade's exit bar.
 926
 927    Matches the shared walk's equity-curve shape: ``curve[i]`` is
 928    the cumulative ``pnl_net_r`` AFTER bar ``i`` (a close credits
 929    its bar), ``0.0`` before the first close.
 930    """
 931    credited = [0.0] * n_bars
 932    for leg_records in records_by_leg.values():
 933        for record in leg_records:
 934            credited[int(record["exit_bar"])] += float(record["pnl_net_r"])
 935    curve: list[float] = []
 936    running = 0.0
 937    for pnl in credited:
 938        running += pnl
 939        curve.append(running)
 940    return curve

 943def _exposure_from_records(
 944    records_by_leg: dict[str, list[dict[str, Any]]],
 945    n_bars: int,
 946) -> tuple[list[int], list[float], list[float]]:
 947    """The independent-mode per-bar exposure triple from records.
 948
 949    Composes :func:`_open_series` and
 950    :func:`_equity_curve_from_records` into
 951    ``(concurrent, net, equity_curve)`` -- the same series shape the
 952    shared walk reports, so :func:`run_strategy` can hand one
 953    unified result contract to consumers of either composition
 954    path.
 955    """
 956    concurrent, net, _gross = _open_series(records_by_leg, n_bars)
 957    equity_curve = _equity_curve_from_records(records_by_leg, n_bars)
 958    return concurrent, net, equity_curve

 961def _daily_ev(
 962    records_by_leg: dict[str, list[dict[str, Any]]],
 963) -> pd.Series:
 964    """Calendar-day aggregation of closed-trade net R.
 965
 966    Each trade's ``pnl_net_r`` is bucketed by its ``exit_ts``
 967    normalized to midnight (``ts.normalize()``), summed per day and
 968    ordered by day -- the ``daily_ev`` stream the portfolio gates
 969    consume is calendar-day, NOT per-bar.
 970
 971    Returns:
 972        A ``pd.Series`` indexed by normalized day Timestamps whose
 973        values are the summed ``pnl_net_r``; empty records give an
 974        empty float series.
 975    """
 976    day_totals: dict[pd.Timestamp, float] = {}
 977    for leg_records in records_by_leg.values():
 978        for record in leg_records:
 979            day = pd.Timestamp(record["exit_ts"]).normalize()
 980            day_totals[day] = day_totals.get(day, 0.0) + float(
 981                record["pnl_net_r"]
 982            )
 983    if not day_totals:
 984        return pd.Series(dtype=np.float64)
 985    ordered_days = sorted(day_totals)
 986    return pd.Series(
 987        [day_totals[day] for day in ordered_days],
 988        index=pd.DatetimeIndex(ordered_days),
 989        dtype=np.float64,
 990    )

 993def _cap_breach_notes(
 994    policy: PortfolioPolicy,
 995    gross: list[float],
 996    net: list[float],
 997) -> list[str]:
 998    """Soft-cap breach diagnostics (reporting only, no enforcement).
 999
1000    A note fires only when the series' per-bar peak EXCEEDS the
1001    policy cap (strictly); the bar count is the number of bars
1002    strictly above the cap.  Enforcement stays deferred.
1003    """
1004    notes: list[str] = []
1005    gross_peak = max(gross, default=0.0)
1006    if gross_peak > policy.max_gross_exposure:
1007        gross_bars = sum(
1008            1 for value in gross if value > policy.max_gross_exposure
1009        )
1010        notes.append(
1011            f"cap breach: gross {gross_peak:.2f}"
1012            f" > {policy.max_gross_exposure:.2f}"
1013            f" on {gross_bars} bars"
1014        )
1015    net_peak = max(net, default=0.0)
1016    if net_peak > policy.max_net_exposure:
1017        net_bars = sum(1 for value in net if value > policy.max_net_exposure)
1018        notes.append(
1019            f"cap breach: net {net_peak:.2f}"
1020            f" > {policy.max_net_exposure:.2f}"
1021            f" on {net_bars} bars"
1022        )
1023    return notes
