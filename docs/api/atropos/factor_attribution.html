atropos.factor_attribution

Factor attribution: the native factor_regression instrument.

The cross_sectional_factor plan (atropos.instrument_map) judges a factor book by stage_7_cs + factor_regression; this module IS the factor_regression instrument. Three public pieces:

  • factor_regression() -- OLS of the strategy's return stream on factor proxies (intercept + HC0 statistics, the atropos.orthogonal.FitBlock conventions), with an explicit collinearity screen (pairwise |pearson| >= 0.95 drops the LATER factor in insertion order; an iterative VIF screen then drops the highest-VIF factor while any VIF exceeds 10 -- every drop lands in factors_dropped with its reason).
  • factor_verdict() -- the ROUTING verdict of the report: a stream whose variance the factors explain is a FACTOR_EXPOSURE (the book collects the factor; it is not alpha -- packaging-vs- direct comparison, §18), while a stream with a significant intercept AFTER the factor betas is an ALPHA_CANDIDATE (the orthogonal residual is the real finding). Precedence: a significant alpha wins even when R2 is high -- the residual is the information the factors do not own.
  • construct_factor_proxies() -- builds the standard proxy trio's honest subset (mkt equal-weight mean + bab_proxy low-beta minus high-beta, trailing 60-row betas) from a dates x symbols returns panel, for callers who only have the panel.

The size_proxy is deliberately NOT constructed: a size factor needs market-cap data the panel does not carry, and fabricating a price-based stand-in would smuggle a different factor under the name. Callers with cap data pass their own size column into factor_regression.

Alignment contract: factor_regression takes streams the CALLER has already aligned by index/position (the shared align_inputs path still inner-joins pandas indexes and drops non-finite rows; numpy inputs align positionally).

Import note: reuses atropos.orthogonal.FitBlock and the ols_hc0 helper so the fit statistics cannot drift from the orthogonal check's conventions.

Run python -m atropos.factor_attribution for a synthetic demo.

 81class FactorRegressionReport(TypedDict):
 82    """Fixed report schema; every key is present on every outcome.
 83
 84    ``status`` is ``OK`` (identifiable design, ``n_obs >= 30``) or
 85    ``INCONCLUSIVE`` (empty alignment, degenerate outcome, all factors
 86    dropped, rank-deficient design, or ``n_obs < 30`` -- statistics are
 87    still carried when the fit ran, but the status forbids routing on
 88    them).  ``fit`` follows the :class:`atropos.orthogonal.FitBlock`
 89    conventions (``intercept`` first, then surviving factors in
 90    insertion order); ``alpha_mean`` / ``alpha_t`` duplicate the
 91    intercept's beta / t for the pinned reading.
 92    """
 93
 94    label: str
 95    status: str
 96    n_obs: int
 97    factors_used: list[str]
 98    factors_dropped: dict[str, str]
 99    fit: FitBlock
100    alpha_mean: float
101    alpha_t: float
102    r_squared: float
103    notes: list[str]

106class FactorVerdict(TypedDict):
107    """Routing verdict of one :class:`FactorRegressionReport`.
108
109    ``verdict`` is one of ``FACTOR_EXPOSURE`` / ``ALPHA_CANDIDATE`` /
110    ``RESIDUAL_WEAK`` / ``INCONCLUSIVE``; ``informative`` is True only
111    for the first two (the run separates the stream); the remaining
112    fields follow the glossary verdict anatomy (reading + run facts,
113    next step, what would change the verdict).
114    """
115
116    verdict: str
117    informative: bool
118    interpretation: str
119    next_step: str
120    what_would_change: str

126def _is_degenerate(values: np.ndarray) -> bool:
127    """True when a column cannot carry any statistical test.
128
129    Same semantics as ``atropos.orthogonal._is_degenerate``: empty,
130    all-NaN, no finite entry, or a zero peak-to-peak range over the
131    finite slice.
132    """
133    arr = np.asarray(values, dtype=float).reshape(-1)
134    if arr.size == 0 or np.all(np.isnan(arr)):
135        return True
136    finite = arr[np.isfinite(arr)]
137    if finite.size == 0:
138        return True
139    return bool(np.ptp(finite) == 0.0)

142def _one_column_frame(value: Any, name: str) -> pd.DataFrame:
143    """One-column frame view of an input, named for the alignment join.
144
145    A multi-column value (DataFrame or 2-D array) cannot map onto one
146    factor name, so it is rejected loudly (the same contract as the
147    orthogonal check's input screen).
148    """
149    frame = frameify(value, name)
150    if frame.shape[1] != 1:
151        raise ValueError(
152            f"factor {name!r} must be a single column, got"
153            f" {frame.shape[1]} columns"
154        )
155    return frame

158def _fit_block(fit: dict[str, Any], names: list[str]) -> FitBlock:
159    """Pack one ``ols_hc0`` payload into the report's fit block.
160
161    Same packing as ``atropos.orthogonal._fit_block``: the payload keys
162    ``t`` / ``p`` become the report keys ``t_stat`` / ``p_value``.
163    """
164    return FitBlock(
165        r2=float(fit["r2"]),
166        beta={key: float(fit["beta"][pos]) for pos, key in enumerate(names)},
167        se={key: float(fit["se"][pos]) for pos, key in enumerate(names)},
168        t_stat={key: float(fit["t"][pos]) for pos, key in enumerate(names)},
169        p_value={key: float(fit["p"][pos]) for pos, key in enumerate(names)},
170    )

184def _pairwise_screen(
185    names: list[str], arrays: list[np.ndarray]
186) -> tuple[list[str], list[np.ndarray], dict[str, str]]:
187    """Drop the LATER factor of any ``|pearson| >= 0.95`` pair.
188
189    One deterministic pass in insertion order: factor ``j`` is dropped
190    when any SURVIVING earlier factor ``i`` correlates with it at
191    ``|pearson| >= 0.95``; the earlier name always survives.
192    """
193    kept: list[tuple[str, np.ndarray]] = []
194    dropped: dict[str, str] = {}
195    for name, arr in zip(names, arrays, strict=True):
196        collinear_with = ""
197        worst_rho = 0.0
198        for kept_name, kept_arr in kept:
199            rho = float(np.corrcoef(arr, kept_arr)[0, 1])
200            if abs(rho) >= _PEARSON_DROP and abs(rho) > worst_rho:
201                collinear_with = kept_name
202                worst_rho = abs(rho)
203        if collinear_with:
204            dropped[name] = (
205                f"|pearson| = {worst_rho:.2f} with {collinear_with}"
206                f" (>= {_PEARSON_DROP} collinearity screen); the earlier"
207                " name survives"
208            )
209        else:
210            kept.append((name, arr))
211    return (
212        [name for name, _ in kept],
213        [arr for _, arr in kept],
214        dropped,
215    )

218def _vif_of(target: np.ndarray, others: list[np.ndarray]) -> float:
219    """VIF of one factor against the remaining columns (inf on break)."""
220    design = np.column_stack([np.ones(target.size), *others])
221    r_squared = float(ols_hc0(target, design)["r2"])
222    if not np.isfinite(r_squared) or r_squared >= 1.0:
223        return float("inf")
224    return 1.0 / (1.0 - r_squared)
225

227def _vif_screen(
228    names: list[str], arrays: list[np.ndarray]
229) -> tuple[list[str], list[np.ndarray], dict[str, str]]:
230    """Iteratively drop the highest-VIF factor while any VIF > 10.
231
232    Ties break to the LATER name in insertion order.  A single
233    surviving factor has no VIF to compute (nothing left to inflate
234    against), so the loop stops at one survivor.
235    """
236    kept_names = list(names)
237    kept_arrays = list(arrays)
238    dropped: dict[str, str] = {}
239    while len(kept_names) >= 2:
240        vifs = [
241            _vif_of(
242                kept_arrays[pos],
243                kept_arrays[:pos] + kept_arrays[pos + 1 :],
244            )
245            for pos in range(len(kept_arrays))
246        ]
247        worst_pos = max(range(len(vifs)), key=lambda pos: (vifs[pos], pos))
248        if vifs[worst_pos] <= _VIF_DROP:
249            break
250        dropped[kept_names[worst_pos]] = (
251            f"VIF = {vifs[worst_pos]:.1f} > {_VIF_DROP:g} against the"
252            " surviving factors (iterative VIF screen)"
253        )
254        del kept_names[worst_pos]
255        del kept_arrays[worst_pos]
256    return kept_names, kept_arrays, dropped

259def _align_and_screen(
260    returns: Any,
261    factors: dict[str, Any],
262) -> tuple[
263    np.ndarray, list[str], list[np.ndarray], dict[str, str], list[str]
264]:
265    """Align the streams and run every factor-drop screen.
266
267    Returns ``(returns_arr, usable_names, usable_arrays, dropped,
268    notes)``: ``dropped`` maps every dropped factor name to its reason
269    (degenerate column, pairwise ``|pearson| >= 0.95``, VIF > 10 --
270    in that order) and ``notes`` carries the same reasons plus the
271    row-drop note from the alignment.
272    """
273    notes: list[str] = []
274    dropped: dict[str, str] = {}
275    if not factors:
276        notes.append("no factors supplied (factors dict is empty)")
277    factor_frames = [
278        _one_column_frame(value, name) for name, value in factors.items()
279    ]
280    returns_frame = frameify(returns, "returns")
281    if returns_frame.shape[1] != 1:
282        raise ValueError(
283            "input 'returns' must be a single column, got"
284            f" {returns_frame.shape[1]} columns"
285        )
286    n_before = len(
287        pd.concat([returns_frame, *factor_frames], axis=1, join="inner")
288    )
289    aligned = align_inputs(returns, *factors.values())
290    returns_arr = aligned[0]
291    factor_arrs = aligned[1:]
292    if n_before > returns_arr.size:
293        notes.append(
294            f"{n_before - int(returns_arr.size)} row(s) dropped by"
295            " alignment (index mismatch or non-finite values)"
296        )
297
298    usable_names: list[str] = []
299    usable_arrays: list[np.ndarray] = []
300    for name, arr in zip(list(factors), factor_arrs, strict=True):
301        if _is_degenerate(arr):
302            dropped[name] = "degenerate column (constant or all-NaN)"
303            notes.append(f"factor {name} dropped: degenerate column")
304        else:
305            usable_names.append(name)
306            usable_arrays.append(arr)
307    if not usable_names:
308        return returns_arr, [], [], dropped, notes
309
310    usable_names, usable_arrays, pairwise = _pairwise_screen(
311        usable_names, usable_arrays
312    )
313    for name, reason in pairwise.items():
314        dropped[name] = reason
315        notes.append(f"factor {name} dropped: {reason}")
316    usable_names, usable_arrays, vif_dropped = _vif_screen(
317        usable_names, usable_arrays
318    )
319    for name, reason in vif_dropped.items():
320        dropped[name] = reason
321        notes.append(f"factor {name} dropped: {reason}")
322    return returns_arr, usable_names, usable_arrays, dropped, notes

325def _dominant_factor(
326    fit: FitBlock, factors_used: list[str]
327) -> tuple[str, float, float]:
328    """Name / beta / t of the factor with the largest |t_stat|.
329
330    Ties break to the earlier name in insertion order; with no finite
331    factor t the name is ``""`` (the caller reads that as undecidable).
332    """
333    dominant_name = ""
334    dominant_beta = float("nan")
335    dominant_t = float("nan")
336    for name in factors_used:
337        t_stat = float(fit["t_stat"][name])
338        if np.isfinite(t_stat) and abs(t_stat) > abs(dominant_t):
339            dominant_name = name
340            dominant_beta = float(fit["beta"][name])
341            dominant_t = t_stat
342    return dominant_name, dominant_beta, dominant_t

348def factor_regression(
349    returns: Any,
350    factors: dict[str, Any],
351    *,
352    label: str = "unnamed",
353) -> FactorRegressionReport:
354    """OLS of a return stream on factor proxies (intercept + HC0).
355
356    Fits ``returns ~ intercept + factors`` with the shared ``ols_hc0``
357    (HC0 standard errors, t / p per column, R2, rank-deficiency flag --
358    the orthogonal check's conventions), after two collinearity screens
359    (pairwise ``|pearson| >= 0.95`` drops the later name; iterative VIF
360    drops the highest-VIF factor while any VIF exceeds 10).  Degenerate
361    factor columns (constant / all-NaN after alignment) are dropped
362    with a note.  ``alpha_mean`` is the intercept beta, ``alpha_t`` its
363    t-statistic: the mean and significance of the residual the factors
364    do not explain.
365
366    Args:
367        returns: the strategy's return / R stream (pandas or numpy 1-D
368            array-like), index/position-aligned with every factor by
369            the CALLER; the shared alignment still drops non-finite
370            rows.
371        factors: mapping factor name -> single column (Series or 1-D
372            array-like); insertion order fixes the design order.
373        label: free-text tag stored under ``report["label"]``.
374
375    Returns:
376        :class:`FactorRegressionReport`; ``status`` is ``OK`` only for
377        an identifiable design with ``n_obs >= 30`` (see the class
378        docstring for the INCONCLUSIVE causes).
379
380    Raises:
381        ValueError: if a factor value is not a single column.
382
383    Example::
384
385        >>> import numpy as np
386        >>> import pandas as pd
387        >>> rng = np.random.default_rng(11)
388        >>> mkt = rng.standard_normal(240)
389        >>> strategy = pd.Series(0.8 * mkt + 0.1 * rng.standard_normal(240))
390        >>> report = factor_regression(
391        ...     strategy, {"mkt": pd.Series(mkt)}, label="pure beta"
392        ... )
393        >>> report["status"], round(report["fit"]["beta"]["mkt"], 2)
394        ('OK', 0.8)
395        >>> round(report["r_squared"], 2) >= 0.97
396        True
397        >>> twin = factor_regression(
398        ...     strategy,
399        ...     {"mkt": pd.Series(mkt), "mkt_copy": pd.Series(2.0 * mkt)},
400        ...     label="collinear pair",
401        ... )
402        >>> list(twin["factors_dropped"]), twin["status"]
403        (['mkt_copy'], 'OK')
404    """
405    (
406        returns_arr,
407        usable_names,
408        usable_arrays,
409        dropped,
410        notes,
411    ) = _align_and_screen(returns, factors)
412    n_obs = int(returns_arr.size)
413
414    status = _OK
415    if n_obs == 0:
416        status = _INCONCLUSIVE
417        notes.append("no rows survived alignment - cannot fit any design")
418    elif _is_degenerate(returns_arr):
419        status = _INCONCLUSIVE
420        notes.append("returns stream is constant after alignment")
421    elif not usable_names:
422        status = _INCONCLUSIVE
423        notes.append(
424            "no usable factor columns survived the screens - attribution"
425            " is undecidable"
426        )
427
428    fit = _nan_fit_block()
429    r_squared = float("nan")
430    alpha_mean = float("nan")
431    alpha_t = float("nan")
432    if n_obs > 0 and usable_names and status == _OK:
433        design = np.column_stack([np.ones(n_obs), *usable_arrays])
434        payload = ols_hc0(returns_arr, design)
435        fit = _fit_block(payload, ["intercept", *usable_names])
436        r_squared = float(payload["r2"])
437        alpha_mean = float(payload["beta"][0])
438        alpha_t = float(payload["t"][0])
439        if bool(payload["rank_deficient"]) or not np.isfinite(r_squared):
440            status = _INCONCLUSIVE
441            notes.append(
442                "design is rank-deficient or saturated - statistics are"
443                " NaN and must not be read as evidence"
444            )
445    if status == _OK and n_obs < _MIN_OBS:
446        status = _INCONCLUSIVE
447        notes.append(
448            f"n_obs = {n_obs} < {_MIN_OBS} minimum - numbers carried"
449            " for inspection only, routing is forbidden"
450        )
451
452    return FactorRegressionReport(
453        label=label,
454        status=status,
455        n_obs=n_obs,
456        factors_used=usable_names,
457        factors_dropped=dropped,
458        fit=fit,
459        alpha_mean=alpha_mean,
460        alpha_t=alpha_t,
461        r_squared=r_squared,
462        notes=notes,
463    )
464

466def factor_verdict(
467    report: FactorRegressionReport,
468    *,
469    r2_exposure: float = 0.7,
470    alpha_t_threshold: float = 2.0,
471) -> FactorVerdict:
472    """Routing verdict of a :class:`FactorRegressionReport` (§18).
473
474    Semantics (precedence top-down):
475
476    * ``ALPHA_CANDIDATE`` -- ``|alpha_t| >= alpha_t_threshold``: the
477      orthogonal residual is the real finding, even when R2 is high.
478    * ``FACTOR_EXPOSURE`` -- ``r_squared >= r2_exposure`` with an
479      insignificant alpha: the book collects the factor; deploy it as
480      an exposure, not as alpha (packaging-vs-direct comparison, §18).
481    * ``RESIDUAL_WEAK`` -- neither factor nor alpha: noise on this
482      alignment.
483    * ``INCONCLUSIVE`` -- non-OK status (``n_obs < 30``, empty
484      alignment, collinearity-undecidable or rank-deficient design).
485
486    Args:
487        report: a :class:`FactorRegressionReport` from
488            :func:`factor_regression`.
489        r2_exposure: R2 an exposure must clear; must lie in (0, 1).
490        alpha_t_threshold: |alpha_t| that separates alpha from noise;
491            must be a positive finite float.
492
493    Returns:
494        :class:`FactorVerdict` with the run facts (R2, alpha_t,
495        dominant beta) in ``interpretation``.
496
497    Raises:
498        ValueError: if ``r2_exposure`` is not in (0, 1) or
499            ``alpha_t_threshold`` is not a positive finite float.
500
501    Example::
502
503        >>> import numpy as np
504        >>> import pandas as pd
505        >>> rng = np.random.default_rng(11)
506        >>> mkt = rng.standard_normal(240)
507        >>> pure_beta = pd.Series(0.8 * mkt + 0.1 * rng.standard_normal(240))
508        >>> exposure = factor_verdict(
509        ...     factor_regression(
510        ...         pure_beta, {"mkt": pd.Series(mkt)}, label="pure beta"
511        ...     )
512        ... )
513        >>> exposure["verdict"], exposure["informative"]
514        ('FACTOR_EXPOSURE', True)
515        >>> with_alpha = pd.Series(
516        ...     0.05 + 0.8 * mkt + 0.05 * rng.standard_normal(240)
517        ... )
518        >>> factor_verdict(
519        ...     factor_regression(
520        ...         with_alpha, {"mkt": pd.Series(mkt)}, label="planted"
521        ...     )
522        ... )["verdict"]
523        'ALPHA_CANDIDATE'
524    """
525    exposure_gate = validate_number("r2_exposure", r2_exposure)
526    if not 0.0 < exposure_gate < 1.0:
527        raise ValueError(
528            f"r2_exposure must be in (0, 1), got {r2_exposure!r}"
529        )
530    alpha_gate = validate_number("alpha_t_threshold", alpha_t_threshold)
531    if alpha_gate <= 0:
532        raise ValueError(
533            "alpha_t_threshold must be a positive finite float, got"
534            f" {alpha_t_threshold!r}"
535        )
536
537    alpha_t = float(report["alpha_t"])
538    r_squared = float(report["r_squared"])
539    if (
540        report["status"] != _OK
541        or not report["factors_used"]
542        or not np.isfinite(alpha_t)
543        or not np.isfinite(r_squared)
544    ):
545        reason = (
546            "; ".join(report["notes"]) if report["notes"] else "undecidable"
547        )
548        return FactorVerdict(
549            verdict=_INCONCLUSIVE,
550            informative=False,
551            interpretation=f"undecidable: {reason}",
552            next_step=(
553                "collect at least 30 aligned observations and an"
554                " identifiable factor set, then re-run"
555            ),
556            what_would_change=(
557                "an OK report (full-rank factors, n_obs >= 30) with"
558                " finite alpha_t and r_squared"
559            ),
560        )
561
562    dominant_name, dominant_beta, dominant_t = _dominant_factor(
563        report["fit"], report["factors_used"]
564    )
565    if abs(alpha_t) >= alpha_gate:
566        return FactorVerdict(
567            verdict="ALPHA_CANDIDATE",
568            informative=True,
569            interpretation=(
570                f"|alpha_t| = {abs(alpha_t):.2f} >= {alpha_gate:g}: the"
571                " residual after the factor betas is the finding"
572                f" (R2 = {r_squared:.2f}; dominant exposure"
573                f" {dominant_name} beta = {dominant_beta:.2f},"
574                f" t = {dominant_t:.2f})"
575            ),
576            next_step=(
577                "route the orthogonal residual to preregistration (§8)"
578                " -- the alpha is what survives the factor block"
579            ),
580            what_would_change=(
581                "alpha_t collapsing below the threshold under costs or"
582                " extra controls reclassifies the stream"
583                " (FACTOR_EXPOSURE if R2 holds, else RESIDUAL_WEAK)"
584            ),
585        )
586    if r_squared >= exposure_gate:
587        return FactorVerdict(
588            verdict="FACTOR_EXPOSURE",
589            informative=True,
590            interpretation=(
591                f"R2 = {r_squared:.2f} >= {exposure_gate:g} with"
592                f" |alpha_t| = {abs(alpha_t):.2f} < {alpha_gate:g}: the"
593                " stream IS the factor -- dominant exposure"
594                f" {dominant_name} (beta = {dominant_beta:.2f},"
595                f" t = {dominant_t:.2f})"
596            ),
597            next_step=(
598                "collect the factor: deploy as a factor exposure (or"
599                " run the packaging-vs-direct comparison, §18); do NOT"
600                " book it as alpha"
601            ),
602            what_would_change=(
603                "an orthogonal residual |alpha_t| >= threshold on a"
604                " longer sample upgrades the verdict to ALPHA_CANDIDATE"
605            ),
606        )
607    return FactorVerdict(
608        verdict="RESIDUAL_WEAK",
609        informative=False,
610        interpretation=(

612            f" {abs(alpha_t):.2f} < {alpha_gate:g}: neither factor nor"
613            " alpha -- the stream is noise on this alignment"
614        ),
615        next_step=(
616            "graveyard entry (§8): nothing here is collectable; stop"
617            " iterating on this stream"
618        ),
619        what_would_change=(
620            "a longer aligned sample or a different factor set that"
621            " lifts R2 (exposure) or |alpha_t| (alpha)"

626def construct_factor_proxies(
627    panel_returns: pd.DataFrame,
628    *,
629    betas: Mapping[str, float] | None = None,
630) -> dict[str, np.ndarray]:
631    """Build the honest proxy subset from a dates x symbols panel.
632
633    Constructs ``mkt`` (equal-weight mean of the row's finite symbols)
634    and ``bab_proxy`` (equal-weight mean of the LOW-beta leg minus the
635    HIGH-beta leg).  Betas are the caller's static ``betas`` mapping
636    when given, else a trailing 60-row estimate ``cov(sym, mkt) /
637    var(mkt)`` per symbol (the 60d convention); the rolling path
638    yields NaN for the first 59 rows (no trailing window yet -- honest
639    NaN, never a backfilled guess).  The median symbol of each split
640    joins the LOW leg; a row whose betas tie everywhere (no high leg)
641    reads NaN.  ``size_proxy`` is deliberately not constructed: a size
642    factor needs market-cap data the panel does not carry, and a
643    price-based stand-in would be a fabricated factor.
644
645    Args:
646        panel_returns: returns panel (rows = dates, columns = symbols);
647            NaN cells are excluded symbol-by-symbol from ``mkt`` and
648            poison any trailing window they touch.
649        betas: optional static mapping symbol -> beta used for the
650            low/high split instead of the trailing estimate; must cover
651            every panel column.
652
653    Returns:
654        ``{"mkt": ndarray, "bab_proxy": ndarray}`` aligned with the
655        panel's row order.
656
657    Raises:
658        ValueError: if ``panel_returns`` is not a DataFrame with at
659            least two columns and one row, or ``betas`` does not cover
660            every column with finite floats.
661
662    Example::
663
664        >>> import numpy as np
665        >>> import pandas as pd
666        >>> steps = np.arange(120, dtype=float)
667        >>> market = np.sin(steps / 10.0)
668        >>> panel = pd.DataFrame(
669        ...     {
670        ...         "lo_1": 0.30 * market,
671        ...         "lo_2": 0.40 * market,
672        ...         "hi_1": 1.60 * market,
673        ...         "hi_2": 1.90 * market + 0.01 * np.cos(steps / 7.0),
674        ...     }
675        ... )
676        >>> static = construct_factor_proxies(
677        ...     panel,
678        ...     betas={"lo_1": 0.3, "lo_2": 0.4, "hi_1": 1.6, "hi_2": 1.9},
679        ... )
680        >>> sorted(static)
681        ['bab_proxy', 'mkt']
682        >>> round(float(static["mkt"][0]), 4)
683        0.0025
684        >>> round(float(static["bab_proxy"][0]), 4)
685        -0.005
686        >>> rolled = construct_factor_proxies(panel)
687        >>> bool(np.isnan(rolled["bab_proxy"][:59]).all())
688        True
689        >>> bool(np.isnan(rolled["bab_proxy"][59]))
690        False
691    """
692    if not isinstance(panel_returns, pd.DataFrame):
693        raise ValueError(
694            "panel_returns must be a pandas DataFrame (dates x symbols),"
695            f" got {type(panel_returns).__name__}"
696        )
697    n_rows, n_cols = panel_returns.shape
698    if n_cols < 2:
699        raise ValueError(
700            "panel_returns needs at least 2 symbol columns for a"
701            f" cross-sectional split, got {n_cols}"
702        )
703    if n_rows < 1:
704        raise ValueError("panel_returns needs at least 1 row")
705    panel_arr = panel_returns.to_numpy(dtype=float)
706    present = np.isfinite(panel_arr)
707    counts = present.sum(axis=1)
708    mkt = np.full(n_rows, np.nan)
709    np.divide(
710        np.where(present, panel_arr, 0.0).sum(axis=1),
711        counts,
712        out=mkt,
713        where=counts > 0,
714    )
715    if betas is not None:
716        bab = _bab_from_betas(panel_arr, panel_returns.columns, betas)
717    elif n_rows >= _PROXY_WINDOW:
718        bab = _bab_from_trailing_betas(panel_arr, mkt)
719    else:
720        bab = np.full(n_rows, np.nan)
721    return {"mkt": mkt, "bab_proxy": bab}

724def _bab_from_betas(
725    panel_arr: np.ndarray,
726    columns: pd.Index,
727    betas: Mapping[str, float],
728) -> np.ndarray:
729    """Low-minus-high spread from the caller's static betas.
730
731    Every panel column must appear in ``betas`` with a finite float;
732    the median beta joins the LOW leg, an all-tie split reads NaN.
733    """
734    missing = [str(symbol) for symbol in columns if symbol not in betas]
735    if missing:
736        raise ValueError(
737            f"betas must cover every panel column; missing: {missing}"
738        )
739    beta_values = np.asarray(
740        [
741            validate_number(f"betas[{symbol!r}]", betas[symbol])
742            for symbol in columns
743        ],
744        dtype=float,
745    )
746    low_mask = beta_values <= float(np.median(beta_values))
747    high_mask = ~low_mask
748    if not low_mask.any() or not high_mask.any():
749        return np.full(panel_arr.shape[0], np.nan)
750    return panel_arr[:, low_mask].mean(axis=1) - panel_arr[:, high_mask].mean(
751        axis=1
752    )

755def _bab_from_trailing_betas(
756    panel_arr: np.ndarray, mkt: np.ndarray
757) -> np.ndarray:
758    """Low-minus-high spread from trailing 60-row betas vs ``mkt``.
759
760    Rows whose 60-row window is incomplete (the first 59), contains a
761    NaN cell or a zero-variance market window read NaN -- honest NaN,
762    never a backfilled guess.  The median beta of a row joins the LOW
763    leg; a fully-tied row (no high leg) reads NaN.
764    """
765    n_rows = panel_arr.shape[0]
766    # sliding_window_view appends the window axis LAST:
767    # win_panel is (windows, symbols, window), win_mkt (windows, window)
768    win_panel = sliding_window_view(panel_arr, _PROXY_WINDOW, axis=0)
769    win_mkt = sliding_window_view(mkt, _PROXY_WINDOW)
770    dev_panel = win_panel - win_panel.mean(axis=2, keepdims=True)
771    dev_mkt = win_mkt - win_mkt.mean(axis=1, keepdims=True)
772    covariances = (dev_panel * dev_mkt[:, None, :]).sum(axis=2) / (
773        _PROXY_WINDOW - 1
774    )
775    variances = (dev_mkt**2).sum(axis=1) / (_PROXY_WINDOW - 1)
776    beta_frame = covariances / variances[:, None]
777
778    bab = np.full(n_rows, np.nan)
779    for row in range(_PROXY_WINDOW - 1, n_rows):
780        beta_row = beta_frame[row - _PROXY_WINDOW + 1]
781        if not np.isfinite(beta_row).all():
782            continue
783        low_mask = beta_row <= float(np.median(beta_row))
784        high_mask = ~low_mask
785        if not low_mask.any() or not high_mask.any():
786            continue
787        bab[row] = float(panel_arr[row, low_mask].mean()) - float(
788            panel_arr[row, high_mask].mean()
789        )
790    return bab

349def factor_regression(
350    returns: Any,
351    factors: dict[str, Any],
352    *,
353    label: str = "unnamed",
354) -> FactorRegressionReport:
355    """OLS of a return stream on factor proxies (intercept + HC0).
356
357    Fits ``returns ~ intercept + factors`` with the shared ``ols_hc0``
358    (HC0 standard errors, t / p per column, R2, rank-deficiency flag --
359    the orthogonal check's conventions), after two collinearity screens
360    (pairwise ``|pearson| >= 0.95`` drops the later name; iterative VIF
361    drops the highest-VIF factor while any VIF exceeds 10).  Degenerate
362    factor columns (constant / all-NaN after alignment) are dropped
363    with a note.  ``alpha_mean`` is the intercept beta, ``alpha_t`` its
364    t-statistic: the mean and significance of the residual the factors
365    do not explain.
366
367    Args:
368        returns: the strategy's return / R stream (pandas or numpy 1-D
369            array-like), index/position-aligned with every factor by
370            the CALLER; the shared alignment still drops non-finite
371            rows.
372        factors: mapping factor name -> single column (Series or 1-D
373            array-like); insertion order fixes the design order.
374        label: free-text tag stored under ``report["label"]``.
375
376    Returns:
377        :class:`FactorRegressionReport`; ``status`` is ``OK`` only for
378        an identifiable design with ``n_obs >= 30`` (see the class
379        docstring for the INCONCLUSIVE causes).
380
381    Raises:
382        ValueError: if a factor value is not a single column.
383
384    Example::
385
386        >>> import numpy as np
387        >>> import pandas as pd
388        >>> rng = np.random.default_rng(11)
389        >>> mkt = rng.standard_normal(240)
390        >>> strategy = pd.Series(0.8 * mkt + 0.1 * rng.standard_normal(240))
391        >>> report = factor_regression(
392        ...     strategy, {"mkt": pd.Series(mkt)}, label="pure beta"
393        ... )
394        >>> report["status"], round(report["fit"]["beta"]["mkt"], 2)
395        ('OK', 0.8)
396        >>> round(report["r_squared"], 2) >= 0.97
397        True
398        >>> twin = factor_regression(
399        ...     strategy,
400        ...     {"mkt": pd.Series(mkt), "mkt_copy": pd.Series(2.0 * mkt)},
401        ...     label="collinear pair",
402        ... )
403        >>> list(twin["factors_dropped"]), twin["status"]
404        (['mkt_copy'], 'OK')
405    """
406    (
407        returns_arr,
408        usable_names,
409        usable_arrays,
410        dropped,
411        notes,
412    ) = _align_and_screen(returns, factors)
413    n_obs = int(returns_arr.size)
414
415    status = _OK
416    if n_obs == 0:
417        status = _INCONCLUSIVE
418        notes.append("no rows survived alignment - cannot fit any design")
419    elif _is_degenerate(returns_arr):
420        status = _INCONCLUSIVE
421        notes.append("returns stream is constant after alignment")
422    elif not usable_names:
423        status = _INCONCLUSIVE
424        notes.append(
425            "no usable factor columns survived the screens - attribution"
426            " is undecidable"
427        )
428
429    fit = _nan_fit_block()
430    r_squared = float("nan")
431    alpha_mean = float("nan")
432    alpha_t = float("nan")
433    if n_obs > 0 and usable_names and status == _OK:
434        design = np.column_stack([np.ones(n_obs), *usable_arrays])
435        payload = ols_hc0(returns_arr, design)
436        fit = _fit_block(payload, ["intercept", *usable_names])
437        r_squared = float(payload["r2"])
438        alpha_mean = float(payload["beta"][0])
439        alpha_t = float(payload["t"][0])
440        if bool(payload["rank_deficient"]) or not np.isfinite(r_squared):
441            status = _INCONCLUSIVE
442            notes.append(
443                "design is rank-deficient or saturated - statistics are"
444                " NaN and must not be read as evidence"
445            )
446    if status == _OK and n_obs < _MIN_OBS:
447        status = _INCONCLUSIVE
448        notes.append(
449            f"n_obs = {n_obs} < {_MIN_OBS} minimum - numbers carried"
450            " for inspection only, routing is forbidden"
451        )
452
453    return FactorRegressionReport(
454        label=label,
455        status=status,
456        n_obs=n_obs,
457        factors_used=usable_names,
458        factors_dropped=dropped,
459        fit=fit,
460        alpha_mean=alpha_mean,
461        alpha_t=alpha_t,
462        r_squared=r_squared,
463        notes=notes,
464    )

OLS of a return stream on factor proxies (intercept + HC0).

Fits returns ~ intercept + factors with the shared ols_hc0 (HC0 standard errors, t / p per column, R2, rank-deficiency flag -- the orthogonal check's conventions), after two collinearity screens (pairwise |pearson| >= 0.95 drops the later name; iterative VIF drops the highest-VIF factor while any VIF exceeds 10). Degenerate factor columns (constant / all-NaN after alignment) are dropped with a note. alpha_mean is the intercept beta, alpha_t its t-statistic: the mean and significance of the residual the factors do not explain.

Args: returns: the strategy's return / R stream (pandas or numpy 1-D array-like), index/position-aligned with every factor by the CALLER; the shared alignment still drops non-finite rows. factors: mapping factor name -> single column (Series or 1-D array-like); insertion order fixes the design order. label: free-text tag stored under report["label"].

Returns: FactorRegressionReport; status is OK only for an identifiable design with n_obs >= 30 (see the class docstring for the INCONCLUSIVE causes).

Raises: ValueError: if a factor value is not a single column.
