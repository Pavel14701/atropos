atropos.incremental_regression

Incremental (HC0-robust) regression: is a new signal anything NEW?

Two kill rules, deliberately different in strictness:

  • incremental_test() is the STRICT gate: one canonical controlled spec with a four-way verdict (full table in its docstring): SURVIVES (finite |t_new| >= 2), REPACKAGING-DEATH (controls present, |t_new| < 2 - the signal repackages what the controls already know), NULL-DEATH (no controls, |t_new| < 2
    • no detectable effect at all, nothing is being repackaged) and INCONCLUSIVE (degenerate full model: rank-deficient / saturated design, non-finite t_new, constant target, or no rows surviving the NaN alignment - unidentifiable, no evidence either way).
  • specification_curve() / curve_summary() are the BREADTH diagnostic: the curve spans control sets x rank / z-score / winsorized / demeaned transforms, and the signal dies only if NO spec in the grid reaches |t| >= 2. n_surviving_controlled counts the specs that survive WITH controls - a curve kept alive purely by uncontrolled specs is a repackaging flag even when the lenient verdict says SURVIVES. A spec whose model is unidentifiable (collinear design, zero-sd z-score, constant outcome, empty alignment) gets a per-spec verdict of INCONCLUSIVE; its non-finite t_new is excluded from the curve statistics instead of silently counting as a death.

p-values use the t distribution with df = n - k degrees of freedom -- an asymptotic approximation for HC0 standard errors, kept as the house convention.

Functions

incremental_test one canonical spec: controls vs controls + new signal. specification_curve grid of specs; returns a DataFrame with t_new and a per-spec verdict. curve_summary overall SURVIVES / REPACKAGING-DEATH call for the curve.

All pandas inputs are index-aligned (inner join); numpy inputs align by position. NaN rows are dropped pairwise; when NO row survives the drop, public functions return an honest INCONCLUSIVE instead of crashing or killing the hypothesis on zero observations.

Run python -m atropos.incremental_regression for a synthetic demo.

 80def _fit(
 81    target: np.ndarray, design: np.ndarray, robust: bool = True
 82) -> dict[str, Any]:
 83    """OLS fit; HC0 (``robust``) or classical (non-robust) standard errors.
 84
 85    The HC0 path delegates to :func:`atropos._utils.ols_hc0`; the
 86    classical path mirrors its identification contract: when the design
 87    is saturated (``n_rows <= n_cols``) or rank-deficient, every
 88    statistic is NaN and ``rank_deficient`` is True.  A pseudo-inverse
 89    alone would fabricate plausible-looking minimum-norm t-stats
 90    exactly in the collinear cases the library must flag, so callers
 91    must treat ``rank_deficient`` (or a non-finite ``t``) as
 92    INCONCLUSIVE, never as evidence for or against the hypothesis.
 93    """
 94    if robust:
 95        return ols_hc0(target, design)
 96    n_rows, n_cols = design.shape
 97    # Deliberate duplication of the rank gate in
 98    # atropos._utils.ols_hc0 (kept in sync by hand): the classical
 99    # path must return the SAME NaN-payload contract as the HC0 path,
100    # and the shared helper stays robust-only rather than growing a
101    # classical branch used solely by this caller.
102    if n_rows <= n_cols or np.linalg.matrix_rank(design) < n_cols:
103        nan_vector = np.full(n_cols, np.nan)
104        return {
105            "beta": nan_vector,
106            "se": nan_vector.copy(),
107            "t": nan_vector.copy(),
108            "p": nan_vector.copy(),
109            "df": max(n_rows - n_cols, 1),
110            "n": n_rows,
111            "r2": float("nan"),
112            "rank_deficient": True,
113        }
114    beta, _, _, _ = np.linalg.lstsq(design, target, rcond=None)
115    resid = target - design @ beta
116    xtx_inv = np.linalg.pinv(design.T @ design)
117    s2 = float(resid @ resid) / (n_rows - n_cols)
118    cov = s2 * xtx_inv
119    se = np.sqrt(np.maximum(np.diag(cov), 0.0))
120    with np.errstate(divide="ignore", invalid="ignore"):
121        t_stats = np.where(se > 0, beta / se, np.nan)
122    df = n_rows - n_cols
123    pvalues = 2.0 * stats.t.sf(np.abs(t_stats), df)
124    sst = float(np.sum((target - target.mean()) ** 2))
125    r2 = 1.0 - float(resid @ resid) / sst if sst > 0 else float("nan")
126    return {
127        "beta": np.asarray(beta, dtype=float),
128        "se": np.asarray(se, dtype=float),
129        "t": np.asarray(t_stats, dtype=float),
130        "p": np.asarray(pvalues, dtype=float),
131        "df": df,
132        "n": n_rows,
133        "r2": r2,
134        "rank_deficient": False,
135    }

138def _validate_winsor_pct(value: float, label: str) -> None:
139    """Reject ``winsor_pct`` outside the open interval (0, 0.5).
140
141    The winsorize transform clips to ``[quantile(p), quantile(1-p)]``;
142    at ``p >= 0.5`` those bounds invert (``lo > hi``) and ``np.clip``
143    silently collapses the signal onto the upper bound - a degenerate
144    transform that must fail loudly instead of fabricating a spec.
145    """
146    if not 0.0 < value < 0.5:
147        raise ValueError(
148            f"{label} must satisfy 0 < winsor_pct < 0.5, got {value}"
149            " (at >= 0.5 the winsorize quantile bounds invert)"
150        )
151
152
153def _transform_signal(
154    signal: np.ndarray, kind: str, winsor_pct: float
155) -> np.ndarray:
156    if kind == "raw":
157        return signal.copy()
158    if kind == "rank":
159        ranks: np.ndarray = stats.rankdata(signal, method="average")
160        return ranks / signal.size
161    if kind == "zscore":
162        sd = float(np.std(signal))
163        if sd > 0:
164            centered: np.ndarray = (signal - float(np.mean(signal))) / sd
165            return centered
166        # sd == 0 (constant signal): returning zeros would turn the
167        # spec into a regression on a constant - a dummy spec that
168        # silently changes the hypothesis.  NaN marks the spec as
169        # degenerate so callers report INCONCLUSIVE.
170        return np.full(signal.shape, np.nan)
171    if kind == "winsorize":
172        lo = float(np.quantile(signal, winsor_pct))
173        hi = float(np.quantile(signal, 1.0 - winsor_pct))
174        clipped: np.ndarray = np.clip(signal, lo, hi)
175        return clipped
176    if kind == "demean":
177        return signal - float(np.mean(signal))
178    raise ValueError(
179        f"unknown transform {kind!r}; expected one of {DEFAULT_TRANSFORMS}"
180    )

186def _inconclusive_result(robust: bool, n_obs: int = 0) -> dict[str, Any]:
187    """NaN payload with verdict INCONCLUSIVE for degenerate inputs.
188
189    ``n_obs`` is the aligned row count to report; it defaults to 0
190    (the historical empty-alignment case) so future callers cannot
191    accidentally report observations they never fitted.
192    """
193    return {
194        "t_new": float("nan"),
195        "delta_r2": float("nan"),
196        "verdict": _INCONCLUSIVE,
197        "coef_new": float("nan"),
198        "p_new": float("nan"),
199        "r2_restricted": float("nan"),
200        "r2_full": float("nan"),
201        "n": int(n_obs),
202        "robust": bool(robust),
203    }

206def incremental_test(
207    fwd_ret: Any,
208    known_controls_df: Any,
209    new_signal: Any,
210    robust: bool = True,
211) -> dict[str, Any]:
212    """Does the new signal add anything after the known controls?
213
214    Fits restricted ``fwd_ret ~ const + controls`` and full
215    ``fwd_ret ~ const + controls + new_signal``.  Verdict table:
216
217    * ``SURVIVES`` -- finite ``|t_new| >= 2`` in the full model.
218    * ``REPACKAGING-DEATH`` -- known controls are present (at least one
219      aligned control column) and ``|t_new| < 2``: the signal adds
220      nothing beyond what the controls already know; it is a
221      repackaging of known information.
222    * ``NULL-DEATH`` -- no controls (``known_controls_df=None`` or an
223      empty control set) and ``|t_new| < 2``: there is no detectable
224      effect at all - nothing is being repackaged, the signal is simply
225      null.
226    * ``INCONCLUSIVE`` -- the full model is degenerate and the test is
227      unidentifiable: rank-deficient / saturated design (e.g. the
228      signal is EXACTLY collinear with a control - a pseudo-inverse
229      would fabricate a plausible arbitrary ``t_new`` here), non-finite
230      ``t_new``, constant ``fwd_ret``, or an empty NaN alignment
231      (``n == 0``).  No evidence either way; do not treat as a kill.
232
233    Note: ``p``-values use the t distribution with ``df = n - k``
234    degrees of freedom -- an asymptotic approximation when HC0 robust
235    standard errors are used, kept as the house convention.
236
237    Returns ``{t_new, delta_r2, verdict, coef_new, p_new, r2_restricted,
238    r2_full, n, robust}``; degenerate cases return NaN statistics with
239    ``verdict="INCONCLUSIVE"``.
240
241    Example::
242
243        >>> rng = np.random.default_rng(0)  # doctest: +SKIP
244        >>> n = 800  # doctest: +SKIP
245        >>> c = rng.standard_normal((n, 2))  # doctest: +SKIP
246        >>> z = rng.standard_normal(n)  # doctest: +SKIP
247        >>> y = (0.3 * z + 0.5 * c[:, 0]  # doctest: +SKIP
248        ...      + rng.standard_normal(n))
249        >>> ctrl = pd.DataFrame(c, columns=["c0", "c1"])  # doctest: +SKIP
250        >>> incremental_test(y, ctrl, z)["verdict"]  # doctest: +SKIP
251        'SURVIVES'
252    """
253    if known_controls_df is None:
254        outcome, sig = align_inputs(fwd_ret, new_signal)
255        controls = np.empty((outcome.size, 0))
256    else:
257        outcome, sig, controls = align_inputs(
258            fwd_ret, new_signal, known_controls_df
259        )
260        if controls.ndim == 1:
261            controls = controls.reshape(-1, 1)
262
263    has_controls = controls.shape[1] > 0
264    if outcome.size == 0:
265        # nothing survived the NaN alignment: honest INCONCLUSIVE
266        # instead of a crash or a silent zero-row kill
267        return _inconclusive_result(robust, n_obs=int(outcome.size))
268
269    if has_controls:
270        design_reduced = np.column_stack([np.ones(outcome.size), controls])
271        design_full = np.column_stack([np.ones(outcome.size), sig, controls])
272    else:
273        design_reduced = np.ones((outcome.size, 1))
274        design_full = np.column_stack([np.ones(outcome.size), sig])
275
276    res_r = _fit(outcome, design_reduced, robust=robust)
277    res_f = _fit(outcome, design_full, robust=robust)
278    t_new = float(res_f["t"][1])
279    p_new = float(res_f["p"][1])
280    delta_r2 = float(res_f["r2"] - res_r["r2"])
281    constant_target = float(np.ptp(outcome)) == 0.0
282    if (
283        bool(res_f["rank_deficient"])
284        or not np.isfinite(t_new)
285        or constant_target
286    ):
287        verdict = _INCONCLUSIVE
288    elif abs(t_new) >= _T_RULE:
289        verdict = _SURVIVES
290    else:
291        verdict = _DEATH if has_controls else _NULL_DEATH
292    return {
293        "t_new": t_new,
294        "delta_r2": delta_r2,
295        "verdict": verdict,
296        "coef_new": float(res_f["beta"][1]),
297        "p_new": p_new,
298        "r2_restricted": float(res_r["r2"]),
299        "r2_full": float(res_f["r2"]),
300        "n": int(outcome.size),
301        "robust": bool(robust),
302    }

308def _resolve_controls(
309    controls_index: Any, controls_list: list[Any], spec_no: int
310) -> Any:
311    """Map a spec's ``controls`` key to a control set or None.
312
313    ``None`` means no controls; a valid integer indexes
314    ``controls_list``.  Anything else - out-of-range, negative, boolean
315    or non-integer values - raises ``ValueError``: silently falling
316    back to an uncontrolled specification would quietly change the
317    hypothesis being tested.
318    """
319    if controls_index is None:
320        return None
321    if (
322        isinstance(controls_index, int)
323        and not isinstance(controls_index, bool)
324        and 0 <= controls_index < len(controls_list)
325    ):
326        return controls_list[controls_index]
327    raise ValueError(
328        f"spec {spec_no}: controls={controls_index!r} is not a valid "
329        f"index into controls_list (len={len(controls_list)}); use "
330        "None for no controls or an in-range integer index"
331    )
332

334def specification_curve(
335    fwd_ret: Any,
336    controls_list: Any,
337    signal: Any,
338    *,
339    specs_to_try: list[dict[str, Any]] | None = None,
340    robust: bool = True,
341    winsor_pct: float = 0.01,
342) -> pd.DataFrame:
343    """Table of ``t_new`` across a grid of reasonable specifications.
344
345    Parameters
346    ----------
347    controls_list : list of control sets; each entry is a DataFrame /
348        (n, m) array (or None).  A spec references one entry by integer
349        index, or ``None`` for no controls; an out-of-range or
350        non-integer index raises ``ValueError`` (a mistyped index must
351        not silently become an uncontrolled spec).
352    specs_to_try : list of ``{"controls": int | None, "transform": str,
353        "winsor_pct": float}`` dicts.  ``transform`` is one of
354        ``raw | rank | zscore | winsorize | demean``.  When None, the
355        full grid ``transforms x (None + each control set)`` is used.
356    robust, winsor_pct : keyword-only tuning knobs shared by every
357        spec.  ``winsor_pct`` (top level and per spec) must satisfy
358        ``0 < winsor_pct < 0.5``, else ``ValueError``: at ``>= 0.5``
359        the winsorize quantile bounds invert and the clip degenerates.
360
361    Per-spec verdicts are ``SURVIVES`` / ``REPACKAGING-DEATH`` by the
362    ``|t_new| >= 2`` rule, or ``INCONCLUSIVE`` when the spec's full
363    model is unidentifiable (rank-deficient / saturated design,
364    degenerate transform such as a zero-sd z-score, constant outcome,
365    or empty NaN alignment); degenerate specs carry a NaN ``t_new``
366    which :func:`curve_summary` excludes from the curve statistics.
367
368    The kill rule: if ``max |t_new| < 2`` across every spec in the curve,
369    the signal is a repackaging and the hypothesis dies
370    (see :func:`curve_summary`).
371
372    Example::
373
374        >>> rng = np.random.default_rng(0)  # doctest: +SKIP
375        >>> n = 800  # doctest: +SKIP
376        >>> y = rng.standard_normal(n)  # doctest: +SKIP
377        >>> z = rng.standard_normal(n)  # doctest: +SKIP
378        >>> c = rng.standard_normal(n)  # doctest: +SKIP
379        >>> ctrl = [pd.DataFrame({"c": c})]  # doctest: +SKIP
380        >>> table = specification_curve(y, ctrl, z)  # doctest: +SKIP
381        >>> set(table.columns) >= {"t_new", "verdict"}  # doctest: +SKIP
382        True
383    """
384    controls_list = list(controls_list) if controls_list is not None else []
385    _validate_winsor_pct(float(winsor_pct), "winsor_pct")
386    if specs_to_try is None:
387        specs_to_try = [
388            {
389                "controls": ctrl_idx,
390                "transform": transform,
391                "winsor_pct": winsor_pct,
392            }
393            for transform in DEFAULT_TRANSFORMS
394            for ctrl_idx in [None, *range(len(controls_list))]
395        ]
396
397    rows: list[dict[str, Any]] = []
398    for spec_no, spec in enumerate(specs_to_try):
399        sp = dict(spec)
400        ci = sp.get("controls")
401        tr = sp.get("transform", "raw")
402        wp = float(sp.get("winsor_pct", winsor_pct))
403        _validate_winsor_pct(wp, f"spec {spec_no}: winsor_pct")
404        ctrl = _resolve_controls(ci, controls_list, spec_no)
405
406        if ctrl is None:
407            outcome, sig = align_inputs(fwd_ret, signal)
408            controls = np.empty((outcome.size, 0))
409        else:
410            outcome, sig, controls = align_inputs(fwd_ret, signal, ctrl)
411            if controls.ndim == 1:
412                controls = controls.reshape(-1, 1)
413
414        sig_t = _transform_signal(sig, tr, wp)
415        row: dict[str, Any] = {
416            "spec": spec_no,
417            "transform": tr,
418            "controls": "none" if ctrl is None else f"set{ci}",
419            "n": int(outcome.size),
420        }
421        if (
422            outcome.size == 0
423            or not np.isfinite(sig_t).all()
424            or float(np.ptp(outcome)) == 0.0
425        ):
426            # degenerate spec (empty alignment, constant signal after
427            # the transform, or constant outcome): honest INCONCLUSIVE
428            # row, never a fabricated death
429            row.update(
430                t_new=float("nan"),
431                p_new=float("nan"),
432                delta_r2=float("nan"),
433                verdict=_INCONCLUSIVE,
434            )
435            rows.append(row)
436            continue
437        if controls.shape[1] > 0:
438            design_full = np.column_stack(
439                [np.ones(outcome.size), sig_t, controls]
440            )
441            design_reduced = np.column_stack(
442                [np.ones(outcome.size), controls]
443            )
444        else:
445            design_full = np.column_stack([np.ones(outcome.size), sig_t])
446            design_reduced = np.ones((outcome.size, 1))
447
448        res_f = _fit(outcome, design_full, robust=robust)
449        res_r = _fit(outcome, design_reduced, robust=robust)
450        t_new = float(res_f["t"][1])
451        if bool(res_f["rank_deficient"]) or not np.isfinite(t_new):
452            spec_verdict = _INCONCLUSIVE
453        else:
454            spec_verdict = _SURVIVES if abs(t_new) >= _T_RULE else _DEATH
455        row.update(
456            t_new=t_new,
457            p_new=float(res_f["p"][1]),
458            delta_r2=float(res_f["r2"] - res_r["r2"]),
459            verdict=spec_verdict,
460        )
461        rows.append(row)
462    return pd.DataFrame(rows)

465def curve_summary(spec_table: pd.DataFrame) -> dict[str, Any]:
466    """Overall SURVIVES / REPACKAGING-DEATH call for a specification curve.
467
468    The rule (lenient by design - the strict gate is
469    :func:`incremental_test`): if NO reasonable spec pushes
470    ``|t_new| >= 2``, the signal is a repackaging of known information ->
471    death.  ``n_surviving_controlled`` additionally counts the specs that
472    survive WITH known controls in the model; 0 surviving controlled
473    specs means the curve is kept alive by uncontrolled specs only - a
474    repackaging flag even when the verdict says SURVIVES.  A spec curve
475    where specs flip sign is reported via ``sign_consistent``.
476
477    ``sign_consistent`` is judged on the NONZERO t-values: an exact 0.0
478    t-stat carries no sign information (``np.sign(0.0) == 0.0`` would
479    otherwise force any curve containing one to look inconsistent), so
480    zeros are ignored and a curve with no nonzero t at all is trivially
481    consistent.
482
483    Non-finite ``t_new`` entries (degenerate specs, see
484    :func:`specification_curve`) are excluded from every statistic.
485
486    Example::
487
488        >>> table = specification_curve(y, ctrl_sets, z)   # doctest: +SKIP
489        >>> curve_summary(table)["verdict"]                # doctest: +SKIP
490        'SURVIVES'
491    """
492    t_vals = spec_table["t_new"].to_numpy(dtype=float)
493    finite = np.isfinite(t_vals)
494    t_vals = t_vals[finite]
495    n_specs = int(t_vals.size)
496    max_abs_t = float(np.max(np.abs(t_vals))) if n_specs else float("nan")
497    min_abs_t = float(np.min(np.abs(t_vals))) if n_specs else float("nan")
498    n_surviving = int(np.sum(np.abs(t_vals) >= _T_RULE)) if n_specs else 0
499    controls_col = (
500        spec_table["controls"].to_numpy()
501        if "controls" in spec_table.columns
502        else np.full(len(spec_table), "none", dtype=object)
503    )
504    controlled = (
505        (controls_col != "none")
506        & finite
507        & (np.abs(spec_table["t_new"].to_numpy(dtype=float)) >= _T_RULE)
508    )
509    n_surviving_controlled = int(np.sum(controlled))
510    nonzero_t = t_vals[t_vals != 0.0]
511    sign_consistent = bool(
512        n_specs > 0
513        and (
514            nonzero_t.size == 0
515            or np.all(np.sign(nonzero_t) == np.sign(nonzero_t[0]))
516        )
517    )
518    verdict = _SURVIVES if (n_specs > 0 and max_abs_t >= _T_RULE) else _DEATH
519    return {
520        "verdict": verdict,
521        "n_specs": n_specs,
522        "n_surviving": n_surviving,
523        "n_surviving_controlled": n_surviving_controlled,
524        "max_abs_t": max_abs_t,
525        "min_abs_t": min_abs_t,
526        "sign_consistent": sign_consistent,
527        "t_rule": _T_RULE,
