atropos.ensemble_pipeline

Ensemble pipeline: one call that chains every hypothesis-killing module.

run_full_pipeline() feeds a candidate signal through up to seven adversarial stages, in increasing order of cost, and KILLS the candidate the moment any stage fails (remaining stages are reported as SKIPPED and never run):

  1. null_control_suite 6 null controls (permutation, placebo events, momentum, known features, subperiod concentration, calendar fixed effects).
  2. incremental_regression specification curve - does ANY reasonable spec keep |t| >= 2?
  3. robustness_battery 7-test mechanical-trading battery (threshold / window sensitivity, subperiods, leave-one-out, placebo lag, declustering, monotonicity).
  4. walkforward_framework expanding-window walk-forward with anti-peeking enforcement.
  5. monte_carlo block-bootstrap distributions of Sharpe and max drawdown of the threshold rule NET OF TRANSACTION COSTS (proportional one-way cost per unit turnover, atropos.cost_model).
  6. predictive_model_eval purged K-fold CV, rolling walk-forward OOS, feature-importance stability, sign consistency by regime, deflated Sharpe. The regression model is configurable: "ols" (default), "knn", "kernel" (Nadaraya-Watson) or any callable factory (e.g. an sklearn wrapper) via config["model"].
  7. cross_sectional optional panel stage (runs when the data carries panel_signal / panel_returns DataFrames): per-date cross-sectional IC, net-of-cost quantile long-short spread, quantile monotonicity.

Decision tree (first FAIL decides; stage 0 is the degenerate-feed pre-flight that runs BEFORE any stage, before the aligner's row drop can mask a degenerate column with a generic size error):

  • pre-flight: signal or returns is empty / all-NaN / constant (zero peak-to-peak) -> DEGENERATE_FEED
  • stage 1, momentum / known-features control fails -> REPACKAGING (a routing verdict: the signal is a view of a known premium - compare the packaging against the direct factor implementation)
  • stage 1, other controls fail -> ARTIFACT
  • stage 2 curve death -> REPACKAGING (same routing verdict; a curve SURVIVES call backed by fewer than 5 testable specs is INCONCLUSIVE - a WARN, not a pass)
  • stage 3 battery OVERALL DEAD (the baseline rule itself is catastrophic or never trades - no active days) -> DEAD
  • stage 3 FRAGILE driven by the placebo_lag row (its ONLY failing attack) -> PLACEBO_VIOLATION
  • stage 3 FRAGILE, any other failing book (fewer than 5/7 tests passed: ROBUSTNESS-DEATH) -> ROBUSTNESS_DEATH
  • stage 4 walk-forward FAIL, shrinkage over the cap (OVERFIT_DEATH marker) -> OVERFIT_DEATH
  • stage 4 walk-forward model emitted (numerically) constant OOS predictions (preds_std below 1e-12 or non-finite) -> CONSTANT_PREDICTIONS
  • stage 4 walk-forward FAIL (weak OOS edge only) -> NO_OOS_EDGE
  • stage 4 walk-forward cannot run (the configuration exceeds the aligned data) -> INCONCLUSIVE
  • stage 5 drawdown-tail breach, or a Sharpe-floor breach that persists gross of costs -> RISK
  • stage 5 net-of-cost Sharpe floor breach ONLY (the gross envelope passes, drawdown tail intact), or the same net breach with the stage-5 breakeven gate fired (cost_bps >= breakeven, drawdown tail intact) -> COST_DEATH
  • stage 6 OOS evaluation fail -> NO_OOS_EDGE
  • stage 7 cross-sectional tests fail -> CS_NO_EDGE
  • panel-only mode: stage 7 passes, no warnings -> SURVIVES_CS_ONLY
  • panel-only mode: stage 7 passes, some warnings -> SURVIVES_CS_ONLY_WITH_WARNINGS
  • all series stages pass, no warnings -> SURVIVES
  • all series stages pass, some warnings -> SURVIVES_WITH_WARNINGS

A plain SURVIVES means EVERY executed attack missed; when only the cross-sectional stage ran (panel-only mode), the verdict says so (SURVIVES_CS_ONLY / SURVIVES_CS_ONLY_WITH_WARNINGS) instead of borrowing the stronger all-stages label.

Verdict metadata layer: every report carries verdict_class, informative, interpretation, next_step, what_would_change, failed_test and active_days alongside the verdict token. verdict_class takes exactly four values: DEAD (ONLY a battery OVERALL DEAD - a proven no-edge baseline - and a CS_NO_EDGE when config target == "xs"), NEEDS_ANALYSIS (every other kill: the finding is live and analysable), INCONCLUSIVE and SURVIVES (the whole survives family, CS-only forms included). informative is False ONLY for DEGENERATE_FEED / CONSTANT_PREDICTIONS / INCONCLUSIVE (the signal was not tested, so the run says nothing about it); every other kill and every survival is informative. interpretation / next_step / what_would_change are FILLED strings quoting this run's facts (n_obs, active days, failed battery rows and their stats, the shrink ratio that fired a gate) - never bare templates; failed_test is the comma-joined names of the FAILing battery rows (battery kills only) or None; active_days counts finite non-zero returns.

Input data keys: returns (per-period forward returns the signal is supposed to predict), signal (same index), optional features (DataFrame of known controls), optional mom7 / mom30 (observed 7d/30d momentum factors; fallback: trailing sums of past returns), optional hypothesis (description string). Panel mode: panel_signal / panel_returns DataFrames (rows = dates, columns = assets) enable stage 7; they may be supplied alone (stages 1-6 are then SKIPPED: panel-only mode, verdict SURVIVES_CS_ONLY) or together with the series inputs.

Run python -m atropos.ensemble_pipeline for the thirteen synthetic verification cases: a genuine edge must SURVIVE; a SLOW genuine edge (smoothed driver) must SURVIVE - the battery passes slow-robust edges (9/10 swept seeds); a momentum echo must die as REPACKAGING; an edge concentrated in the first third of the sample is caught by the OOS evaluation as NO_OOS_EDGE (its single stage-1 concentration FAIL is only a WARN under ATR-12); a genuine edge behind an unreachable entry threshold must die as DEAD (battery OVERALL DEAD); the slow class on the sweep's seed 7 reads a FRAGILE battery and must die as ROBUSTNESS_DEATH; the stage-4 shrink gate fired by a canned walk-forward must die as OVERFIT_DEATH; a constant (zero-variance) signal feed must stop at the pre-flight as DEGENERATE_FEED; a genuine edge under prohibitive costs must die as COST_DEATH; a genuine edge under a strict drawdown mandate must die as RISK; a genuine cross-sectional panel must report SURVIVES_CS_ONLY (only the cross-sectional attack ran); a thin panel must report SURVIVES_CS_ONLY_WITH_WARNINGS; a pure-noise panel must die as CS_NO_EDGE. ARTIFACT, INCONCLUSIVE, PLACEBO_VIOLATION and CONSTANT_PREDICTIONS are the four verdicts without a demo case: ARTIFACT needs two independent stage-1 rejections with clean factor controls (ATR-12; no honest synthetic reaches it), INCONCLUSIVE needs a walk-forward configuration that outgrows the data, and the stage-3 placebo row and the stage-4 constant-prediction gate cannot be hit by an honest synthetic - all four are pinned with canned/patched worlds in tests/test_ensemble_pipeline.py.

 679def _is_degenerate(values: np.ndarray) -> bool:
 680    """True when a feed array cannot carry any statistical test.
 681
 682    Degenerate means one of: empty; all-NaN; no finite entry; or a
 683    zero peak-to-peak range over the finite slice (a constant feed,
 684    e.g. a paused leg or a degenerate threshold on a dominant ternary
 685    signal).  This is the DEGENERATE_FEED pre-flight predicate: it
 686    runs BEFORE :func:`_align_inputs`, whose NaN row drop would turn
 687    an all-NaN column into a generic "too few observations" error and
 688    mask the diagnosable feed problem.
 689    """
 690    arr = np.asarray(values, dtype=float).reshape(-1)
 691    if arr.size == 0:
 692        return True
 693    if np.all(np.isnan(arr)):
 694        return True
 695    finite = arr[np.isfinite(arr)]
 696    if finite.size == 0:
 697        return True
 698    return bool(np.ptp(finite) == 0.0)

 727def _align_inputs(data: dict[str, Any]) -> tuple[dict[str, Any], int]:
 728    """Index-align every input (inner join, NaN rows dropped).
 729
 730    Returns ``{"returns", "signal", "mom7", "mom30", "features",
 731    "panel_signal", "panel_returns"}`` where the series entries are Series /
 732    DataFrames sharing one index (or ``None`` in panel-only mode) and the
 733    panel entries are the raw DataFrames (or ``None`` when absent), plus the
 734    aligned observation count (panel dates in panel-only mode).
 735    """
 736    panel_signal = data.get("panel_signal")
 737    panel_returns = data.get("panel_returns")
 738    has_panel = isinstance(panel_signal, pd.DataFrame) and isinstance(
 739        panel_returns, pd.DataFrame
 740    )
 741    ret = data.get("returns")
 742    sig = data.get("signal")
 743    if ret is None or sig is None:
 744        if not has_panel or panel_signal is None or panel_returns is None:
 745            raise ValueError(
 746                "data must contain 'returns' and 'signal' series "
 747                "(or 'panel_signal' and 'panel_returns' DataFrames)"
 748            )
 749        # panel-only mode: no single-series stages.  The >= 300 floor
 750        # below deliberately does NOT apply here: it guards the series
 751        # stages (battery / walk-forward / block bootstrap need that many
 752        # rows of a single history), while panel evidence scales with
 753        # dates x assets and stage 7 enforces its own per-date
 754        # ``min_assets`` floor instead.
 755        return {
 756            "returns": None,
 757            "signal": None,
 758            "mom7": None,
 759            "mom30": None,
 760            "features": None,
 761            "panel_signal": panel_signal,
 762            "panel_returns": panel_returns,
 763        }, len(panel_signal.index)
 764    if not isinstance(ret, pd.Series):
 765        ret = pd.Series(np.asarray(ret, dtype=float).reshape(-1))
 766    if not isinstance(sig, pd.Series):
 767        sig = pd.Series(
 768            np.asarray(sig, dtype=float).reshape(-1), index=ret.index
 769        )
 770
 771    def _ser(value: Any) -> pd.Series:
 772        if isinstance(value, pd.Series):
 773            return value.astype(float)
 774        return pd.Series(
 775            np.asarray(value, dtype=float).reshape(-1), index=ret.index
 776        )
 777
 778    feats_df = data.get("features")
 779    feat_series: dict[str, pd.Series] = {}
 780    if isinstance(feats_df, pd.DataFrame) and feats_df.shape[1] > 0:
 781        for column in feats_df.columns:
 782            feat_series[f"__f::{column}"] = feats_df[column].astype(float)
 783
 784    mom7_in, mom30_in = data.get("mom7"), data.get("mom30")
 785    # fallback: trailing sums of PAST returns only (shift(1) -> no lookahead)
 786    mom7 = (
 787        _ser(mom7_in)
 788        if mom7_in is not None
 789        else ret.astype(float).shift(1).rolling(7).sum()
 790    )
 791    mom30 = (
 792        _ser(mom30_in)
 793        if mom30_in is not None
 794        else ret.astype(float).shift(1).rolling(30).sum()
 795    )
 796
 797    pieces: dict[str, pd.Series] = {
 798        "__returns": ret.astype(float),
 799        "__signal": sig.astype(float),
 800        "__mom7": mom7,
 801        "__mom30": mom30,
 802    }
 803    pieces.update(feat_series)
 804    comb = pd.concat(pieces.values(), axis=1, join="inner")
 805    comb.columns = list(pieces.keys())
 806    comb = comb.dropna()
 807    n_obs = len(comb)
 808    if n_obs < 300:
 809        raise ValueError(
 810            f"need >= 300 aligned observations after dropna, got {n_obs}"
 811        )
 812
 813    feat_cols = [
 814        column for column in comb.columns if column.startswith("__f::")
 815    ]
 816    if feat_cols:
 817        features = comb[feat_cols].rename(columns=lambda column: column[5:])
 818    else:
 819        features = pd.DataFrame(
 820            {"mom7": comb["__mom7"], "mom30": comb["__mom30"]}
 821        )
 822    aligned = {
 823        "returns": comb["__returns"],
 824        "signal": comb["__signal"],
 825        "mom7": comb["__mom7"],
 826        "mom30": comb["__mom30"],
 827        "features": features,
 828        "panel_signal": panel_signal if has_panel else None,
 829        "panel_returns": panel_returns if has_panel else None,
 830    }
 831    return aligned, n_obs

 837def _stage_1_null_controls(
 838    al: dict[str, Any], cfg: dict[str, Any]
 839) -> dict[str, Any]:
 840    """Six adversarial null controls on the aligned signal/returns."""
 841    seed = int(cfg["seed"])
 842    draws = int(cfg["n_perm_draws"])
 843    ret, sig = al["returns"], al["signal"]
 844    n_obs = len(ret)
 845    results: dict[str, dict[str, Any]] = {}
 846    results["shuffled_permutation"] = shuffled_permutation(
 847        sig, ret, n_draws=draws, seed=seed
 848    )
 849
 850    k_events = max(
 851        20, round((1.0 - float(cfg["placebo_top_quantile"])) * n_obs)
 852    )
 853    event_pos = np.argsort(sig.to_numpy(dtype=float))[-k_events:]
 854    results["placebo_placebo"] = placebo_placebo(
 855        event_pos, ret, n_draws=draws, seed=seed + 1
 856    )
 857
 858    results["momentum_control"] = momentum_control(
 859        ret, sig, al["mom7"], al["mom30"]
 860    )
 861    results["known_features_control"] = known_features_control(
 862        ret, sig, al["features"]
 863    )
 864
 865    daily_ev = sig.to_numpy(dtype=float) * ret.to_numpy(dtype=float)
 866    results["subperiod_stability"] = subperiod_stability(
 867        daily_ev, periods=3, n_perm=draws, seed=seed + 2
 868    )
 869
 870    idx = ret.index
 871    years = (
 872        idx.year.to_numpy()
 873        if isinstance(idx, pd.DatetimeIndex)
 874        else np.arange(n_obs) // 250
 875    )
 876    # drop_first avoids the dummy trap: calendar_control's design already
 877    # carries an intercept, so a FULL one-hot year set is exactly
 878    # collinear with it (rank-deficient -> INCONCLUSIVE).  Dropping one
 879    # category spans the same column space and leaves the signal's
 880    # t-stat identical.
 881    year_dummies = pd.get_dummies(years, drop_first=True).to_numpy(
 882        dtype=float
 883    )
 884    results["calendar_control"] = calendar_control(ret, sig, year_dummies)
 885
 886    failed = [
 887        name
 888        for name, result in results.items()
 889        if result["verdict"] == "FAIL"
 890    ]
 891    repackaging = bool(failed) and any(
 892        name in failed
 893        for name in ("momentum_control", "known_features_control")
 894    )
 895    # rank-deficient controls (signal exactly collinear with a control)
 896    # are neither a pass nor a kill: they could not be tested
 897    inconclusive = [
 898        name
 899        for name, result in results.items()
 900        if result["verdict"] == "INCONCLUSIVE"
 901    ]
 902    # ATR-12: null-control hierarchy — one FAIL flags (WARN), two or
 903    # more independent rejections kill.  A single false positive at
 904    # alpha=0.05 across 6 controls is expected by chance (~26%); two
 905    # simultaneous rejections are unlikely enough to warrant a kill.
 906    status = (
 907        "FAIL"
 908        if len(failed) >= 2
 909        else ("WARN" if failed or inconclusive else "PASS")
 910    )
 911    summary = f"{len(results) - len(failed)}/6 controls passed"
 912    if failed:
 913        summary += f"; failed: {', '.join(failed)}"
 914    if inconclusive:
 915        summary += (
 916            f"; inconclusive (collinear, untested): {', '.join(inconclusive)}"
 917        )
 918    return {
 919        "stage": 1,
 920        "name": _STAGE_NAMES[1],
 921        "status": status,
 922        "summary": summary,
 923        "results": results,
 924        "repackaging": repackaging,
 925    }

 928def _stage_2_specification_curve(
 929    al: dict[str, Any], _cfg: dict[str, Any]
 930) -> dict[str, Any]:
 931    """Specification curve: 5 transforms x {none, known-features} controls.
 932
 933    ``_cfg`` (the merged config) is accepted for call-site symmetry with
 934    the other stage functions; the stage is intentionally not
 935    configurable - the 5 x 2 specification lattice is fixed by design so
 936    that every candidate faces exactly the same curve.
 937
 938    Trust conditions on top of the lenient curve verdict:
 939
 940    * at least one CONTROLLED spec must survive, otherwise the curve is
 941      kept alive by uncontrolled specs only (repackaging of known
 942      information) -> FAIL;
 943    * at least 5 testable specs must reach the summary at all: taking
 944      the max over 1-4 specs is a multiple search too small to trust,
 945      so a SURVIVES call on a thin curve is downgraded to INCONCLUSIVE
 946      (WARN, not a kill - the evidence cannot decide) instead of PASS.
 947    """
 948    table = specification_curve(
 949        al["returns"], [al["features"]], al["signal"], robust=True
 950    )
 951    cs = curve_summary(table)
 952    n_specs = int(cs["n_specs"])
 953    if cs["verdict"] == "SURVIVES" and n_specs < _MIN_CURVE_SPECS:
 954        # thin curve: max-of-few-specs is not evidence - INCONCLUSIVE,
 955        # never a silent pass
 956        return {
 957            "stage": 2,
 958            "name": _STAGE_NAMES[2],
 959            "status": "WARN",
 960            "summary": (
 961                f"INCONCLUSIVE: only {n_specs} testable specs "
 962                f"(< {_MIN_CURVE_SPECS}) reach the summary - max|t|="
 963                f"{cs['max_abs_t']:.2f} over so few specs is a multiple "
 964                "search too small to trust; the SURVIVES call is not "
 965                "treated as a pass"
 966            ),
 967            "results": {"curve_summary": cs, "spec_table": table},
 968        }
 969    # the lenient curve verdict is not enough: at least one CONTROLLED
 970    # spec must survive, otherwise the curve is kept alive by
 971    # uncontrolled specs only (repackaging of known information)
 972    status = (
 973        "PASS"
 974        if cs["verdict"] == "SURVIVES"
 975        and int(cs["n_surviving_controlled"]) >= 1
 976        else "FAIL"
 977    )
 978    summary = (
 979        f"{cs['verdict']}: max|t|={cs['max_abs_t']:.2f} across "
 980        f"{n_specs} specs ({cs['n_surviving']} with |t|>=2, "
 981        f"{cs['n_surviving_controlled']} controlled, "
 982        f"sign_consistent={cs['sign_consistent']})"
 983    )
 984    return {
 985        "stage": 2,
 986        "name": _STAGE_NAMES[2],
 987        "status": status,
 988        "summary": summary,
 989        "results": {"curve_summary": cs, "spec_table": table},
 990    }

1020    overall = battery_overall(table)

1022        table.loc[~table["test"].isin(["OVERALL", "baseline"]), "verdict"]
1023        .eq("PASS")
1024        .sum()
1025    )
1026    # FRAGILE is a KILL, not a warning: the doctrine (FRAMEWORK.md,
1027    # ROBUSTNESS-DEATH) stops the candidate when fewer than 5 of 7
1028    # battery tests pass -- a stage status softer than the doctrine
1029    # would let sub-5/7 books through on a warning (ATR-04).
1030    status = {"ROBUST": "PASS", "FRAGILE": "FAIL", "DEAD": "FAIL"}[overall]
1031    summary = (
1032        f"{overall}: {n_pass}/7 tests passed "
1033        f"(baseline threshold={threshold:.3f})"
1034    )
1035    return {
1036        "stage": 3,
1037        "name": _STAGE_NAMES[3],
1038        "status": status,
1039        "summary": summary,
1040        "results": {
1041            "battery_table": table,
1042            "overall": overall,
1043            "threshold_used": threshold,
1044        },
1045    }

1048def _stage_4_walkforward(
1049    al: dict[str, Any], cfg: dict[str, Any]
1050) -> dict[str, Any]:
1051    """Expanding-window walk-forward with anti-peeking enforcement.
1052
1053    Verdict mapping: PASS -> PASS, DEGRADED -> WARN, FAIL -> FAIL and
1054    INCONCLUSIVE -> INCONCLUSIVE (a shrinkage-NaN walk-forward cannot
1055    hand out a tier).  The walk-forward's ``verdict_reason`` is carried
1056    through verbatim (it marks OVERFIT_DEATH or the shrinkage-NaN
1057    cause) so the caller can classify without recomputing; when set it
1058    is also appended to the summary.
1059
1060    CONSTANT_PREDICTIONS gate (taxonomy): a ``preds_std`` (std of the
1061    union OOS predictions, reported by the framework) that is
1062    non-finite or below ``_CONSTANT_PREDS_STD_FLOOR`` means the model
1063    emitted (numerically) a single prediction - the sign rule carried
1064    no information, so the run is marked FAIL with
1065    ``results["constant_predictions"] = True`` and the orchestrator
1066    kills as CONSTANT_PREDICTIONS (the signal was not tested).  An
1067    INCONCLUSIVE walk-forward verdict is surfaced unchanged and is
1068    never reclassified by this gate: undecided beats the gate.
1069
1070    A :class:`ValueError` whose message marks a capacity the data
1071    cannot carry (``"too small"``: not enough rows for even one fold)
1072    is INCONCLUSIVE, not a FAIL (ATR-06) -- the configuration did not
1073    fit, which says nothing about the edge.  Any other walk-forward
1074    rejection is a caller/config error (bad window sizes, negative
1075    purge gap, ``label_horizon > 1``, the default predictor's own
1076    exactly-constant-prediction raise) and PROPAGATES loudly instead
1077    of being classified here.
1078    """
1079    wcfg = cfg["walkforward"]
1080    df_wf = pd.DataFrame({"signal": al["signal"], "outcome": al["returns"]})
1081    try:
1082        wf = walkforward(
1083            df_wf,
1084            train_window=int(wcfg.get("train_window", 180)),
1085            test_window=int(wcfg.get("test_window", 30)),
1086            step=int(wcfg.get("step", 30)),
1087            forbid_calendar=True,
1088            purge_gap=int(wcfg.get("purge_gap", 0)),
1089            label_horizon=int(wcfg.get("label_horizon", 1)),
1090        )
1091    except ValueError as exc:
1092        if "too small" not in str(exc):
1093            # caller/config error (e.g. train_window below the
1094            # framework floor): re-raise, never classify it as the
1095            # data-capacity INCONCLUSIVE (a typo'd config would
1096            # otherwise read as "could not test")
1097            raise
1098        return {
1099            "stage": 4,
1100            "name": _STAGE_NAMES[4],
1101            "status": "INCONCLUSIVE",
1102            "summary": (
1103                "walk-forward could not run: insufficient data for"
1104                f" the configuration ({exc})"
1105            ),
1106            "results": {"error": str(exc)},
1107        }
1108    no_peek = check_no_peeking(wf)
1109    preds_std = float(wf.get("preds_std", float("nan")))
1110    constant_predictions = (
1111        not np.isfinite(preds_std) or preds_std < _CONSTANT_PREDS_STD_FLOOR
1112    )
1113    wf_verdict = str(wf["verdict"])
1114    if wf_verdict == "INCONCLUSIVE":
1115        # undecided beats the gate: "could not test" stays undecided
1116        status = "INCONCLUSIVE"
1117    else:
1118        status = {
1119            "PASS": "PASS",
1120            "DEGRADED": "WARN",
1121            "FAIL": "FAIL",
1122        }[wf_verdict]
1123        if constant_predictions or not no_peek:
1124            status = "FAIL"
1125    summary = (
1126        f"{wf_verdict}: wf_t={wf['wf_t']:.2f} "
1127        f"direction={wf['wf_direction_consistency']:.3f} "
1128        f"shrink={wf['wf_shrink_ratio']:.2f} ({wf['n_folds']} folds, "
1129        f"no_peeking={no_peek}, mode={wf['mode']}, "
1130        f"purge={int(wf.get('purge_gap', 0))})"
1131    )
1132    if constant_predictions and wf_verdict != "INCONCLUSIVE":
1133        summary = (
1134            "walk-forward model produced constant predictions "
1135            f"(preds_std={preds_std:.2e}) - the model degenerated on "
1136            "the folds; the signal was not tested"
1137        )
1138    reason = wf.get("verdict_reason")
1139    if reason:
1140        summary = f"{summary} [{reason}]"
1141    results = {key: value for key, value in wf.items() if key != "folds"} | {
1142        "folds": wf["folds"],
1143        "no_peeking": no_peek,
1144    }
1145    if constant_predictions and wf_verdict != "INCONCLUSIVE":
1146        results["constant_predictions"] = True
1147    return {
1148        "stage": 4,
1149        "name": _STAGE_NAMES[4],
1150        "status": status,
1151        "summary": summary,
1152        "results": results,
1153    }

1156def _strategy_position_returns(
1157    al: dict[str, Any], threshold: float
1158) -> tuple[np.ndarray, np.ndarray]:
1159    """Long/flat rule on the signal with a one-period lag (no lookahead).
1160
1161    Returns ``(positions, strategy_returns)`` where ``strat[t] =
1162    pos[t-1] * ret[t]`` and ``strat[0] = 0`` (entry costs are handled by
1163    :func:`atropos.cost_model.apply_proportional_costs` via the position
1164    changes).
1165    """
1166    sig = al["signal"].to_numpy(dtype=float)
1167    ret = al["returns"].to_numpy(dtype=float)
1168    pos = (sig > threshold).astype(float)
1169    strat = np.zeros(ret.size, dtype=float)
1170    strat[1:] = pos[:-1] * ret[1:]
1171    return pos, strat

1174def _stage_5_monte_carlo(
1175    al: dict[str, Any], cfg: dict[str, Any], threshold: float
1176) -> dict[str, Any]:
1177    """Bootstrap Sharpe / max-drawdown envelope of the threshold rule.
1178
1179    The envelope is computed on returns NET of proportional transaction
1180    costs (``cost.cost_bps`` one-way per unit turnover).  Verdict matrix
1181    (first match wins; ``cost_breach`` is set only on the last row):
1182
1183    * drawdown tail breached (``mDD p5 < worst_allowed_mdd_p5``)
1184      -> ``RISK``
1185    * gross Sharpe floor also breached (no edge even before costs)
1186      -> ``RISK``
1187    * net Sharpe floor breached while the gross envelope clears it
1188      -> ``COST_DEATH`` (``cost_breach=True``)
1189    * net Sharpe floor breached, drawdown tail intact, and the
1190      breakeven gate fires (``cost_bps >= breakeven_cost_bps`` with a
1191      finite positive breakeven) -> ``COST_DEATH`` too: costs at or
1192      above the edge-eating level attribute the death to costs even
1193      when the gross bootstrap envelope is too noisy to vouch for the
1194      edge (the breakeven number itself proves a positive gross mean).
1195      The boundary is inclusive on the cost side - a cost exactly
1196      equal to the breakeven kills, because the net edge is then
1197      exactly eaten.  A non-positive breakeven (no gross edge in the
1198      mean), NaN (neither edge nor trading) and inf (never trades) can
1199      never fire the gate.
1200
1201    So a drawdown breach always dominates: ``COST_DEATH`` requires the
1202    drawdown tail to be intact, and either the gross envelope to pass
1203    or the breakeven gate to fire.  The breakeven comparison is a kill
1204    ATTRIBUTION, not a reported number: when it fires, the verdict is
1205    the existing ``COST_DEATH`` path (no new token), and
1206    ``results["cost"]["breakeven_breach"]`` records that the gate (not
1207    the gross-envelope comparison) drove the attribution.
1208
1209    Entry-day exclusion: ``strat[0] = 0`` by construction (no position
1210    is held on the entry day) and it carries no turnover charge, so
1211    every per-period statistic of this stage - the Sharpe /
1212    drawdown envelope AND ``cost_drag_mean`` - is computed on the
1213    post-entry body ``net[1:]``: the entry day is excluded from both.
1214    """
1215    mc = cfg["mc"]
1216    cost_cfg = cfg["cost"]
1217    cost_bps = float(cost_cfg.get("cost_bps", 10.0))
1218    pos, strat = _strategy_position_returns(al, threshold)
1219    net = apply_proportional_costs(strat, pos, cost_bps)
1220    turn = annual_turnover(pos)
1221    breakeven = float(breakeven_cost_bps(strat, pos)["breakeven_cost_bps"])
1222    body = net[1:]
1223    cost_drag = (
1224        float(np.mean((strat - net)[1:])) if net.size > 1 else float("nan")
1225    )
1226    sd = float(np.std(body, ddof=1))
1227    if not np.isfinite(sd) or sd <= 0:
1228        return {
1229            "stage": 5,
1230            "name": _STAGE_NAMES[5],
1231            "status": "FAIL",
1232            "summary": (
1233                "degenerate strategy returns "
1234                "(no active trades or zero variance)"
1235            ),
1236            "results": {"n_active": int(np.sum(body != 0))},
1237        }
1238    # rescale to a sane annualized vol so compounded drawdowns are meaningful
1239    scale = (float(mc["target_ann_vol"]) / np.sqrt(252.0)) / sd
1240    scaled = body * scale
1241    sr_d = sharpe_distribution(
1242        scaled,
1243        n_sim=int(mc["n_sim"]),
1244        block=int(mc["block"]),
1245        seed=int(cfg["seed"]) + 51,
1246    )
1247    mdd_d = max_drawdown_distribution(
1248        scaled,
1249        n_sim=int(mc["n_sim"]),
1250        block=int(mc["block"]),
1251        seed=int(cfg["seed"]) + 52,
1252    )
1253    sr_p5, mdd_p5 = sr_d["sr_p5"], mdd_d["mdd_p5"]
1254    sr_floor = float(mc["min_sr_p5"])
1255    mdd_limit = float(mc["worst_allowed_mdd_p5"])
1256    sr_fail = not np.isfinite(sr_p5) or sr_p5 <= sr_floor
1257    mdd_fail = not np.isfinite(mdd_p5) or mdd_p5 < mdd_limit
1258    gross_sr_p5: float | None = None
1259    if sr_fail:
1260        # attribute the breach: costs or genuine lack of edge?
1261        gross_d = sharpe_distribution(
1262            strat[1:],
1263            n_sim=int(mc["n_sim"]),
1264            block=int(mc["block"]),
1265            seed=int(cfg["seed"]) + 51,
1266        )
1267        gross_sr_p5 = float(gross_d["sr_p5"])
1268    gross_pass = (
1269        gross_sr_p5 is not None
1270        and np.isfinite(gross_sr_p5)
1271        and gross_sr_p5 > sr_floor
1272    )
1273    # breakeven gate: a finite positive breakeven proves the gross MEAN
1274    # is positive, so costs at or above it attribute a net-envelope
1275    # death to costs even when the gross bootstrap p5 is too noisy to
1276    # clear the floor.  NaN (no edge, no trading), inf (never trades)
1277    # and a non-positive breakeven (no gross edge in the mean) can
1278    # never fire: the comparison then cannot attribute a death to
1279    # costs because there is no edge to eat.  The verdict matrix (see
1280    # docstring): a drawdown breach always yields RISK, COST_DEATH
1281    # needs net fail + intact drawdown tail + (gross pass or this gate)
1282    breakeven_breach = bool(
1283        np.isfinite(breakeven) and breakeven > 0.0 and cost_bps >= breakeven
1284    )
1285    cost_breach = (
1286        sr_fail and not mdd_fail and (gross_pass or breakeven_breach)
1287    )
1288    reasons: list[str] = []
1289    if sr_fail:
1290        if cost_breach:
1291            reasons.append(
1292                f"net SR p5={sr_p5:.2f} <= floor {sr_floor:.2f} "
1293                f"while gross p5={gross_sr_p5:.2f} "
1294                f"(cost {cost_bps:.0f}bps vs breakeven {breakeven:.0f}bps)"
1295            )
1296        else:
1297            reasons.append(f"SR p5={sr_p5:.2f} <= floor {sr_floor:.2f}")
1298    if mdd_fail:
1299        reasons.append(f"mDD p5={mdd_p5:.1%} < limit {mdd_limit:.1%}")
1300    warns: list[str] = []
1301    max_turn = cost_cfg.get("max_turnover_annual")
1302    if max_turn is not None and turn["annual_turnover"] > float(max_turn):
1303        warns.append(
1304            f"annual turnover {turn['annual_turnover']:.0f}/yr "
1305            f"> {float(max_turn):.0f}"
1306        )
1307    status = "FAIL" if reasons else ("WARN" if warns else "PASS")
1308    summary = (
1309        f"net SR p5/p50/p95 = {sr_d['sr_p5']:.2f}/{sr_d['sr_p50']:.2f}/"
1310        f"{sr_d['sr_p95']:.2f} | "
1311        f"mDD p5/p50/p95 = {mdd_d['mdd_p5']:.1%}/{mdd_d['mdd_p50']:.1%}/"
1312        f"{mdd_d['mdd_p95']:.1%} | "
1313        f"breakeven {breakeven:.0f}bps (cost {cost_bps:.0f}bps, "
1314        f"turnover {turn['annual_turnover']:.0f}/yr)"
1315    )
1316    if reasons:
1317        summary = "FAILED: " + "; ".join(reasons)
1318    elif warns:
1319        summary = "WARN: " + "; ".join(warns) + " | " + summary
1320    return {
1321        "stage": 5,
1322        "name": _STAGE_NAMES[5],
1323        "status": status,
1324        "summary": summary,
1325        "results": {
1326            "sr_distribution": sr_d,
1327            "mdd_distribution": mdd_d,
1328            "vol_scale_factor": scale,
1329            "strategy_returns": net,
1330            "gross_strategy_returns": strat,
1331            "cost": {
1332                "cost_bps": cost_bps,
1333                "breakeven_cost_bps": breakeven,
1334                # True when the breakeven gate (cost_bps >= breakeven,
1335                # finite positive breakeven) drove the cost_breach
1336                # attribution - see the verdict matrix in the docstring
1337                "breakeven_breach": breakeven_breach,
1338                "annual_turnover": turn["annual_turnover"],
1339                "n_changes": turn["n_changes"],
1340                "cost_drag_mean": cost_drag,
1341            },
1342            "cost_breach": cost_breach,
1343        },
1344    }

1347def _resolve_model(cfg: dict[str, Any]) -> ModelFn:
1348    """Map ``config['model']`` to a model factory used by stage 6.
1349
1350    ``"ols"`` / ``"knn"`` / ``"kernel"`` select the bundled factories
1351    (``model_params`` are forwarded to the non-linear ones); any callable
1352    ``(features, target) -> predictor`` passes through unchanged, so an
1353    sklearn-style wrapper plugs in without new dependencies.
1354    """
1355    model_spec = cfg.get("model", "ols")
1356    params: dict[str, Any] = dict(cfg.get("model_params") or {})
1357    if callable(model_spec):
1358        passthrough: ModelFn = model_spec
1359        return passthrough
1360    if model_spec == "ols":
1361        return ols_model_fn
1362
1363    def _knn_factory(
1364        features_train: np.ndarray, target_train: np.ndarray
1365    ) -> Predictor:
1366        return knn_model_fn(features_train, target_train, **params)
1367
1368    def _kernel_factory(
1369        features_train: np.ndarray, target_train: np.ndarray
1370    ) -> Predictor:
1371        return kernel_model_fn(features_train, target_train, **params)
1372
1373    factories: dict[str, ModelFn] = {
1374        "knn": _knn_factory,
1375        "kernel": _kernel_factory,
1376    }
1377    if model_spec not in factories:
1378        raise ValueError(
1379            f"unknown model {model_spec!r}: "
1380            "expected 'ols' | 'knn' | 'kernel' or a callable factory"
1381        )
1382    return factories[model_spec]
1383

1386    """Human-readable model name for the stage-6 summary line."""
1387    model_spec = cfg.get("model", "ols")
1388    if isinstance(model_spec, str):
1389        return model_spec
1390    return getattr(model_spec, "__name__", "custom")

1394    al: dict[str, Any],
1395    cfg: dict[str, Any],
1396    strat_returns: np.ndarray,
1397    mdd_p50: float,
1398) -> dict[str, Any]:
1399    """Purged CV + walk-forward + stability + sign + deflated Sharpe."""
1400    features = pd.concat(
1401        [al["signal"].rename("signal"), al["features"]], axis=1

1418        purge_gap=int(cfg["wf_eval"].get("purge_gap", 0)),
1419    )

1422        target,
1423        model_fn,
1424        n_bootstrap=int(cfg["importance"]["n_bootstrap"]),

1442        fails.append(
1443            f"sign consistency FAIL (acc={sc['directional_accuracy']:.3f})"
1444        )
1445    warns: list[str] = []
1446    if sc["verdict"] == "INCONCLUSIVE":
1447        warns.append(
1448            "sign consistency INCONCLUSIVE "
1449            f"({sc.get('reason', 'degenerate outcomes')})"
1450        )
1451    if wfe["verdict"] == "DEGRADED":
1452        warns.append(
1453            f"rolling walk-forward DEGRADED (pnl_t={wfe['pnl_t']:.2f})"
1454        )
1455    if stab["verdict"] == "UNSTABLE":
1456        warns.append(
1457            f"feature importances unstable "
1458            f"(rho={stab['mean_pairwise_spearman']:.2f})"
1459        )
1460    if dp["verdict"] == "FAIL":
1461        # ATR-08: DSR FAIL is a KILL in both chains (aligned with
1462        # ml_training _gate_deflated_sharpe hard DEAD)
1463        fails.append(
1464            f"deflated Sharpe p={dp['p_value']:.3f} "
1465            f"(n_strategies={dp['n_strategies']})"
1466        )
1467
1468    status = "FAIL" if fails else ("WARN" if warns else "PASS")
1469    summary = (
1470        f"[model={_model_label(cfg)}] "
1471        f"purged-CV IC={cv['mean_ic']:.3f} | "
1472        f"wf_eval pnl_t={wfe['pnl_t']:.2f} "
1473        f"hit={wfe['oos_hit_rate']:.3f} | "
1474        f"sign acc={sc['directional_accuracy']:.3f} | "
1475        f"DSR p={dp['p_value']:.3f}"
1476    )
1477    if fails:
1478        summary = f"[model={_model_label(cfg)}] FAILED: " + "; ".join(fails)
1479    elif warns:
1480        summary = f"[model={_model_label(cfg)}] WARN: " + "; ".join(warns)
1481    return {
1482        "stage": 6,
1483        "name": _STAGE_NAMES[6],
1484        "status": status,
1485        "summary": summary,
1486        "results": {
1487            "purged_cv": {
1488                key: value for key, value in cv.items() if key != "folds"
1489            },
1490            "cv_folds": cv["folds"],
1491            "wf_eval": {
1492                key: value
1493                for key, value in wfe.items()
1494                if key not in ("folds", "predictions", "realized")
1495            },
1496            "wf_eval_folds": wfe["folds"],
1497            "importance_stability": stab,
1498            "sign_consistency": sc,
1499            "deflated_performance": dp,
1500        },
1501    }

1565def _battery_failed_rows(table: Any) -> list[tuple[str, float]]:
1566    """(test name, baseline stat) of the battery's FAILing attack rows.

1643def _json_safe_config(cfg: dict[str, Any]) -> dict[str, Any]:
1644    """JSON-serializable copy of the merged config.
1645
1646    Callable values (a custom ``model`` factory, callable ``model_params``
1647    entries) are replaced with the ``"<callable>"`` placeholder; the
1648    pipeline itself keeps using the real objects.
1649    """
1650    return {key: (_json_safe_value(value)) for key, value in cfg.items()}

1652
1653def _json_safe_value(value: Any) -> Any:
1654    """Recursively replace callables with a serializable placeholder.
1655
1656    Tuples become lists and sets become sorted lists (entries are
1657    assumed to be mutually sortable), so containers ``json.dumps``
1658    cannot handle - a bare ``set`` - or would only convert at dump
1659    time - a tuple that still hides a callable inside - leave this
1660    function already JSON-serializable.
1661    """
1662    if callable(value):
1663        return "<callable>"
1664    if isinstance(value, dict):
1665        return {
1666            inner_key: _json_safe_value(inner)
1667            for inner_key, inner in value.items()
1668        }
1669    if isinstance(value, (list, tuple)):
1670        return [_json_safe_value(item) for item in value]
1671    if isinstance(value, (set, frozenset)):
1672        return sorted(_json_safe_value(item) for item in value)
1673    return value

1676def _strategy_metrics_block(
1677    active_returns: np.ndarray,
1678    report_index: pd.Index,
1679    periods: int = 252,
1680) -> dict[str, Any]:
1681    """Informational return-metrics block for the report (never a gate).
1682
1683    Reads ONLY the hoisted feed facts, so the block is present on every
1684    verdict path (early kills included) and nothing here can affect the
1685    verdict, the issues or any template fill.  The standing "active"
1686    convention of this codebase is FINITE NON-ZERO returns -- exactly
1687    what ``active_days`` counts -- so the metrics run on
1688    ``active_returns[np.isfinite(active_returns) & (active_returns !=
1689    0.0)]`` and ``n_obs`` equals ``active_days`` by construction
1690    (test-pinned).  Zeros are compounding-neutral: dropping them
1691    removes exact-1.0 factors from ``cumprod(1 + r)``, so the filtered
1692    equity path is the same subsequence as the full path and the
1693    filtered-vs-full drawdown is identical.
1694
1695    ``period_years`` is the CALENDAR span of ``report_index`` -- the
1696    full window, active days or not; CAGR/Calmar annualize with it (71
1697    active days over 502 calendar days is 1.38 years, not 0.28).  A
1698    non-datetime (or empty) index yields ``period_years=None`` and
1699    ``cagr`` / ``calmar`` ``None``: an unknowable span is not guessed
1700    (fail-honest), while ``sharpe`` / ``sortino`` / ``max_dd`` need no
1701    span and are still computed.  ``calmar_ratio`` is the single home
1702    of the CAGR / drawdown arithmetic, so the block delegates to it
1703    once instead of re-deriving the curve.
1704
1705    The Sharpe CI is a minimum-cost noisy directional interval, not a
1706    significance test: below 50 active observations it is not computed
1707    at all (an early kill must not pay for an unreadable CI).
1708    """
1709    metrics_returns = active_returns[
1710        np.isfinite(active_returns) & (active_returns != 0.0)
1711    ]
1712    n_obs = int(metrics_returns.size)
1713    period_years: float | None = None
1714    if isinstance(report_index, pd.DatetimeIndex) and len(report_index) > 0:
1715        period_years = (
1716            float((report_index.max() - report_index.min()).days) / 365.25
1717        )
1718    if n_obs == 0:
1719        # early-kill honesty: no active periods, no metrics -- the
1720        # block reports the emptiness instead of fabricated numbers
1721        return {
1722            "cagr": None,
1723            "sharpe": None,
1724            "sharpe_ci_low": None,
1725            "sharpe_ci_high": None,
1726            "sortino": None,
1727            "max_dd": None,
1728            "calmar": None,
1729            "n_obs": 0,
1730            "period_years": None,
1731        }
1732    if n_obs < 50:
1733        # point estimate only: the bootstrap CI is unreadable here and
1734        # an early kill must not pay for it (n_boot=1 skips the
1735        # resampling; the CI keys stay None)
1736        sharpe_out = sharpe_ratio(
1737            metrics_returns, periods=periods, n_boot=1, block=1, seed=0
1738        )
1739        sharpe_ci_low: float | None = None
1740        sharpe_ci_high: float | None = None
1741    else:
1742        sharpe_out = sharpe_ratio(
1743            metrics_returns, periods=periods, n_boot=200, block=20, seed=42
1744        )
1745        sharpe_ci_low = float(sharpe_out["sr_ci"][0])
1746        sharpe_ci_high = float(sharpe_out["sr_ci"][1])
1747    sortino_value: float | None = sortino_ratio(
1748        metrics_returns, periods=periods
1749    )["sortino"]
1750    eq = equity_from_returns(metrics_returns)
1751    cagr_value: float | None = None
1752    calmar_value: float | None = None
1753    mdd_value: float | None
1754    if not bool(np.all(eq > 0.0)):
1755        # a single period of -100% or worse destroys multiplicative
1756        # compounding: no positive equity peak exists, so the
1757        # drawdown/CAGR family is undefined -- fail-honest None instead
1758        # of a raise from a report block
1759        mdd_value = None
1760    elif period_years is not None and n_obs >= 2:
1761        calmar_out = calmar_ratio(
1762            metrics_returns, periods=periods, period_years=period_years
1763        )
1764        cagr_value = float(calmar_out["cagr"])
1765        calmar_value = float(calmar_out["calmar"])
1766        mdd_value = float(calmar_out["mdd"])
1767    else:
1768        # no usable calendar span (or a single observation): the
1769        # drawdown itself is still a span-free fact
1770        mdd_value = float(max_drawdown(eq)["mdd"])
1771    return {
1772        "cagr": cagr_value,
1773        "sharpe": float(sharpe_out["sr"]),
1774        "sharpe_ci_low": sharpe_ci_low,
1775        "sharpe_ci_high": sharpe_ci_high,
1776        "sortino": sortino_value,
1777        "max_dd": mdd_value,
1778        "calmar": calmar_value,
1779        "n_obs": n_obs,
1780        "period_years": period_years,
1781    }

1784# PLR0911 waived: one return per pipeline-stage verdict (stages 1-7, the
1785# panel-only branch, and the all-survived return), mirroring the
1786# kill-on-first-FAIL decision tree.  Intentionally NOT refactored into a
1787# class: the flat return-per-verdict shape is the decision tree.
1788def run_full_pipeline(  # noqa: PLR0911, PLR0912, PLR0915
1789    data: dict[str, Any],
1790    hypothesis_config: dict[str, Any] | None = None,
1791    *,
1792    prereg_hash: str | None = None,
1793    strategy_family: str | None = None,
1794) -> dict[str, Any]:
1795    """Chain the adversarial stages; kill on the first FAIL.
1796
1797    Args:
1798        data: dict with ``returns`` (per-period forward returns),
1799            ``signal`` (same index), optional ``features`` (known
1800            control factors), optional ``mom7`` / ``mom30`` (observed
1801            momentum factors; trailing-return sums are used when
1802            absent), optional ``hypothesis`` (description).  Panel
1803            mode: ``panel_signal`` / ``panel_returns`` DataFrames
1804            (rows = dates, columns = assets) enable stage 7; given
1805            alone, stages 1-6 are SKIPPED (panel-only mode).  A
1806            degenerate ``signal`` or ``returns`` feed (empty /
1807            all-NaN / zero peak-to-peak) stops the run at the
1808            stage-0 pre-flight as ``DEGENERATE_FEED`` - before the
1809            aligner can mask it with a size error.
1810        hypothesis_config: optional overrides over
1811            :data:`DEFAULT_CONFIG` (nested dicts are merged
1812            key-wise).  Notable keys: ``cost.cost_bps`` (one-way cost
1813            in bps, netted out in stage 5), ``model`` (``"ols"`` |
1814            ``"knn"`` | ``"kernel"`` | callable factory, stage 6),
1815            ``target`` (``"ts"`` | ``"xs"``; what the hypothesis
1816            predicts - ``"ts"`` the default: a time-series book for
1817            which the stage-7 cross-sectional attack is corroborating
1818            evidence only; ``"xs"``: the cross-section IS the target,
1819            so a CS_NO_EDGE kill reads verdict_class ``DEAD``).
1820        prereg_hash: keyword-only hash of the frozen preregistration
1821            this run is bound to (e.g.
1822            :func:`atropos.prereg_generator.spec_hash` of the frozen
1823            params).  Purely an anchor: when given, the report echoes
1824            it as ``report["prereg_hash"]`` so a verdict can never
1825            drift away from the spec it was preregistered under;
1826            ``None`` (the default) leaves the key ``None`` and the
1827            run unanchored.
1828        strategy_family: keyword-only instrument-routing override (a
1829            :func:`atropos.instrument_map.validate_family` literal).
1830            Resolution order: the explicit kwarg WINS over
1831            ``hypothesis_config["strategy_family"]``; if BOTH are set
1832            and differ, ValueError; if only one is set it is
1833            validated (an unknown name raises); if NEITHER is set the
1834            run stays in audit mode (family ``None``, nothing
1835            enforced).  A family set through ``hypothesis_config``
1836            also flows into the merged ``config`` echoed by the
1837            report.
1838
1839    Returns:
1840        One dict: ``{hypothesis, n_obs, date_range, overall_verdict,
1841        verdict_class, informative, interpretation, next_step,
1842        what_would_change, failed_test, active_days, strategy_metrics,
1843        killed_by_stage, kill_reason, stages (list of per-stage dicts),
1844        config, runtime_seconds, prereg_hash, instrument_audit}``.
1845
1846        ``overall_verdict`` tokens - kills: ``DEGENERATE_FEED``
1847        (stage-0 pre-flight: a degenerate feed column), ``ARTIFACT``,
1848        ``REPACKAGING`` (stage 1/2), ``DEAD`` (ONLY a battery OVERALL
1849        DEAD: catastrophic baseline / no active days),
1850        ``ROBUSTNESS_DEATH`` (stage-3 FRAGILE book),
1851        ``PLACEBO_VIOLATION`` (stage-3 FRAGILE driven solely by the
1852        ``placebo_lag`` row - its only failing attack),
1853        ``OVERFIT_DEATH`` (stage-4 shrink gate),
1854        ``CONSTANT_PREDICTIONS`` (stage-4 model degenerated),
1855        ``NO_OOS_EDGE`` (stages 4/6), ``RISK`` / ``COST_DEATH``
1856        (stage 5), ``CS_NO_EDGE`` (stage 7); ``INCONCLUSIVE`` (a
1857        walk-forward configuration the data cannot carry, a NaN
1858        shrinkage, or fewer than two unique OOS predictions -
1859        undecided, not a kill; ``kill_reason`` names the blocker);
1860        ``SURVIVES`` / ``SURVIVES_WITH_WARNINGS`` (every executed
1861        series attack missed) and the panel-only
1862        ``SURVIVES_CS_ONLY`` / ``SURVIVES_CS_ONLY_WITH_WARNINGS``
1863        (only the cross-sectional attack ran - never a plain
1864        ``SURVIVES``).  Stages after the killer are ``SKIPPED`` (with
1865        a kill-context summary); in a series-only survival stage 7 is
1866        ``SKIPPED`` as an optional stage (no panel data).
1867
1868        Metadata keys: ``verdict_class`` is exactly one of ``DEAD`` /
1869        ``NEEDS_ANALYSIS`` / ``INCONCLUSIVE`` / ``SURVIVES`` (DEAD
1870        only for the battery-OVERALL-DEAD verdict and for
1871        ``CS_NO_EDGE`` when ``target == "xs"``); ``informative`` is
1872        False ONLY for ``DEGENERATE_FEED`` / ``CONSTANT_PREDICTIONS``
1873        / ``INCONCLUSIVE``; ``interpretation`` / ``next_step`` /
1874        ``what_would_change`` are filled strings quoting this run's
1875        facts; ``failed_test`` is the comma-joined names of the
1876        FAILing battery rows for a stage-3 kill (baseline and OVERALL
1877        rows excluded), ``None`` for every other outcome;
1878        ``active_days`` counts finite non-zero returns of the feed.
1879        ``killed_by_stage`` is ``0`` for the pre-flight
1880        (``DEGENERATE_FEED``), ``1..7`` for a stage kill, ``None``
1881        when no stage killed.
1882
1883        The ``strategy_metrics`` block is informational: they are
1884        read-outs.  They do not affect the verdict. A high Sharpe
1885        does not override ``ROBUSTNESS_DEATH``. The kill-protocol
1886        answers "can this be killed", not "how good is the return".
1887        Sharpe 2.3 on 71 active days is not an edge -- it is an
1888        insignificant mean with outliers. Metrics help the principal
1889        read the report; they do not decide it. ``n_obs`` counts
1890        ACTIVE periods (finite non-zero returns -- the standing
1891        active convention, matching ``active_days``); ``period_years``
1892        is the CALENDAR span of the full window; CAGR/Calmar use the
1893        calendar span (71 active days over 502 calendar days is 1.38
1894        years, not 0.28). The block is per-period only:
1895        hit_rate/n_trades/profit_factor are trade-stream metrics and
1896        live in trade-stream contexts (payoff_stats / profit_factor).
1897
1898        ``instrument_audit`` records the instrument-routing contract
1899        (see :mod:`atropos.instrument_map`) and is built on EVERY
1900        verdict path, stage-0 kills included:
1901        ``{"family": <family|None>, "mode": "audit"|"enforce",
1902        "violations": [...], "units_mismatch": None}``.  Family
1903        ``None`` (the default) is AUDIT mode: the run behaves exactly
1904        as without routing and nothing is enforced.  A resolved family
1905        is ENFORCE mode: a plan forbidden entry whose concrete
1906        ``stage`` is inside the stages the run would reach (series
1907        mode 1-7, panel-only mode 7) raises ValueError BEFORE any
1908        data work (up-front contract check), and the per-stage gates
1909        re-check the same contract before each stage executes;
1910        ``violations`` repeats the post-hoc
1911        :func:`atropos.instrument_map.audit_report` findings for the
1912        stages that DID run (normally empty - enforce prevents them,
1913        and SKIPPED placeholders are excluded).  The
1914        ``units_mismatch`` key is reserved and always ``None`` this
1915        wave: no return-stream unit inference heuristics are
1916        implemented; the key exists so the schema is stable when
1917        detection lands.
1918
1919    Raises:
1920        ValueError: if ``data`` lacks a usable ``returns`` stream,
1921            the panel inputs violate the aligner's label contract,
1922            the aligned feed has fewer than 300 usable observations,
1923            ``config["target"]`` is not ``"ts"`` / ``"xs"``,
1924            ``strategy_family`` conflicts with
1925            ``hypothesis_config["strategy_family"]`` or names an
1926            unknown family, or - enforce mode - the family plan
1927            forbids a stage (concrete stage number) the run would
1928            reach, checked up front before any data work.
1929    """
1930    t0 = time.time()
1931    cfg = _merge_config(hypothesis_config)
1932    target = str(cfg.get("target", "ts"))
1933    if target not in ("ts", "xs"):
1934        raise ValueError(
1935            f"config['target'] must be 'ts' or 'xs', got {target!r}"
1936        )
1937    # instrument routing (opt-in, atropos.instrument_map): the explicit
1938    # kwarg overrides the config; both set and differing is a loud
1939    # conflict; neither set leaves the run in audit mode (family None,
1940    # nothing enforced, report unchanged except the audit key)
1941    config_family = (
1942        hypothesis_config.get("strategy_family")
1943        if hypothesis_config is not None
1944        else None
1945    )
1946    if (
1947        strategy_family is not None
1948        and config_family is not None
1949        and strategy_family != config_family
1950    ):
1951        raise ValueError(
1952            f"strategy_family kwarg={strategy_family} conflicts "
1953            f"with config={config_family}; pass one or align"
1954        )
1955    resolved_family = (
1956        strategy_family if strategy_family is not None else config_family
1957    )
1958    family: StrategyFamily | None = (
1959        validate_family(resolved_family)
1960        if resolved_family is not None
1961        else None
1962    )
1963    plan: InstrumentPlan | None = (
1964        route(family) if family is not None else None
1965    )
1966    hypothesis = str(data.get("hypothesis", ""))
1967    # stage-0 DEGENERATE_FEED pre-flight (B1): BEFORE _align_inputs.
1968    # The aligner drops NaN rows and raises its generic <300-obs
1969    # ValueError when a column is all-NaN, and a constant column would
1970    # otherwise survive alignment into stages that read it as a real
1971    # feed - both mask the diagnosable "the feed itself is broken"
1972    # verdict, so the pre-flight judges the RAW arrays first.
1973    signal_input = data.get("signal")
1974    returns_input = data.get("returns")
1975    signal_arr = _input_array(signal_input)
1976    returns_arr = _input_array(returns_input)
1977    degenerate_which: str | None = None
1978    if signal_arr is not None and returns_arr is not None:
1979        if _is_degenerate(signal_arr):
1980            degenerate_which = "signal"
1981        elif _is_degenerate(returns_arr):
1982            degenerate_which = "returns"
1983    # enforce-mode UP-FRONT contract check: a family whose plan
1984    # forbids a stage the run WOULD reach (series mode reaches stages
1985    # 1-7; panel-only mode only stage 7) is refused BEFORE any data
1986    # work - the family contract is a prerequisite of the run, not a
1987    # post-run annotation, so it fires ahead even of the aligner's
1988    # data-volume floor.  Declaration-level bans (stage None) never
1989    # gate here.  The per-stage ``_gate`` calls below stay as the
1990    # pinned per-stage enforcement points (defense-in-depth; they
1991    # cannot fire while stage reachability is purely mode-dependent).
1992    if family is not None and plan is not None:
1993        if returns_input is None or signal_input is None:
1994            reachable_stages: set[int] = {7}
1995        else:
1996            reachable_stages = set(range(1, 8))
1997        for forbidden_entry in plan["forbidden"]:
1998            gate_stage = forbidden_entry.get("stage")
1999            if gate_stage is not None and gate_stage in reachable_stages:
2000                raise ValueError(
2001                    f"stage {gate_stage} forbidden for family "
2002                    f"{family}: {forbidden_entry.get('reason', '')}"
2003                )
2004    if degenerate_which is not None:
2005        # the stages cannot run: nothing below the pre-flight touches
2006        # the feed, alignment included
2007        al: dict[str, Any] = {
2008            "returns": None,
2009            "signal": None,
2010            "mom7": None,
2011            "mom30": None,
2012            "features": None,
2013            "panel_signal": None,
2014            "panel_returns": None,
2015        }
2016        n_obs = 0
2017    else:
2018        al, n_obs = _align_inputs(data)
2019    has_series = al["returns"] is not None
2020    has_panel = al["panel_signal"] is not None
2021    # report facts hoisted once (the _finish closure reads them): the
2022    # report index falls back to the raw feed index in the pre-flight
2023    # case, and active_days follows the contract formula on the
2024    # returns the run carried (flattened panel in panel-only mode)
2025    if al["returns"] is not None:
2026        report_index: pd.Index = al["returns"].index
2027        active_returns: np.ndarray = al["returns"].to_numpy(dtype=float)
2028    elif al["panel_signal"] is not None:
2029        report_index = al["panel_signal"].index
2030        active_returns = np.asarray(al["panel_returns"], dtype=float)
2031        active_returns = active_returns.reshape(-1)
2032    elif returns_arr is not None:
2033        report_index = _raw_index(returns_input)
2034        active_returns = returns_arr
2035    else:  # unreachable: series or panel inputs are validated above
2036        report_index = pd.RangeIndex(0)
2037        active_returns = np.empty(0, dtype=float)
2038    active_days = int(
2039        np.count_nonzero(
2040            np.isfinite(active_returns) & (active_returns != 0.0)
2041        )

2591def _smoothed_state(values: np.ndarray, window: int) -> np.ndarray:
2592    """Trailing mean of ``values`` (expanding head), rescaled to unit std."""

2594        pd.Series(values)
2595        .rolling(window, min_periods=1)
2596        .mean()

2606    kind: str, n_obs: int = 900, seed: int = 7
2607) -> dict[str, Any]:
2608    """Synthetic market world: latent momentum factor + hidden driver.
2609
2610    Latent states are AR processes - persistent enough to survive the
2611    battery's one-period lag, with memory short enough that run starts
2612    still carry edge.  A candidate signal must survive the one-period
2613    position lag, which kills any non-persistent "edge".  Returns are
2614    ``fwd = edge_term + 0.6*mom + 0.55*eps``; the two latent states are
2615    independent of each other by construction (separate Gaussian shocks).
2616
2617    Two CLASSES of genuine edge (the fast/slow review contract):
2618
2619    * ``kind='genuine_edge'`` (FAST class) - signal = hidden driver +
2620      30% momentum bleed; returns load on the raw AR(0.5) driver
2621      (lag-1 autocorr ~0.5, dead by lag 10).  The driver's memory is
2622      SHORTER than the battery's smoothing windows (5/10/15), so
2623      window-smoothing the signal inverts its alignment with the
2624      next-period return (a smoothed high reads as "the state was high
2625      over the whole window" -> mean-reversion anti-signal).  The
2626      battery correctly kills this class on a minority of data seeds -
2627      pinned, never loosened, in tests/test_pipeline_sweep.py.
2628    * ``kind='slow_genuine_edge'`` (SLOW class) - the same driver is
2629      averaged into a slow state (trailing mean over
2630      ``_SLOW_SMOOTHING_WINDOW`` rows, unit variance; lag-1 autocorr
2631      ~0.95); signal = slow state + 30% momentum bleed; returns load
2632      on the slow state.  The signal's information is spread over a
2633      multi-row window, so the battery's smoothing OVERLAPS the
2634      information window instead of washing past it: the edge
2635      attenuates but never inverts, and the battery correctly lets
2636      the slow class through on 9/10 swept seeds (seed 7 reads FRAGILE
2637      3/7 and stops under the ATR-04 ROBUSTNESS-DEATH - pinned in
2638      tests/test_pipeline_sweep.py).  The window is
2639      deliberately modest: per-day evidence is ~ slow**2, and a
2640      ~20-row window concentrates that evidence into subperiod
2641      chunks (max_share above the stage-1 cap -> ARTIFACT kill on
2642      ~4/10 swept seeds, measured), so the window sits where the
2643      squared-state memory stays inside one subperiod third while
2644      the level memory still dwarfs the battery's smoothing scale.
2645
2646    Two kill worlds:
2647
2648    * ``kind='momentum_echo'`` - signal = momentum + noise (no new
2649      information) -> stage-1 known-features FAIL (a WARN under the
2650      ATR-12 hierarchy) -> stage-2 REPACKAGING kill.
2651    * ``kind='concentrated_edge'`` - a genuine driver edge that only
2652      ever existed in the first ``_CONCENTRATED_EDGE_FRACTION`` of the
2653      sample (full-sample regressions stay significant); the evidence
2654      concentrates in one subperiod -> stage-1 subperiod control FAIL
2655      (a single FAIL is only a WARN under ATR-12, factor controls
2656      clean) -> the stage-6 OOS evaluation catches the edge-free tail
2657      -> NO_OOS_EDGE at n_obs=400 (at 900 rows the deeper stages keep
2658      passing and the run survives with the stage-1 warning).
2659
2660    Known features are built from PAST information only (no lookahead):
2661
2662    * ``mom_noisy`` - a noisy contemporaneous observation of latent
2663      momentum (NOT a 7-day sum, hence the honest name);
2664    * ``mom12`` - momentum lagged 12 periods, shifted with a 12-row NaN
2665      head (NOT ``np.roll``, which would wrap future values around to
2666      the front - a lookahead); ``_align_inputs`` drops the NaN rows.
2667
2668    No ``mom7`` / ``mom30`` factors are supplied: the pipeline falls back
2669    to its own trailing sums of past returns, so alignment drops ~30
2670    leading rows and the usable ``n_obs`` shrinks accordingly.
2671    """
2672    rng = np.random.default_rng(seed)
2673    mom = np.zeros(n_obs)
2674    mom_shocks = rng.standard_normal(n_obs)
2675    for pos in range(1, n_obs):
2676        mom[pos] = 0.5 * mom[pos - 1] + mom_shocks[pos]
2677    mom /= float(np.std(mom))
2678    driver = np.zeros(n_obs)  # hidden persistent driver
2679    driver_shocks = rng.standard_normal(n_obs)
2680    for pos in range(1, n_obs):
2681        driver[pos] = 0.5 * driver[pos - 1] + driver_shocks[pos]
2682    driver /= float(np.std(driver))  # independent of mom by construction
2683
2684    if kind == "genuine_edge":
2685        signal = driver + 0.3 * mom
2686        edge_term = 1.0 * driver
2687        hyp = (
2688            "persistent order-flow state z predicts next-period return, "
2689            "incrementally to 7d/30d momentum (signal carries z plus a "
2690            "momentum bleed)"
2691        )
2692    elif kind == "slow_genuine_edge":
2693        slow = _smoothed_state(driver, _SLOW_SMOOTHING_WINDOW)
2694        signal = slow + 0.3 * mom
2695        edge_term = 1.0 * slow
2696        hyp = (
2697            "slow order-flow state (multi-period average of the hidden "
2698            "driver) predicts next-period return: robust to the "
2699            "battery's window smoothing, unlike the fast class"
2700        )
2701    elif kind == "momentum_echo":
2702        signal = mom + 0.4 * rng.standard_normal(n_obs)
2703        edge_term = 1.0 * driver
2704        hyp = (
2705            "claim: a fresh order-flow signal - but it is just observed "
2706            "momentum plus noise (echo of a known factor)"
2707        )
2708    elif kind == "concentrated_edge":
2709        signal = driver + 0.3 * mom
2710        loading = np.zeros(n_obs)
2711        edge_rows = int(_CONCENTRATED_EDGE_FRACTION * n_obs)
2712        loading[:edge_rows] = _CONCENTRATED_EDGE_STRENGTH
2713        edge_term = loading * driver
2714        hyp = (
2715            "claim: a persistent edge - but it only ever existed in the "
2716            "first third of the sample (in-sample concentration)"
2717        )
2718    else:
2719        raise ValueError(f"unknown kind {kind!r}")
2720
2721    fwd = edge_term + 0.6 * mom + 0.55 * rng.standard_normal(n_obs)
2722    # observed feature: noisy read of latent momentum (past-only: mom is
2723    # the state at t, observable when the signal is built)
2724    mom_noisy = mom + 0.10 * rng.standard_normal(n_obs)
2725    # observed feature: momentum lagged 12 periods - head padded with NaN
2726    # so nothing from the future leaks in (np.roll would wrap it around)
2727    mom12 = np.concatenate([np.full(12, np.nan), mom[:-12]]) + 0.10 * (
2728        rng.standard_normal(n_obs)
2729    )
2730    idx = pd.date_range("2022-01-03", periods=n_obs, freq="B")
2731    return {
2732        "returns": pd.Series(fwd, index=idx),
2733        "signal": pd.Series(signal, index=idx),
2734        "features": pd.DataFrame(
2735            {"mom_noisy": mom_noisy, "mom12": mom12}, index=idx
2736        ),
2737        "hypothesis": hyp,
2738    }

2741def _make_panel(
2742    kind: str,
2743    n_dates: int = 240,
2744    n_assets: int = 40,
2745    seed: int = 13,
2746) -> dict[str, Any]:
2747    """Synthetic cross-sectional panel: per-asset persistent factor.
2748
2749    Each asset carries a latent AR(0.85) state; the factor is z-scored
2750    across assets per date (pure cross-sectional information, no market
2751    timing).  Forward returns load on the same factor plus noise.
2752    Persistence keeps the long-short turnover realistic so the demo shows
2753    a meaningful cost drag rather than an iid churn.
2754
2755    ``kind='genuine_edge'``  - signal = factor + 30% noise (real ranking).
2756    ``kind='cs_noise'``      - signal = pure noise (no ranking information).
2757    """
2758    rng = np.random.default_rng(seed)
2759    factor = np.zeros((n_dates, n_assets))
2760    shocks = rng.standard_normal((n_dates, n_assets))
2761    for row in range(1, n_dates):
2762        factor[row] = 0.85 * factor[row - 1] + shocks[row]
2763    mean_per_date = factor.mean(axis=1, keepdims=True)
2764    std_per_date = factor.std(axis=1, keepdims=True)
2765    std_per_date[std_per_date == 0.0] = 1.0
2766    zfactor = (factor - mean_per_date) / std_per_date
2767
2768    if kind == "genuine_edge":
2769        signal = zfactor + 0.30 * rng.standard_normal((n_dates, n_assets))
2770        hyp = (
2771            "cross-sectional order-flow imbalance ranks assets: next-day "
2772            "relative returns are predictable from today's cross-section"
2773        )
2774    elif kind == "cs_noise":
2775        signal = rng.standard_normal((n_dates, n_assets))
2776        hyp = (
2777            "claim: a fresh cross-sectional ranking signal - but it is "
2778            "pure noise across assets"
2779        )
2780    else:
2781        raise ValueError(f"unknown kind {kind!r}")
2782
2783    fwd = (
2784        0.0005
2785        + 0.004 * zfactor
2786        + 0.010 * rng.standard_normal((n_dates, n_assets))
2787    )
2788    idx = pd.date_range("2022-01-03", periods=n_dates, freq="B")
2789    columns = [f"asset_{asset_no:02d}" for asset_no in range(n_assets)]
2790    return {
2791        "panel_signal": pd.DataFrame(signal, index=idx, columns=columns),
2792        "panel_returns": pd.DataFrame(fwd, index=idx, columns=columns),
2793        "hypothesis": hyp,
2794    }

2797def _verdict_matches(verdict: str, expected: str) -> bool:
2798    """Check a demo verdict against its expected label.

2800    ``"SURVIVES*"`` matches every alive form (``SURVIVES``,

(see `atropos.instrument_map`) and is built on EVERY
verdict path, stage-0 kills included:

as without routing and nothing is enforced.  A resolved family

``violations`` repeats the post-hoc

stages that DID run (normally empty - enforce prevents them,
and SKIPPED placeholders are excluded).  The
``units_mismatch`` key is reserved and always ``None`` this
wave: no return-stream unit inference heuristics are
implemented; the key exists so the schema is stable when
detection lands.
