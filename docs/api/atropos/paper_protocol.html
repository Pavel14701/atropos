atropos.paper_protocol

Paper-vs-frozen parity checker: does paper execute the frozen spec?

Paper is a forward test of the IMPLEMENTATION, not the edge. This protocol answers: "does the paper engine execute the same strategy as the frozen spec?" — a parity checker, not a strategy kill-protocol. A PARITY_FAIL indicts the paper implementation or its feed; it never indicts the hypothesis.

The stage machine runs in a FIXED order, per leg. Parity and operational stages are n-agnostic (any single issue kills regardless of sample size); the n-gate fires only after they pass:

  1. feed_granularity_check — the paper log's stamped bar_delta_min must equal the frozen spec's.
  2. frozen_window_coverage — every paper entry_ts sits inside the spec's paper_window and the frozen frame covers it through its exits (1-bar tolerance on both bounds). An EMPTY paper_window dict derives the window from the frozen frame's own span.
  3. parity_check — nearest-entry matching per (coin, entry_ts) within one bar, then per-pair comparisons: exit type through the frozen exit_type_normalization map, exit timestamp, pnl_r, fee, size, funding rate, optional pnl components. Paper trades without a frozen counterpart read as unmatched_entry or (when the coin is outside the frozen universe) universe_violation.
  4. operational_check — exactly TWO data-checks: latency (needs the signal_ts column) and exit_direction (needs side + entry_price/exit_price). Anything that cannot run is recorded in checks_skipped, never inferred.
  5. n_check — n_matched >= min_n_trades or INSUFFICIENT_N.
  6. statistical_check — paired mean-drift bootstrap (p_le0) plus the paper-vs-frozen max-drawdown ratio gate.

Final-verdict contract:

  • any stage 1/2/3 issue -> PARITY_FAIL
  • any operational issue -> OPERATIONAL_FAIL
  • clean stages 1-4, too few trades -> INSUFFICIENT_N
  • mean-drift p_le0 < 0.05 or a dd breach -> STATISTICAL_FAIL
  • statistical clean, at least one operational data-check RAN -> SURVIVES_TO_LIVE: execution-quality evidence exists and passes
  • statistical clean, BOTH data-checks skipped -> PARITY_PASS: a parity-only attestation

SURVIVES_TO_LIVE demands execution evidence (fill direction and latency actually verified); PARITY_PASS attests the trade-level match when the paper log carries no execution columns. Both are PASS-class; the distinction is evidence completeness, not correctness.

dd_comparison is computed on EVERY verdict (including kills at any earlier stage); the breach flag can only affect the verdict inside stage 6. Class-specific sections (funding, pnl_decomposition) are opt-in via frozen_spec: absence means the related check is skipped and recorded, never inferred.

The function:

  • run_paper_protocol() -- validate the paper log and the frozen spec, run the stage machine per leg, and aggregate the severity cascade into one PaperVerdict.

Issue taxonomy: the parity report carries exactly 10 named issues, the statistical report exactly one (dd_divergence); the facts dict pins the count.

 329def _validate_paper_log(paper_log: pd.DataFrame) -> tuple[int, str]:
 330    """Contract-check the paper log (columns, attrs, sizing, side).
 331
 332    Required columns: ``leg, coin, entry_ts, exit_ts, exit_type,
 333    pnl_r, sizing_rule``; required attribute
 334    ``paper_log.attrs["bar_delta_min"]`` (int minutes).  Optional
 335    columns are listed in ``_OPTIONAL_COLUMN_NAMES``; their absence
 336    sends the related check to ``checks_skipped``.
 337
 338    Returns:
 339        The stamped bar granularity in minutes and the global
 340        ``sizing_rule`` value (read via ``.iloc[0]``).
 341
 342    Raises:
 343        ValueError: on an empty log, missing columns/attr, a
 344            non-string ``sizing_rule`` value, or ``side`` values
 345            outside ``{"long", "short"}``.
 346    """
 347    if paper_log.empty:
 348        raise ValueError("paper_log is empty: nothing to parity-check")
 349    missing = [
 350        column_name
 351        for column_name in _PAPER_REQUIRED_COLUMNS
 352        if column_name not in paper_log.columns
 353    ]
 354    if missing:
 355        raise ValueError(f"paper_log is missing required columns {missing}")
 356    if "bar_delta_min" not in paper_log.attrs:
 357        raise ValueError(
 358            "paper_log.attrs['bar_delta_min'] is missing: the paper "
 359            "engine must stamp its bar granularity (int minutes) on "
 360            "the log"
 361        )
 362    bar_delta_min = validate_int(
 363        "paper_log.attrs['bar_delta_min']",
 364        paper_log.attrs["bar_delta_min"],
 365        minimum=1,
 366    )
 367    sizing_value = paper_log["sizing_rule"].iloc[0]
 368    if not isinstance(sizing_value, str) or not sizing_value.strip():
 369        raise ValueError(
 370            "paper_log['sizing_rule'] must carry a non-empty string "
 371            f"value at .iloc[0], got {sizing_value!r}"
 372        )
 373    if "side" in paper_log.columns:
 374        unknown_sides = sorted(
 375            {str(value) for value in paper_log["side"].tolist()}
 376            - {"long", "short"}
 377        )
 378        if unknown_sides:
 379            raise ValueError(
 380                "paper_log['side'] must only contain 'long'/'short', "
 381                f"got {unknown_sides}"
 382            )
 383    return bar_delta_min, sizing_value

 410def _validate_normalization(prefix: str, raw_normalization: Any) -> None:
 411    """The alias map must be non-empty and unambiguous."""
 412    if not isinstance(raw_normalization, dict) or not raw_normalization:
 413        raise ValueError(
 414            f"{prefix}['exit_type_normalization'] must be a non-empty "
 415            "dict canonical -> alias list"
 416        )
 417    seen_aliases: dict[str, str] = {}
 418    for canonical, raw_aliases in raw_normalization.items():
 419        canonical_name = str(canonical)
 420        if not isinstance(raw_aliases, list) or not raw_aliases:
 421            raise ValueError(
 422                f"{prefix}['exit_type_normalization'][{canonical_name!r}]"
 423                " must be a non-empty list of alias strings"
 424            )
 425        for raw_alias in raw_aliases:
 426            if not isinstance(raw_alias, str):
 427                raise ValueError(
 428                    f"{prefix}['exit_type_normalization']"
 429                    f"[{canonical_name!r}] must be a non-empty list of "
 430                    "alias strings"
 431                )
 432            owner = seen_aliases.get(raw_alias)
 433            if owner is not None and owner != canonical_name:
 434                raise ValueError(
 435                    f"{prefix}['exit_type_normalization']: alias "
 436                    f"{raw_alias!r} is claimed by both {owner!r} and "
 437                    f"{canonical_name!r}"
 438                )
 439            seen_aliases[raw_alias] = canonical_name

 485def _validate_paper_window(prefix: str, raw_window: Any) -> None:
 486    """``paper_window`` must parse to start <= end ({} = frozen span).
 487
 488    An EMPTY ``paper_window`` dict is legal and means the frozen
 489    frame's own span defines the window; a non-empty dict must carry
 490    Timestamp-parseable ``start``/``end``.
 491    """
 492    if not isinstance(raw_window, dict):
 493        raise ValueError(
 494            f"{prefix}['paper_window'] must be a dict "
 495            "('start'/'end', pd.Timestamp-parseable; {} = the frozen "
 496            "frame's span)"
 497        )
 498    if not raw_window:
 499        return
 500    if "start" not in raw_window or "end" not in raw_window:
 501        raise ValueError(
 502            f"{prefix}['paper_window'] must carry 'start'/'end' "
 503            "(pd.Timestamp-parseable) or be empty ({} = frozen span)"
 504        )
 505    try:
 506        window_start = pd.Timestamp(raw_window["start"])
 507        window_end = pd.Timestamp(raw_window["end"])
 508    except (TypeError, ValueError) as error:
 509        raise ValueError(
 510            f"{prefix}['paper_window'] start/end must be "
 511            f"pd.Timestamp-parseable: {error}"
 512        ) from error
 513    if window_start > window_end:
 514        raise ValueError(
 515            f"{prefix}['paper_window'] start must not exceed end "
 516            f"({window_start} > {window_end})"
 517        )

 523        raise ValueError(f"{prefix}['funding'] must be a dict")

 596        raise ValueError(f"{prefix} must be a dict")

 737def _max_drawdown_r(pnls: np.ndarray) -> float:
 738    """Max peak-to-trough decline of the pnl cumsum (positive).
 739
 740    The cumsum runs over the FRAME'S ROW ORDER (as recorded, NOT
 741    sorted by time): paper journals append in resolution order which
 742    legitimately differs from the frozen sim's sequence, and that
 743    order divergence is exactly the ``dd_divergence`` signal.  The
 744    initial equity of 0 counts as the first peak, so an early loss
 745    already counts as a drawdown.
 746    """
 747    if pnls.size == 0:
 748        return 0.0
 749    equity = np.concatenate([[0.0], np.cumsum(pnls)])
 750    peaks = np.maximum.accumulate(equity)
 751    return float(np.max(peaks[1:] - equity[1:]))
 752

 754def _max_losing_streak(pnls: np.ndarray) -> int:
 755    """Longest run of consecutive ``pnl_r < 0`` in frame row order."""
 756    longest = 0
 757    current = 0
 758    for value in pnls.tolist():
 759        if value < 0:
 760            current += 1
 761            longest = max(longest, current)
 762        else:
 763            current = 0
 764    return longest

 767def _paired_bootstrap_p(
 768    arm_a: np.ndarray,
 769    arm_b: np.ndarray,
 770    *,
 771    n_boot: int = 1000,
 772    seed: int = 42,
 773) -> float:
 774    """One-sided paired-bootstrap pseudo-p that ``mean(a) <= mean(b)``.
 775
 776    Joint paired bootstrap: non-finite pairs are dropped, the
 777    surviving INDEX PAIRS are resampled jointly through
 778    ``np.random.default_rng(seed).integers`` and the statistic is
 779    ``mean(arm_a[idx]) - mean(arm_b[idx])``; ``p_le0`` is the fraction
 780    of draws with ``diff <= 0``.  Same inputs + seed give IDENTICAL
 781    p-values to ``atropos.ranking.paired_bootstrap_diff``'s ``p_le0``.
 782
 783    Pinned against atropos.ranking.paired_bootstrap_diff @ commit
 784    5afc184 (convention 1:1).  If that implementation changes, this
 785    must be re-pinned via test_local_bootstrap_matches_ranking.
 786    """
 787    n_boot = validate_int("n_boot", n_boot, minimum=1)
 788    seed = validate_int("seed", seed, minimum=0)
 789    values_a = np.asarray(arm_a, dtype=np.float64).ravel()
 790    values_b = np.asarray(arm_b, dtype=np.float64).ravel()
 791    if values_a.shape != values_b.shape:
 792        raise ValueError(
 793            f"arm_a and arm_b must have equal length, got "
 794            f"{values_a.size} and {values_b.size}"
 795        )
 796    rng = np.random.default_rng(seed)
 797    finite = np.isfinite(values_a) & np.isfinite(values_b)
 798    values_a, values_b = values_a[finite], values_b[finite]
 799    size = int(values_a.size)
 800    if size == 0:
 801        return 1.0
 802    diffs = values_a - values_b
 803    indices = rng.integers(0, size, size=(n_boot, size))
 804    draws = diffs[indices].mean(axis=1)
 805    return float((draws <= 0).mean())

 884def _window_coverage_issue(
 885    paper_leg: pd.DataFrame,
 886    frozen_leg: pd.DataFrame,
 887    spec: dict[str, Any],
 888    labels: list[str],
 889) -> dict[str, dict[str, Any]] | None:
 890    """Stage 2: paper entries inside the window, frozen span covers it.
 891
 892    Both bounds tolerate one bar (the spec's ``bar_delta_min``); the
 893    frozen frame must cover the window through its EXITS (frozen min
 894    entry at/before the start, frozen max exit at/after the end).  An
 895    empty ``paper_window`` derives the window from the frozen frame's
 896    own span.  Any out-of-window paper entry or a range that does not
 897    span the window becomes the ``frozen_window_gap`` issue.
 898    """
 899    frozen_entries = _timestamp_values(frozen_leg, "entry_ts")
 900    frozen_exits = _timestamp_values(frozen_leg, "exit_ts")
 901    raw_window = spec["paper_window"]
 902    if raw_window:
 903        window_start = pd.Timestamp(raw_window["start"])
 904        window_end = pd.Timestamp(raw_window["end"])
 905    else:
 906        # empty paper_window: the frozen frame's own span IS the window
 907        window_start = min(frozen_entries)
 908        window_end = max(frozen_exits)
 909    one_bar = pd.Timedelta(minutes=int(spec["bar_delta_min"]))
 910    paper_entries = _timestamp_values(paper_leg, "entry_ts")
 911    issues: dict[str, dict[str, Any]] = {}
 912    for position, entry_stamp in enumerate(paper_entries):
 913        if entry_stamp < window_start or entry_stamp > window_end:
 914            _record_issue(issues, "frozen_window_gap", labels[position])
 915    examples: list[str] = []
 916    span_violations = 0
 917    frozen_min = min(frozen_entries)
 918    if frozen_min > window_start + one_bar:
 919        span_violations += 1
 920        examples.append(f"frozen_min@{frozen_min}")
 921    if max(frozen_exits) < window_end - one_bar:
 922        span_violations += 1
 923        examples.append(f"frozen_max_exit@{max(frozen_exits)}")
 924    if not issues and not span_violations:
 925        return None
 926    slot = issues.setdefault(
 927        "frozen_window_gap", {"n_affected": 0, "examples": []}
 928    )
 929    slot["n_affected"] += span_violations
 930    for example in examples[: 3 - len(slot["examples"])]:
 931        slot["examples"].append(example)
 932    return issues

1041def _exit_record_broken(
1042    paper_side: _SideArrays,
1043    frozen_side: _SideArrays,
1044    paper_position: int,
1045    frozen_position: int,
1046    *,
1047    alias_map: dict[str, str],
1048    leg: str,
1049    tolerance: pd.Timedelta,
1050    parity_tolerance_r: float,
1051) -> bool:
1052    """Exit-record divergence: type token, exit ts, or pnl_r drift.
1053
1054    All three read through one ``exit_mismatch`` bucket — the exit
1055    record as a whole disagrees with the frozen spec's.
1056    """
1057    paper_canonical = _normalize_exit_type(
1058        paper_side["exit_types"][paper_position], alias_map, leg
1059    )
1060    frozen_canonical = _normalize_exit_type(
1061        frozen_side["exit_types"][frozen_position], alias_map, leg
1062    )
1063    if paper_canonical != frozen_canonical:
1064        return True

1066        abs(
1067            paper_side["exits"][paper_position]
1068            - frozen_side["exits"][frozen_position]
1069        )
1070        > tolerance
1071    ):
1072        return True
1073    paper_pnl = paper_side["pnls"][paper_position]
1074    frozen_pnl = frozen_side["pnls"][frozen_position]
1075    return not (
1076        math.isfinite(paper_pnl)
1077        and math.isfinite(frozen_pnl)
1078        and abs(paper_pnl - frozen_pnl) <= parity_tolerance_r
1079    )

1112        paper_size = paper_sizes[paper_position]
1113        frozen_size = frozen_sizes[frozen_position]
1114        if not (
1115            math.isfinite(paper_size)
1116            and math.isfinite(frozen_size)
1117            and abs(paper_size - frozen_size) <= _SIZE_ABS_TOLERANCE
1118        ):
1119            fired.append("sizing_mismatch")
1120    if inputs["funding_enabled"] and paper_canonical == "funding_payment":
1121        paper_rate = paper_side["rates"][paper_position]
1122        frozen_rate = frozen_side["rates"][frozen_position]
1123        if not (
1124            math.isfinite(paper_rate)
1125            and math.isfinite(frozen_rate)
1126            and abs(paper_rate - frozen_rate)
1127            < inputs["rate_tolerance_bps"] * 1e-4
1128        ):
1129            # rates are fractions; the tolerance converts bps -> fraction
1130            fired.append("funding_rate_mismatch")
1131    if inputs["decomposition_enabled"]:
1132        for component_name in inputs["spec_components"]:
1133            paper_value = paper_side["components"][component_name][
1134                paper_position
1135            ]
1136            frozen_value = frozen_side["components"][component_name][
1137                frozen_position
1138            ]
1139            if (
1140                math.isfinite(paper_value)
1141                and math.isfinite(frozen_value)
1142                and abs(paper_value - frozen_value)
1143                <= inputs["component_tolerance"]
1144            ):
1145                continue
1146            fired.append("pnl_component_mismatch")
1147            break
1148    return fired

1151def _run_parity_stage(
1152    leg: str,
1153    paper_leg: pd.DataFrame,
1154    frozen_leg: pd.DataFrame,
1155    spec: dict[str, Any],
1156    *,
1157    alias_map: dict[str, str],
1158    bar_delta_min: int,
1159    paper_sizing_value: str,
1160    parity_tolerance_r: float,
1161    fee_tolerance_bps: float,
1162    labels: list[str],
1163) -> tuple[dict[str, Any], list[tuple[int, int]]]:
1164    """Stage 3: one-to-one trade matching + per-pair comparisons.
1165
1166    Matching: every paper trade (frame order) takes the nearest
1167    not-yet-matched frozen trade of the same coin whose ``entry_ts``
1168    lies within one bar.  The ``min()`` key is
1169    ``(abs_entry_diff, frozen_entry_ts)``, so equidistant candidates
1170    resolve to the EARLIER frozen entry — deterministic, and
1171    independent of row order beyond ties.  Matching is one-to-one.
1172
1173    ``exit_mismatch`` is the bucket for any divergence in the exit
1174    record: normalized exit type, exit timestamp beyond one bar, or a
1175    ``pnl_r`` difference beyond ``parity_tolerance_r``.
1176
1177    Returns:
1178        The ``parity_report`` dict and the matched
1179        ``(paper_position, frozen_position)`` pairs in paper frame
1180        order (consumed by the stage-6 bootstrap).
1181    """
1182    issues: dict[str, dict[str, Any]] = {}
1183    tolerance = pd.Timedelta(minutes=bar_delta_min)
1184    if str(paper_sizing_value) != str(spec["sizing_rule"]):
1185        _record_issue_bulk(
1186            issues, "sizing_rule_mismatch", len(labels), labels
1187        )
1188    inputs = _collect_parity_inputs(spec, paper_leg, frozen_leg)
1189    paper_side = _collect_side_arrays(paper_leg, inputs["spec_components"])
1190    frozen_side = _collect_side_arrays(frozen_leg, inputs["spec_components"])
1191    paper_coins = _string_values(paper_leg, "coin")
1192    paper_entries = _timestamp_values(paper_leg, "entry_ts")
1193    frozen_coins = _string_values(frozen_leg, "coin")
1194    frozen_entries = _timestamp_values(frozen_leg, "entry_ts")
1195    available: dict[str, list[tuple[int, pd.Timestamp]]] = {}
1196    for frozen_position, (coin_value, entry_stamp) in enumerate(
1197        zip(frozen_coins, frozen_entries, strict=True)
1198    ):
1199        available.setdefault(coin_value, []).append(
1200            (frozen_position, entry_stamp)
1201        )
1202    matched_pairs: list[tuple[int, int]] = []
1203    for paper_position, (coin_value, entry_stamp) in enumerate(
1204        zip(paper_coins, paper_entries, strict=True)
1205    ):
1206        label = labels[paper_position]
1207        candidates = available.get(coin_value, [])
1208        eligible = [
1209            (abs(entry_stamp - frozen_stamp), frozen_stamp, frozen_position)
1210            for frozen_position, frozen_stamp in candidates
1211            if abs(entry_stamp - frozen_stamp) <= tolerance
1212        ]
1213        if not eligible:
1214            if inputs["universe"] and coin_value not in inputs["universe"]:
1215                _record_issue(issues, "universe_violation", label)
1216            else:
1217                _record_issue(issues, "unmatched_entry", label)
1218            continue
1219        _, chosen_stamp, frozen_position = min(
1220            eligible, key=lambda candidate: (candidate[0], candidate[1])
1221        )
1222        candidates.remove((frozen_position, chosen_stamp))
1223        matched_pairs.append((paper_position, frozen_position))
1224        if _exit_record_broken(
1225            paper_side,
1226            frozen_side,
1227            paper_position,
1228            frozen_position,
1229            alias_map=alias_map,
1230            leg=leg,
1231            tolerance=tolerance,
1232            parity_tolerance_r=parity_tolerance_r,
1233        ):
1234            _record_issue(issues, "exit_mismatch", label)
1235        paper_canonical = _normalize_exit_type(
1236            paper_side["exit_types"][paper_position], alias_map, leg
1237        )
1238        for issue_name in _pair_extra_issues(
1239            paper_side,
1240            frozen_side,
1241            paper_position,
1242            frozen_position,
1243            inputs=inputs,
1244            paper_canonical=paper_canonical,
1245            fee_tolerance_bps=fee_tolerance_bps,
1246        ):
1247            _record_issue(issues, issue_name, label)
1248    parity_report: dict[str, Any] = {
1249        "stage_verdict": "PARITY_FAIL" if issues else "PARITY_PASS",
1250        "n_matched": len(matched_pairs),
1251        "issues": _issue_list(issues, _PARITY_ISSUE_ORDER),
1252        "checks_skipped": sorted(inputs["checks_skipped"]),
1253    }
1254    return parity_report, matched_pairs

1257def _run_operational_stage(
1258    leg: str,
1259    paper_leg: pd.DataFrame,
1260    alias_map: dict[str, str],
1261    latency_max_sec: float,
1262    labels: list[str],
1263) -> dict[str, Any]:
1264    """Stage 4: exactly TWO operational data-checks.
1265
1266    ``latency`` runs only when ``signal_ts`` is present; the bound is
1267    ``(entry_ts - signal_ts) < latency_max_sec``, and a NEGATIVE
1268    latency (signal stamped at-or-after the entry) is a lookahead
1269    defect that counts as a breach even though the plain bound would
1270    pass it.  ``exit_direction`` runs only when ``side`` and
1271    ``entry_price``/``exit_price`` are present: a long ``stop`` exit
1272    must sit below the entry (short mirrored) and a long ``tp`` exit
1273    above it; canonical tokens that name neither stop nor profit
1274    (``time_exit``, ``funding_payment``, ...) are unconstrained.
1275    Trades with non-finite prices are not checkable and are skipped.
1276    """
1277    issues: dict[str, dict[str, Any]] = {}
1278    checks_run: list[str] = []
1279    checks_skipped: list[str] = []
1280    entries = _timestamp_values(paper_leg, "entry_ts")
1281    if "signal_ts" in paper_leg.columns:
1282        checks_run.append("latency")
1283        signals = _timestamp_values(paper_leg, "signal_ts")
1284        raw_signals = list(paper_leg["signal_ts"])
1285        for position, entry_stamp in enumerate(entries):
1286            signal_stamp = signals[position]
1287            if pd.isna(raw_signals[position]):
1288                continue
1289            latency = (entry_stamp - signal_stamp).total_seconds()
1290            if latency < 0.0 or latency >= latency_max_sec:
1291                _record_issue(issues, "latency_breach", labels[position])
1292    else:
1293        checks_skipped.append("latency (no signal_ts column)")
1294    entry_prices = _float_values(paper_leg, "entry_price")
1295    exit_prices = _float_values(paper_leg, "exit_price")
1296    if (
1297        "side" in paper_leg.columns
1298        and entry_prices is not None
1299        and exit_prices is not None
1300    ):
1301        checks_run.append("exit_direction")
1302        exit_direction_issues = _exit_direction_issues(
1303            paper_leg,
1304            labels,
1305            entry_prices=entry_prices,
1306            exit_prices=exit_prices,
1307            alias_map=alias_map,
1308            leg=leg,
1309        )
1310        for label in exit_direction_issues:
1311            _record_issue(issues, "exit_direction_violation", label)
1312    else:
1313        checks_skipped.append("exit_direction (no side/price columns)")
1314    stage_verdict = "OPERATIONAL_FAIL" if issues else "OPERATIONAL_PASS"
1315    return {
1316        "stage_verdict": stage_verdict,
1317        "issues": _issue_list(issues, _OPERATIONAL_ISSUE_ORDER),
1318        "checks_run": checks_run,
1319        "checks_skipped": checks_skipped,
1320    }

1323def _exit_direction_issues(
1324    paper_leg: pd.DataFrame,
1325    labels: list[str],
1326    *,
1327    entry_prices: list[float],
1328    exit_prices: list[float],
1329    alias_map: dict[str, str],
1330    leg: str,
1331) -> list[str]:
1332    """Labels whose exit fill sits on the wrong side of the entry.
1333
1334    Only stop-like and profit-like canonical tokens carry a direction
1335    constraint (long ``stop`` below the entry / long ``tp`` above it,
1336    short mirrored); ``time_exit``, ``funding_payment`` and other
1337    unconstrained canonicals skip the check.  Trades with non-finite
1338    prices are not checkable and are skipped.
1339    """
1340    paper_sides = _string_values(paper_leg, "side")
1341    paper_exit_types = _string_values(paper_leg, "exit_type")
1342    offending: list[str] = []
1343    for position, entry_price in enumerate(entry_prices):
1344        exit_price = exit_prices[position]
1345        if not math.isfinite(entry_price) or not math.isfinite(exit_price):
1346            continue
1347        canonical = _normalize_exit_type(
1348            paper_exit_types[position], alias_map, leg
1349        )
1350        adverse = "stop" in canonical
1351        favorable = "tp" in canonical or "profit" in canonical
1352        if not adverse and not favorable:
1353            continue
1354        if paper_sides[position] == "long":
1355            direction_ok = (
1356                exit_price < entry_price
1357                if adverse
1358                else exit_price > entry_price
1359            )
1360        else:
1361            direction_ok = (
1362                exit_price > entry_price
1363                if adverse
1364                else exit_price < entry_price
1365            )
1366        if not direction_ok:
1367            offending.append(labels[position])
1368    return offending

1371def _run_statistical_stage(
1372    matched_pairs: list[tuple[int, int]],
1373    paper_pnls: list[float],
1374    frozen_pnls: list[float],
1375    *,
1376    paper_streak: int,
1377    frozen_streak: int,
1378    n_matched: int,
1379    n_bootstrap: int,
1380    seed: int,
1381    dd_comparison: dict[str, Any],
1382) -> dict[str, Any]:
1383    """Stage 6: paired mean-drift bootstrap + drawdown-ratio gate.
1384
1385    Arm order is PINNED (``arm_a`` = frozen, ``arm_b`` = paper), so
1386    the resampled statistic is ``mean(frozen) - mean(paper)`` and a
1387    small ``p_le0`` flags a paper engine that books significantly
1388    LESS than its own frozen simulation (frozen - paper consistently
1389    positive).  Mean drift is reported through ``mean_drift_p_le0`` —
1390    it is the p-value path, NOT a named issue; ``dd_divergence`` is
1391    the only named statistical issue.
1392    """
1393    matched_paper = [
1394        paper_pnls[paper_position] for paper_position, _ in matched_pairs
1395    ]
1396    matched_frozen = [
1397        frozen_pnls[frozen_position] for _, frozen_position in matched_pairs
1398    ]
1399    drift_p = _paired_bootstrap_p(
1400        np.asarray(matched_frozen, dtype=np.float64),
1401        np.asarray(matched_paper, dtype=np.float64),
1402        n_boot=n_bootstrap,
1403        seed=seed,
1404    )
1405    dd_breach = bool(dd_comparison["breach"])
1406    return {
1407        "mean_drift_p_le0": drift_p,
1408        "n_matched": n_matched,
1409        "paper_max_streak": paper_streak,
1410        "frozen_max_streak": frozen_streak,
1411        "streak_ratio": _streak_ratio(paper_streak, frozen_streak),
1412        "issues": ["dd_divergence"] if dd_breach else [],
1413        "sizing_note": _SIZING_NOTE,
1414    }

1417def _streak_ratio(paper_streak: int, frozen_streak: int) -> float:
1418    """Paper/frozen losing-streak ratio (inf when frozen never lost)."""
1419    if frozen_streak > 0:
1420        return paper_streak / frozen_streak
1421    return math.inf

1424def _dd_comparison_dict(
1425    paper_dd_r: float, frozen_dd_r: float, dd_breach_ratio: float
1426) -> dict[str, Any]:
1427    """Drawdown comparison payload (computed on EVERY verdict).
1428
1429    A positive frozen drawdown yields the plain ratio; a zero frozen
1430    drawdown with a positive paper drawdown is an unbounded ratio
1431    (``inf``), and a zero paper drawdown cannot breach.
1432    """
1433    if frozen_dd_r > 0.0:
1434        ratio = paper_dd_r / frozen_dd_r
1435    elif paper_dd_r == 0.0:
1436        ratio = 0.0
1437    else:
1438        ratio = math.inf
1439    return {
1440        "paper_dd_r": paper_dd_r,
1441        "frozen_dd_r": frozen_dd_r,
1442        "ratio": ratio,
1443        "breach": bool(ratio > dd_breach_ratio),
1444    }

1447def _leg_kill_reason(
1448    token: VerdictToken,
1449    parity_report: dict[str, Any],
1450    operational_report: dict[str, Any],
1451    statistical_report: dict[str, Any],
1452    *,
1453    killed_by_stage: int | None,
1454    n_matched: int,
1455    min_n_trades: int,
1456) -> str:
1457    """Human-readable kill reason naming the stage and the issues."""
1458    if token == "PARITY_FAIL":
1459        names = [str(entry["name"]) for entry in parity_report["issues"]]
1460        return f"parity failed at stage {killed_by_stage}: {', '.join(names)}"
1461    if token == "OPERATIONAL_FAIL":
1462        names = [str(entry["name"]) for entry in operational_report["issues"]]
1463        return f"operational failed at stage 4: {', '.join(names)}"
1464    if token == "STATISTICAL_FAIL":
1465        names = [str(name) for name in statistical_report["issues"]]
1466        if not names:
1467            names = ["mean_drift_p_le0"]
1468        return f"statistical failed at stage 6: {', '.join(names)}"
1469    if token == "INSUFFICIENT_N":
1470        return (
1471            f"stage 5: n_matched={n_matched} < min_n_trades={min_n_trades} "
1472            "after clean parity and operational stages"
1473        )
1474    if token == "PARITY_PASS":
1475        return (
1476            "not killed: parity proven; both operational data-checks "
1477            "skipped, so no execution-quality evidence exists"
1478        )
1479    return "not killed: all six stages clean with operational evidence"

1482def _run_leg_stages(  # noqa: PLR0911 (one return per stage gate, house style)
1483    leg: str,
1484    paper_leg: pd.DataFrame,
1485    frozen_leg: pd.DataFrame,
1486    spec: dict[str, Any],
1487    *,
1488    bar_delta_min_paper: int,
1489    paper_sizing_value: str,
1490    min_n_trades: int,
1491    parity_tolerance_r: float,
1492    fee_tolerance_bps: float,
1493    latency_max_sec: float,
1494    dd_breach_ratio: float,
1495    n_bootstrap: int,
1496    seed: int,
1497) -> _LegStageResult:
1498    """Run the fixed six-stage machine for ONE leg (order pinned).
1499
1500    Stages 1-3 are parity stages (n-agnostic), stage 4 the operational
1501    data-checks, stage 5 the n-gate, stage 6 the statistics.  The
1502    drawdown comparison is computed BEFORE the gates: it is reported
1503    on every verdict (the pinned test asserts a populated
1504    ``dd_comparison`` even on ``PARITY_FAIL``) and can only affect the
1505    verdict inside stage 6.
1506    """
1507    # facts computed for EVERY verdict, kills included
1508    alias_map = _exit_alias_map(spec)
1509    labels = _trade_labels(paper_leg)
1510    n_paper_trades = int(paper_leg.shape[0])
1511    paper_pnls_all = np.asarray(
1512        _float_values(paper_leg, "pnl_r") or [], dtype=np.float64
1513    )
1514    frozen_pnls_all = np.asarray(
1515        _float_values(frozen_leg, "pnl_r") or [], dtype=np.float64
1516    )
1517    paper_streak = _max_losing_streak(paper_pnls_all)
1518    frozen_streak = _max_losing_streak(frozen_pnls_all)
1519    dd_comparison = _dd_comparison_dict(
1520        _max_drawdown_r(paper_pnls_all),
1521        _max_drawdown_r(frozen_pnls_all),
1522        dd_breach_ratio,
1523    )
1524    spec_bar_delta = int(spec["bar_delta_min"])
1525    feed_granularity = {
1526        "paper": bar_delta_min_paper,
1527        "frozen": spec_bar_delta,
1528        "match": bool(bar_delta_min_paper == spec_bar_delta),
1529    }
1530    sizing_rule = {
1531        "paper": str(paper_sizing_value),
1532        "frozen": str(spec["sizing_rule"]),
1533        "match": bool(str(paper_sizing_value) == str(spec["sizing_rule"])),
1534    }
1535    funding_alignment: dict[str, Any] | None = None
1536    if "funding" in spec:
1537        funding_alignment = {
1538            "settlement_interval_hours": int(
1539                spec["funding"]["settlement_interval_hours"]
1540            ),
1541            "rate_tolerance_bps": float(
1542                spec["funding"]["rate_tolerance_bps"]
1543            ),
1544            "status": "carry_only",
1545        }
1546    pnl_decomposition: dict[str, Any] | None = None
1547    raw_decomposition = spec.get("pnl_decomposition")
1548    if isinstance(raw_decomposition, dict) and bool(
1549        raw_decomposition["enabled"]
1550    ):
1551        pnl_decomposition = {
1552            "components": [
1553                str(name) for name in raw_decomposition["components"]
1554            ],
1555            "tolerance_per_component_r": float(
1556                raw_decomposition["tolerance_per_component_r"]
1557            ),
1558            "status": "checked",
1559        }
1560
1561    def statistical_scaffold(n_matched: int) -> dict[str, Any]:
1562        """Report shape for runs where stage 6 never executed."""
1563        return {
1564            "mean_drift_p_le0": float("nan"),
1565            "n_matched": n_matched,
1566            "paper_max_streak": paper_streak,
1567            "frozen_max_streak": frozen_streak,
1568            "streak_ratio": _streak_ratio(paper_streak, frozen_streak),
1569            "issues": [],
1570            "sizing_note": _SIZING_NOTE,
1571        }
1572
1573    operational_not_run = {
1574        "stage_verdict": "NOT_RUN",
1575        "issues": [],
1576        "checks_run": [],
1577        "checks_skipped": [],
1578    }
1579
1580    def finish(
1581        token: VerdictToken,
1582        parity_report: dict[str, Any],
1583        operational_report: dict[str, Any],
1584        statistical_report: dict[str, Any],
1585        *,
1586        stage: int | None,
1587        n_matched: int,
1588    ) -> _LegStageResult:
1589        """Assemble the per-leg payload (the ensemble ``_finish`` idiom)."""
1590        return {
1591            "verdict_token": token,
1592            "killed_by_stage": stage,
1593            "kill_reason": _leg_kill_reason(
1594                token,
1595                parity_report,
1596                operational_report,
1597                statistical_report,
1598                killed_by_stage=stage,
1599                n_matched=n_matched,
1600                min_n_trades=min_n_trades,
1601            ),
1602            # the opt-in sections report the matched-pair count they
1603            # were checked against (carry-only alignment included)
1604            "n_paper_trades": n_paper_trades,
1605            "n_frozen_matched": n_matched,
1606            "parity_report": parity_report,
1607            "operational_report": operational_report,
1608            "statistical_report": statistical_report,
1609            "dd_comparison": dd_comparison,
1610            "feed_granularity": feed_granularity,
1611            "sizing_rule": sizing_rule,
1612            "funding_alignment": (
1613                dict(funding_alignment, n_matched=n_matched)
1614                if funding_alignment is not None
1615                else None
1616            ),
1617            "pnl_decomposition": (
1618                dict(pnl_decomposition, n_matched=n_matched)
1619                if pnl_decomposition is not None
1620                else None
1621            ),
1622        }
1623
1624    # --- stage 1: feed granularity (n-agnostic) -------------------------
1625    if not feed_granularity["match"]:
1626        granularity_issues: dict[str, dict[str, Any]] = {}
1627        _record_issue_bulk(
1628            granularity_issues,
1629            "feed_granularity_mismatch",
1630            n_paper_trades,
1631            labels,
1632        )
1633        parity_report = {
1634            "stage_verdict": "PARITY_FAIL",
1635            "n_matched": 0,
1636            "issues": _issue_list(granularity_issues, _PARITY_ISSUE_ORDER),
1637            "checks_skipped": [],
1638        }
1639        return finish(
1640            "PARITY_FAIL",
1641            parity_report,
1642            operational_not_run,
1643            statistical_scaffold(0),
1644            stage=1,
1645            n_matched=0,
1646        )
1647    # --- stage 2: frozen window coverage (n-agnostic) -------------------
1648    window_issues = _window_coverage_issue(
1649        paper_leg, frozen_leg, spec, labels
1650    )
1651    if window_issues is not None:
1652        parity_report = {
1653            "stage_verdict": "PARITY_FAIL",
1654            "n_matched": 0,
1655            "issues": _issue_list(window_issues, _PARITY_ISSUE_ORDER),
1656            "checks_skipped": [],
1657        }
1658        return finish(
1659            "PARITY_FAIL",
1660            parity_report,
1661            operational_not_run,
1662            statistical_scaffold(0),
1663            stage=2,
1664            n_matched=0,
1665        )
1666    # --- stage 3: trade-level parity (n-agnostic) -----------------------
1667    parity_report, matched_pairs = _run_parity_stage(
1668        leg,
1669        paper_leg,
1670        frozen_leg,
1671        spec,
1672        alias_map=alias_map,
1673        bar_delta_min=spec_bar_delta,
1674        paper_sizing_value=paper_sizing_value,
1675        parity_tolerance_r=parity_tolerance_r,
1676        fee_tolerance_bps=fee_tolerance_bps,
1677        labels=labels,
1678    )
1679    n_matched = len(matched_pairs)
1680    if parity_report["stage_verdict"] == "PARITY_FAIL":
1681        return finish(
1682            "PARITY_FAIL",
1683            parity_report,
1684            operational_not_run,
1685            statistical_scaffold(n_matched),
1686            stage=3,
1687            n_matched=n_matched,
1688        )
1689    # --- stage 4: operational data-checks (latency + exit direction) ----
1690    operational_report = _run_operational_stage(
1691        leg,
1692        paper_leg,
1693        alias_map,
1694        latency_max_sec=latency_max_sec,
1695        labels=labels,
1696    )
1697    if operational_report["stage_verdict"] == "OPERATIONAL_FAIL":
1698        return finish(
1699            "OPERATIONAL_FAIL",
1700            parity_report,
1701            operational_report,
1702            statistical_scaffold(n_matched),
1703            stage=4,
1704            n_matched=n_matched,
1705        )
1706    # --- stage 5: the n-gate (fires only after stages 1-4 pass) ---------
1707    if n_matched < min_n_trades:
1708        return finish(
1709            "INSUFFICIENT_N",
1710            parity_report,
1711            operational_report,
1712            statistical_scaffold(n_matched),
1713            stage=5,
1714            n_matched=n_matched,
1715        )
1716    # --- stage 6: statistics --------------------------------------------
1717    statistical_report = _run_statistical_stage(
1718        matched_pairs,
1719        paper_pnls_all.tolist(),
1720        frozen_pnls_all.tolist(),
1721        paper_streak=paper_streak,
1722        frozen_streak=frozen_streak,
1723        n_matched=n_matched,
1724        n_bootstrap=n_bootstrap,
1725        seed=seed,
1726        dd_comparison=dd_comparison,
1727    )
1728    drift_failed = float(statistical_report["mean_drift_p_le0"]) < 0.05
1729    if drift_failed or statistical_report["issues"]:
1730        return finish(
1731            "STATISTICAL_FAIL",
1732            parity_report,
1733            operational_report,
1734            statistical_report,
1735            stage=6,
1736            n_matched=n_matched,
1737        )
1738    # --- final contract: evidence completeness picks the PASS token -----
1739    if operational_report["checks_run"]:
1740        return finish(
1741            "SURVIVES_TO_LIVE",
1742            parity_report,
1743            operational_report,
1744            statistical_report,
1745            stage=None,
1746            n_matched=n_matched,
1747        )
1748    return finish(
1749        "PARITY_PASS",
1750        parity_report,
1751        operational_report,
1752        statistical_report,
1753        stage=None,
1754        n_matched=n_matched,
1755    )

1761def _merge_issue_lists(
1762    issue_lists: list[list[dict[str, Any]]], order: tuple[str, ...]
1763) -> list[dict[str, Any]]:
1764    """Merge per-leg issue lists (sum counts, pool up to 3 examples)."""
1765    merged: dict[str, dict[str, Any]] = {}
1766    for issue_list in issue_lists:
1767        for entry in issue_list:
1768            issue_name = str(entry["name"])
1769            slot = merged.setdefault(
1770                issue_name, {"n_affected": 0, "examples": []}
1771            )
1772            slot["n_affected"] += int(entry["n_affected"])
1773            for example in entry["examples"]:
1774                if len(slot["examples"]) < 3:
1775                    slot["examples"].append(str(example))
1776    return [
1777        {
1778            "name": issue_name,
1779            "n_affected": merged[issue_name]["n_affected"],
1780            "examples": merged[issue_name]["examples"],
1781        }
1782        for issue_name in order
1783        if issue_name in merged
1784    ]

1787def _portfolio_cascade(
1788    results: dict[str, _LegStageResult],
1789) -> tuple[str, str]:
1790    """Severity cascade over legs: PARITY > OPERATIONAL > STAT > N."""
1791    groups: dict[str, list[str]] = {token: [] for token in _SEVERITY_CASCADE}
1792    for leg_name, result in results.items():
1793        token = result["verdict_token"]
1794        if token in groups:
1795            groups[token].append(leg_name)
1796        # a leg's PARITY_PASS counts as the SURVIVES tier
1797    parts = [
1798        f"legs with {cascade_token}: [{', '.join(groups[cascade_token])}]"
1799        for cascade_token in _SEVERITY_CASCADE
1800        if groups[cascade_token]
1801    ]
1802    for cascade_token in _SEVERITY_CASCADE:
1803        if groups[cascade_token]:
1804            return cascade_token, "; ".join(parts)
1805    detail = "; ".join(
1806        f"{leg_name}={result['verdict_token']}"
1807        for leg_name, result in results.items()
1808    )
1809    return "SURVIVES_TO_LIVE", f"no leg killed: {detail}"

2255def run_paper_protocol(
2256    paper_log: pd.DataFrame,
2257    frozen_outcomes: dict[str, pd.DataFrame],
2258    frozen_spec: dict[str, dict[str, Any]],
2259    *,
2260    legs: list[str] | None = None,
2261    min_n_trades: int = 20,
2262    parity_tolerance_r: float = 0.01,
2263    fee_tolerance_bps: float = 1.0,
2264    latency_max_sec: float = 60.0,
2265    dd_breach_ratio: float = 1.5,
2266    n_bootstrap: int = 1000,
2267    seed: int = 42,
2268    label: str = "unnamed",
2269) -> PaperVerdict:
2270    """Parity-check the paper log against the frozen outcomes.
2271
2272    Paper is a forward test of the IMPLEMENTATION, not the edge.  This
2273    protocol answers: "does the paper engine execute the same strategy
2274    as the frozen spec?" — a parity checker, not a strategy
2275    kill-protocol.
2276
2277    Spec correctness is out of scope. This protocol validates that
2278    paper matches frozen, not that frozen is correct. Frozen
2279    correctness → ``run_full_pipeline`` on the backtest feed. A
2280    ``PARITY_PASS`` means "implementation executes the spec", not

Parity-check the paper log against the frozen outcomes.

Paper is a forward test of the IMPLEMENTATION, not the edge. This protocol answers: "does the paper engine execute the same strategy as the frozen spec?" — a parity checker, not a strategy kill-protocol.

Spec correctness is out of scope. This protocol validates that paper matches frozen, not that frozen is correct. Frozen correctness → run_full_pipeline on the backtest feed. A PARITY_PASS means "implementation executes the spec", not "the spec is valid".

The per-leg stage machine runs in the fixed order documented in the module docstring: parity stages 1-3 are n-agnostic, the operational data-checks (latency, exit direction) run only when their columns exist, and the n-gate fires only after they pass. SURVIVES_TO_LIVE demands execution evidence (fill direction and latency actually verified); PARITY_PASS attests the trade-level match when both data-checks were skipped — a parity-only attestation, never proof the edge is real. dd_comparison is populated on EVERY verdict, including PARITY_FAIL killed at any stage.

Class-specific sections (funding, pnl_decomposition) are opt-in via frozen_spec: absence = skipped, not inferred.

Args: paper_log: journal of the paper engine. Required columns leg, coin, entry_ts, exit_ts, exit_type, pnl_r plus sizing_rule (value read via .iloc[0]), and the required attribute paper_log.attrs["bar_delta_min"] (int minutes). Optional columns (absence sends the related check to checks_skipped): signal_ts, entry_price, exit_price, side ("long"/"short"), fee_r, size, funding_rate, pnl_delta, pnl_gamma, pnl_theta, pnl_vega, pnl_fee. frozen_outcomes: per-leg frozen (spec-executed) trade frames. Required columns coin, entry_ts, exit_ts, exit_type, pnl_r; optional fee_r, size, funding_rate, pnl_*. frozen_spec: per-leg spec dict. Required keys: exit_rules ({mtm_bars, tp_r, stop_buffer_atr}), exit_type_normalization (canonical -> alias list), fee ({taker_bps_per_leg, round_trip: "single"| "double"}), universe (list[str]; empty list = universe check skipped), sizing_rule, bar_delta_min and paper_window ({start, end}, pd.Timestamp-parseable; an empty dict derives the window from the frozen frame's own span). Optional: funding ({settlement_interval_hours, rate_tolerance_bps}; carry only) and pnl_decomposition ({enabled, components, tolerance_per_component_r}; options only). legs: legs to process (each must exist in frozen_outcomes and frozen_spec); None processes every paper_log leg in sorted order. min_n_trades: stage-5 gate on the matched-pair count. parity_tolerance_r: max per-pair |pnl_r| difference. fee_tolerance_bps: max per-pair fee difference (basis points). latency_max_sec: max (entry_ts - signal_ts) in seconds. dd_breach_ratio: stage-6 cap on paper/frozen max-drawdown ratio (drawdowns computed in each frame's row order). n_bootstrap: bootstrap draws for the mean-drift p-value. seed: RNG seed for the paired bootstrap. label: run label echoed in the interpretation strings.

Returns: PaperVerdict — every key documented on the TypedDict is always present (per_leg is None for single-leg runs); interpretation / next_step / what_would_change are filled strings quoting this run's facts (n_paper_trades, n_frozen_matched and n_ per firing issue), never the bare templates.

Raises: ValueError: on an empty paper_log or per-leg frames, missing required columns or the bar_delta_min attr, missing frozen_spec keys, unknown leg names (requested legs absent from frozen_outcomes/frozen_spec, paper legs without a frozen entry, or any name containing "portfolio"), unknown round_trip literals, exit_type tokens absent from exit_type_normalization, missing funding_rate / pnl_* columns when their spec sections demand them, non-positive tolerances, dd_breach_ratio <= 0, n_bootstrap < 1 and non-integer / below-minimum integer parameters.
