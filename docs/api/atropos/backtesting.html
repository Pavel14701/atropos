atropos.backtesting

Event-simulator backtest engine: signals to R, slot discipline, metrics.

The engine answers three questions a per-period return backtest cannot:

  • what is ONE signal worth (simulate_signal: optimistic vs pessimistic net R under the taker cost model, plus the maker-entry variants market_sim / maker_sim / maker_entry_sim);
  • which signals become trades when ONE slot is occupied at a time (run_position_state_machine: fills, force-closes, cooldowns);
  • which trades survive a concurrent-slot cap (run_admission_policy: FCFS vs REPLACE policies over rank-normalized scores).

Per-trade metrics (trade_curve_stats, per_trade_sharpe, bucketed_sharpe, pooled_stats) close the loop; they are DEFINED in atropos.backtest_metrics (single home) and re-exported here. They operate on the PER-TRADE R scale and are deliberately distinct from atropos.evaluation_metrics.sharpe_ratio, which annualizes a PER-PERIOD return series with a block-bootstrap CI: a per-trade t-stat of ~10+ corresponds to a per-trade Sharpe of only ~0.3-0.6, so the two must never be read interchangeably.

The taker cost model defaults are the validated engine constants (GEN_SLIP=0.0005, COMM=0.001, GAP=0.25, E_MULT=2.0, X_MULT=2.0), parameterized as CostModel instead of hardcoded.

Score contract for admission: candidates arriving from DIFFERENT model groups are compared only on WITHIN-GROUP rank-normalized scores (rank_normalize_group()); raw predict_proba outputs are not comparable across models (KNN probabilities are noisy and biased, calibrated GBM probabilities are not). If a CandidateGroup frame is used upstream, pass its normalized_scores column -- never the raw scores.

Run python -m atropos.backtesting for a synthetic demo.

 101@dataclass(frozen=True)
 102class CostModel:
 103    """Taker-path cost constants of the event simulator (all finite).
 104
 105    The defaults are the validated engine constants; every field can be
 106    overridden for sensitivity runs (e.g. ``comm=0.0`` for a
 107    frictionless world).
 108
 109    Args:
 110        gen_slip: general slippage as a fraction of price, charged once
 111            at entry and once at exit.
 112        comm: taker commission per side as a fraction of price; the
 113            round trip charges ``2 * comm``.
 114        gap: adverse gap at a stop exit, in ATR units.
 115        e_mult: entry-slippage pessimism multiplier.
 116        x_mult: exit-slippage pessimism multiplier; the extra exit
 117            penalty is ``(x_mult - 1) * gen_slip``, so values below 1
 118            would flip that penalty negative.
 119
 120    Raises:
 121        ValueError: if any field is not a finite number, ``gen_slip`` /
 122            ``comm`` / ``gap`` / ``e_mult`` is negative, or ``x_mult``
 123            is below 1.
 124
 125    Example::
 126
 127        >>> cost = CostModel(gen_slip=0.001)
 128        >>> (cost.gen_slip, cost.comm, cost.gap, cost.e_mult, cost.x_mult)
 129        (0.001, 0.001, 0.25, 2.0, 2.0)
 130        >>> CostModel(comm=0.0).comm
 131        0.0
 132        >>> CostModel(gen_slip=-1.0)
 133        Traceback (most recent call last):
 134            ...
 135        ValueError: gen_slip must be >= 0, got -1.0
 136    """
 137
 138    gen_slip: float = 0.0005
 139    comm: float = 0.001
 140    gap: float = 0.25
 141    e_mult: float = 2.0
 142    x_mult: float = 2.0
 143
 144    def __post_init__(self) -> None:
 145        """Reject non-finite or sign-flipped cost constants loudly."""
 146        for field_name in ("gen_slip", "comm", "gap", "e_mult"):
 147            value = validate_number(field_name, getattr(self, field_name))
 148            if value < 0.0:
 149                raise ValueError(f"{field_name} must be >= 0, got {value}")
 150        x_mult = validate_number("x_mult", self.x_mult)
 151        if x_mult < 1.0:
 152            raise ValueError(f"x_mult must be >= 1, got {x_mult}")

 173# score normalization (the admission seam)

 175def rank_normalize_group(scores: Any) -> np.ndarray:
 176    """Within-group rank normalization to ``[0, 1]`` with average ties.
 177
 178    Admission compares candidates coming from DIFFERENT model groups,
 179    so each candidate must carry its WITHIN-GROUP position, not a raw
 180    cross-model probability (KNN and calibrated GBM probabilities live
 181    on incomparable scales).  The mapping is
 182    ``(average_rank - 1) / (count - 1)`` via ``scipy.stats.rankdata``
 183    with ``method="average"``: tied scores share the AVERAGE of their
 184    rank positions, so a tie broken for display purposes can never leak
 185    into the normalized score.
 186
 187    Edge cases, pinned: a single-candidate group maps to exactly
 188    ``0.5`` (neutral - real groups have one candidate, and a neutral
 189    score neither wins nor loses a replacement contest), and an empty
 190    input maps to an empty output.  This is a different contract from
 191    ``atropos.ml_ensemble.rank_normalize`` (blend space, which maps
 192    ``count < 2`` to 0.0); here 0.5 is the admission-neutral value.
 193
 194    Args:
 195        scores: 1-D array-like of finite within-group scores.
 196
 197    Returns:
 198        1-D float64 array of normalized average ranks (higher score =
 199        higher value); monotone non-decreasing in ``scores``.
 200
 201    Raises:
 202        ValueError: if ``scores`` is not 1-D or contains non-finite
 203            values.
 204
 205    Example::
 206
 207        >>> rank_normalize_group(np.array([3.0, 1.0, 2.0])).tolist()
 208        [1.0, 0.0, 0.5]
 209        >>> rank_normalize_group(np.array([5.0, 5.0, 1.0])).tolist()
 210        [0.75, 0.75, 0.0]
 211        >>> rank_normalize_group(np.array([7.0])).tolist()
 212        [0.5]
 213    """
 214    flat = np.asarray(scores, dtype=np.float64)
 215    if flat.ndim != 1:
 216        raise ValueError(
 217            f"scores must be 1-D, got ndim={flat.ndim} of shape {flat.shape}"
 218        )
 219    count = int(flat.size)
 220    if count == 0:
 221        return np.zeros(0, dtype=np.float64)
 222    if count == 1:
 223        return np.full(1, 0.5, dtype=np.float64)
 224    if not bool(np.all(np.isfinite(flat))):
 225        raise ValueError("scores must be finite, got NaN/inf entries")
 226    ranks = np.asarray(rankdata(flat, method="average"), dtype=np.float64)
 227    return (ranks - 1.0) / float(count - 1)

 233def _validated_ohlc(
 234    opens: Any, highs: Any, lows: Any, closes: Any
 235) -> tuple[np.ndarray, np.ndarray, np.ndarray, np.ndarray]:
 236    """Coerce the four price series to equal-length finite 1-D arrays.
 237
 238    Raises:
 239        ValueError: if any series is not 1-D, the lengths differ, or
 240            any entry is NaN/inf.
 241    """
 242    arrays: list[np.ndarray] = []
 243    for name, values in (
 244        ("opens", opens),
 245        ("highs", highs),
 246        ("lows", lows),
 247        ("closes", closes),
 248    ):
 249        arr = np.asarray(values, dtype=np.float64)
 250        if arr.ndim != 1:
 251            raise ValueError(
 252                f"{name} must be 1-D, got ndim={arr.ndim} of shape"
 253                f" {arr.shape}"
 254            )
 255        if arr.size and not bool(np.all(np.isfinite(arr))):
 256            raise ValueError(f"{name} must be finite, got NaN/inf entries")
 257        arrays.append(arr)
 258    sizes = {arr.size for arr in arrays}
 259    if len(sizes) != 1:
 260        raise ValueError(
 261            "opens/highs/lows/closes must have the same length, got"
 262            f" {[arr.size for arr in arrays]}"
 263        )
 264    open_arr, high_arr, low_arr, close_arr = arrays
 265    return open_arr, high_arr, low_arr, close_arr

 299def _exit_scan(
 300    highs: np.ndarray,
 301    lows: np.ndarray,
 302    closes: np.ndarray,
 303    entry_idx: int,
 304    sign: float,
 305    *,
 306    fill: float,
 307    stop_level: float,
 308    target_level: float,
 309    denom: float,
 310    atr_value: float,
 311    hold_bars: int,
 312    cost: CostModel,
 313    maker_frac: float | None,
 314) -> SimResult:
 315    """Scan bars from the entry for the stop / target / time exit.
 316
 317    Single home of the engine's exit mechanics, shared by the taker
 318    sim and the maker sim:
 319
 320    * SL-first pessimism inside a bar (a bar touching BOTH levels is
 321      resolved as a stop);
 322    * stop exits pessimize by the extra exit slippage
 323      ``(x_mult - 1) * gen_slip`` PLUS the adverse ``gap * atr`` term;
 324    * target exits pessimize by the entry slippage ``e_mult *
 325      gen_slip`` only;
 326    * a time exit (close of the final hold bar, slipped) pessimizes by
 327      entry + extra exit slippage;
 328    * an entry bar opening beyond the stop is an immediate market
 329      scratch (never a win in gap-distance units).
 330
 331    ``maker_frac=None`` charges the full taker round trip
 332    ``2 * comm``; a fraction charges the round trip with the maker
 333    entry fee as part of the round-trip total: ``comm * (1 + frac)``
 334    (maker entry, taker exit).  On the maker path ``r_opt`` is
 335    undefined and reported as NaN.
 336    """
 337    if maker_frac is None:
 338        cost_r = (2 * cost.comm * fill + cost.gen_slip * fill) / denom
 339        r_opt_defined = True
 340    else:
 341        cost_r = (
 342            (cost.comm * (1 + maker_frac) + cost.gen_slip) * fill
 343        ) / denom
 344        r_opt_defined = False
 345    entry_slip_r = cost.e_mult * cost.gen_slip * fill / denom
 346    gap_through = (sign > 0 and fill < stop_level) or (
 347        sign < 0 and fill > stop_level
 348    )
 349    if gap_through:
 350        # the stop order fires immediately at market: a scratch
 351        xtr = (cost.x_mult - 1) * cost.gen_slip * abs(fill) / denom
 352        r_opt = float(-cost_r) if r_opt_defined else float("nan")
 353        return SimResult(
 354            r_opt=r_opt,
 355            r_pess=float(-cost_r - entry_slip_r - xtr),
 356            exit_idx=int(entry_idx),
 357        )
 358    n_bars = int(closes.size)
 359    last = min(n_bars - 1, entry_idx + hold_bars - 1)
 360    for bars_held, bar_idx in enumerate(range(entry_idx, last + 1)):
 361        stop_hit = (
 362            lows[bar_idx] <= stop_level
 363            if sign > 0
 364            else highs[bar_idx] >= stop_level
 365        )
 366        target_hit = (
 367            highs[bar_idx] >= target_level
 368            if sign > 0
 369            else lows[bar_idx] <= target_level
 370        )
 371        if stop_hit:
 372            net_r = (
 373                sign * (stop_level * (1 - sign * cost.gen_slip) - fill)
 374            ) / denom - cost_r
 375            gap_r = cost.gap * atr_value / denom
 376            xtr = (cost.x_mult - 1) * cost.gen_slip * abs(stop_level) / denom
 377            r_opt = float(net_r) if r_opt_defined else float("nan")
 378            return SimResult(
 379                r_opt=r_opt,
 380                r_pess=float(net_r - entry_slip_r - xtr - gap_r),
 381                exit_idx=int(bar_idx),
 382            )
 383        if target_hit:
 384            net_r = sign * (target_level - fill) / denom - cost_r
 385            r_opt = float(net_r) if r_opt_defined else float("nan")
 386            return SimResult(
 387                r_opt=r_opt,
 388                r_pess=float(net_r - entry_slip_r),
 389                exit_idx=int(bar_idx),
 390            )
 391        if bars_held == hold_bars - 1:
 392            exit_px = closes[bar_idx] * (1 - sign * cost.gen_slip)
 393            net_r = sign * (exit_px - fill) / denom - cost_r
 394            xtr = (cost.x_mult - 1) * cost.gen_slip * abs(exit_px) / denom
 395            r_opt = float(net_r) if r_opt_defined else float("nan")
 396            return SimResult(
 397                r_opt=r_opt,
 398                r_pess=float(net_r - entry_slip_r - xtr),
 399                exit_idx=int(bar_idx),
 400            )
 401    return SimResult(r_opt=float("nan"), r_pess=float("nan"), exit_idx=-1)

 407def simulate_signal(  # noqa: PLR0917  (donor OHLC-world signature)
 408    opens: Any,
 409    highs: Any,
 410    lows: Any,
 411    closes: Any,
 412    entry_idx: int,
 413    side: str,
 414    stop_price: float,
 415    target_price: float,
 416    hold_bars: int,
 417    atr_value: float,
 418    *,
 419    risk_ref: float | None = None,
 420    cost: CostModel = DEFAULT_COST,
 421) -> SimResult:
 422    """Simulate one signal from its entry bar under the taker model.
 423
 424    The entry fills at ``opens[entry_idx]``; the scan then walks
 425    forward at most ``hold_bars`` bars and resolves the first stop /
 426    target / time exit.  Returns ``{"r_opt", "r_pess", "exit_idx"}``:
 427    optimistic and pessimistic net R and the exit bar.
 428
 429    Contracts preserved from the engine:
 430
 431    * SL-first pessimism inside a bar: a bar touching BOTH the stop
 432      and the target is resolved as a stop.
 433    * A stop exit pessimizes by the extra exit slippage
 434      ``(x_mult - 1) * gen_slip`` PLUS the adverse ``gap * atr`` term;
 435      a target exit pessimizes by the entry slippage ``e_mult *
 436      gen_slip`` only; a time exit (close of the final hold bar,
 437      slipped) pessimizes by entry + extra exit slippage.
 438    * Gap-through-stop at ENTRY: when the entry bar already OPENS
 439      beyond the stop, live the stop order fires immediately at
 440      market - a scratch, never a +1R win in gap-distance units.  Both
 441      R values are the scratch (the pessimistic one adds the
 442      entry/exit pessimism terms).
 443    * ``risk_ref`` is the intended risk distance used as the R
 444      denominator (a panel ``risk_unit``); it defaults to the actual
 445      ``|entry fill - stop|``.  A non-positive or absent ``risk_ref``
 446      falls back to that actual distance.
 447    * No exit inside the hold window, or ``risk <= 0``: both R values
 448      are NaN and ``exit_idx`` is ``-1``.
 449    * An unresolved trade (``exit_idx == -1``) books neither P&L nor
 450      cost: the bundled round-trip ``cost_r`` is charged only on a
 451      resolved exit (the entry-bar gap-through scratch above DOES
 452      charge the full round trip - the stop fired, so the trade
 453      happened).
 454
 455    Args:
 456        opens: 1-D finite open prices.
 457        highs: 1-D finite high prices, same length as ``opens``.
 458        lows: 1-D finite low prices, same length as ``opens``.
 459        closes: 1-D finite close prices, same length as ``opens``.
 460        entry_idx: entry bar index (the fill bar), ``0 <= idx < len``.
 461        side: ``"long"`` or ``"short"``.
 462        stop_price: stop-loss price level.
 463        target_price: take-profit price level.
 464        hold_bars: maximum bars to hold (time exit on the last one);
 465            must be >= 1.
 466        atr_value: ATR in price units at entry (scales the stop-gap
 467            pessimism term).
 468        risk_ref: optional intended risk distance for the R
 469            denominator; must be finite and positive when given.
 470        cost: cost model; defaults to :data:`DEFAULT_COST`.
 471
 472    Returns:
 473        ``SimResult`` dict with ``r_opt``, ``r_pess`` and ``exit_idx``.
 474
 475    Raises:
 476        ValueError: if the price series are not 1-D finite arrays of
 477            equal length, ``entry_idx`` / ``hold_bars`` are not valid
 478            integers in range, ``side`` is not ``"long"``/``"short"``,
 479            or a scalar parameter is not finite.
 480
 481    Example::
 482
 483        >>> opens = [100.0, 100.0, 100.0, 100.0]
 484        >>> highs = [100.0, 100.0, 102.4, 100.0]
 485        >>> lows = [100.0, 100.0, 100.0, 100.0]
 486        >>> closes = [100.0, 100.0, 101.0, 100.0]
 487        >>> out = simulate_signal(
 488        ...     opens, highs, lows, closes, 0, "long", 99.0, 102.0,
 489        ...     4, 1.0,
 490        ... )
 491        >>> (round(out["r_opt"], 6), round(out["r_pess"], 6))
 492        (1.75, 1.65)
 493        >>> # data ends one bar after entry: the hold window is cut
 494        >>> # short, so no exit happens at all (the time exit needs the
 495        >>> # full window; a lone final bar cannot time-exit)
 496        >>> missed = simulate_signal(
 497        ...     opens, highs, lows, closes, 3, "long", 90.0, 130.0,
 498        ...     2, 1.0,
 499        ... )
 500        >>> (math.isnan(missed["r_opt"]), missed["exit_idx"])
 501        (True, -1)
 502    """
 503    open_arr, high_arr, low_arr, close_arr = _validated_ohlc(
 504        opens, highs, lows, closes
 505    )
 506    sign = _validated_direction(side)
 507    idx = _validated_entry_index(entry_idx, int(open_arr.size))
 508    stop_level = validate_number("stop_price", stop_price)
 509    target_level = validate_number("target_price", target_price)
 510    bars = validate_int("hold_bars", hold_bars, minimum=1)
 511    atr = validate_number("atr_value", atr_value)
 512    fill = float(open_arr[idx])
 513    denom = abs(fill - stop_level)
 514    if denom <= 0.0:
 515        return SimResult(r_opt=float("nan"), r_pess=float("nan"), exit_idx=-1)
 516    if risk_ref is not None and validate_number("risk_ref", risk_ref) > 0.0:
 517        denom = float(risk_ref)
 518    return _exit_scan(
 519        high_arr,
 520        low_arr,
 521        close_arr,
 522        idx,
 523        sign,
 524        fill=fill,
 525        stop_level=stop_level,
 526        target_level=target_level,
 527        denom=denom,
 528        atr_value=atr,
 529        hold_bars=bars,

 609def maker_sim(  # noqa: PLR0917  (donor OHLC-world signature)
 610    opens: Any,
 611    highs: Any,
 612    lows: Any,
 613    closes: Any,
 614    entry_idx: int,
 615    side: str,
 616    stop_price: float,
 617    target_price: float,
 618    limit_price: float,
 619    atr_value: float,
 620    maker_frac: float = MAKER_FRAC,
 621    *,
 622    hold_bars: int = HOLD_BARS,
 623    cost: CostModel = DEFAULT_COST,
 624) -> float:
 625    """Pessimistic R for a KNOWN limit fill at ``limit_price``.
 626
 627    The position opens at bar ``entry_idx`` at the limit price (the
 628    caller established the fill, e.g. via :func:`maker_entry_sim`).
 629    Mechanics mirror the taker sim with two execution differences:
 630
 631    * the round-trip fee total is ``comm * (1 + maker_frac)`` instead
 632      of ``2 * comm`` (the maker entry fee as part of the round-trip
 633      total; taker exit);
 634    * the outcome is computed from the ACTUAL fill price, so a better
 635      entry WIDENS the stop distance: each win is smaller in R but
 636      stop-outs become rarer.
 637
 638    Gap-through-stop guard: a limit filled beyond the stop fires the
 639    stop immediately at market - a scratch net of costs, never a
 640    ~+1R win measured in gap-distance units.
 641
 642    Args:
 643        opens: 1-D finite open prices.
 644        highs: 1-D finite high prices, same length as ``opens``.
 645        lows: 1-D finite low prices, same length as ``opens``.
 646        closes: 1-D finite close prices, same length as ``opens``.
 647        entry_idx: bar index at which the limit filled.
 648        side: ``"long"`` or ``"short"``.
 649        stop_price: stop-loss price level.
 650        target_price: take-profit price level.
 651        limit_price: the actual limit fill price.
 652        atr_value: ATR in price units at entry.
 653        maker_frac: maker entry fee as a fraction of the taker
 654            commission; must be >= 0 (1.0 == full taker round trip).
 655        hold_bars: maximum bars to hold; defaults to
 656            :data:`HOLD_BARS`.
 657        cost: cost model; defaults to :data:`DEFAULT_COST`.
 658
 659    Returns:
 660        Pessimistic net R from the actual fill price; NaN when the
 661        risk distance is non-positive or no exit happens inside the
 662        hold window.
 663
 664    Raises:
 665        ValueError: on invalid inputs (non-finite prices, bad side,
 666            negative ``maker_frac``, out-of-range indices).
 667
 668    Example::
 669
 670        >>> opens = [100.0] * 12
 671        >>> highs = [100.0] * 12
 672        >>> lows = [100.0] * 12
 673        >>> lows[2] = 99.5
 674        >>> highs[10] = 102.0
 675        >>> closes = [100.0] * 12
 676        >>> round(
 677        ...     maker_sim(opens, highs, lows, closes, 2, "long",
 678        ...               99.0, 102.0, 99.5, 1.0),
 679        ...     6,
 680        ... )
 681        4.4428
 682    """
 683    open_arr, high_arr, low_arr, close_arr = _validated_ohlc(
 684        opens, highs, lows, closes
 685    )
 686    sign = _validated_direction(side)
 687    idx = _validated_entry_index(entry_idx, int(open_arr.size))
 688    stop_level = validate_number("stop_price", stop_price)
 689    target_level = validate_number("target_price", target_price)
 690    limit = validate_number("limit_price", limit_price)
 691    atr = validate_number("atr_value", atr_value)
 692    frac = validate_number("maker_frac", maker_frac)
 693    if frac < 0.0:
 694        raise ValueError(f"maker_frac must be >= 0, got {maker_frac}")
 695    bars = validate_int("hold_bars", hold_bars, minimum=1)
 696    denom = abs(limit - stop_level)
 697    if denom <= 0.0:
 698        return float("nan")
 699    result = _exit_scan(
 700        high_arr,
 701        low_arr,
 702        close_arr,
 703        idx,
 704        sign,
 705        fill=limit,
 706        stop_level=stop_level,
 707        target_level=target_level,
 708        denom=denom,
 709        atr_value=atr,
 710        hold_bars=bars,
 711        cost=cost,
 712        maker_frac=frac,
 713    )
 714    return result["r_pess"]

 717def maker_entry_sim(  # noqa: PLR0917  (donor OHLC-world signature)
 718    opens: Any,
 719    highs: Any,
 720    lows: Any,
 721    closes: Any,
 722    entry_idx: int,
 723    side: str,
 724    stop_price: float,
 725    target_price: float,
 726    fill_price: float,
 727    atr_value: float,
 728    *,
 729    delta_atr: float = DEFAULT_DELTA_ATR,
 730    wait_bars: int = DEFAULT_WAIT_BARS,
 731    maker_frac: float = MAKER_FRAC,
 732    hold_bars: int = HOLD_BARS,
 733    cost: CostModel = DEFAULT_COST,
 734) -> float:
 735    """Maker-or-skip entry: place a limit into the zone, skip if missed.
 736
 737    The limit is placed ``delta_atr * ATR`` INTO the zone from the
 738    market-fill reference price ``fill_price`` (typically
 739    ``opens[entry_idx]``).  The fill scan STARTS on ``entry_idx``
 740    itself: a limit touched on the entry bar fills on that very bar
 741    (the earliest possible fill; a caller deciding on an earlier bar
 742    passes the LATER bar as ``entry_idx``).  The fill is
 743    deterministic in the price path: the
 744    order fills on the FIRST bar (within ``wait_bars``) whose range
 745    trades through the limit; a missed fill means a missed trade and
 746    contributes exactly 0 (maker-or-skip).  A limit closer than
 747    ``MIN_ZONE_ATR_FRAC * ATR`` to the stop is unfillable (NaN) - the
 748    zone would put the entry at or beyond the stop.
 749
 750    Determinism note: fills depend ONLY on the price path, so the
 751    same inputs reproduce the same outcome bit-for-bit (stronger than
 752    a seeded RNG draw).
 753
 754    Args:
 755        opens: 1-D finite open prices.
 756        highs: 1-D finite high prices, same length as ``opens``.
 757        lows: 1-D finite low prices, same length as ``opens``.
 758        closes: 1-D finite close prices, same length as ``opens``.
 759        entry_idx: the bar the fill is booked on.  The fill scan
 760            STARTS on this bar (a limit touched here fills HERE), so
 761            callers deciding on an earlier bar must pass the fill bar,
 762            not the decision bar.
 763        side: ``"long"`` or ``"short"``.
 764        stop_price: stop-loss price level.
 765        target_price: take-profit price level.
 766        fill_price: market-fill reference price, normally
 767            ``opens[entry_idx]``.
 768        atr_value: ATR in price units (scales the limit distance).
 769        delta_atr: limit distance into the zone, in ATR units; must
 770            be >= 0.
 771        wait_bars: bars to wait for a fill; must be >= 1.
 772        maker_frac: maker entry fee as a fraction of the taker
 773            commission; must be >= 0.
 774        hold_bars: maximum bars to hold after a fill; defaults to
 775            :data:`HOLD_BARS`.
 776        cost: cost model; defaults to :data:`DEFAULT_COST`.
 777
 778    Returns:
 779        Pessimistic net R of the filled trade, exactly ``0.0`` for a
 780        missed fill (maker-or-skip), NaN when the zone is unfillable
 781        or the filled position has no exit inside the hold window.
 782
 783    Raises:
 784        ValueError: on invalid inputs (same rules as
 785            :func:`maker_sim`).
 786
 787    Example::
 788
 789        >>> opens = [100.0] * 12
 790        >>> highs = [100.0] * 12
 791        >>> lows = [100.0] * 12
 792        >>> lows[2] = 99.5
 793        >>> highs[10] = 102.0
 794        >>> closes = [100.0] * 12
 795        >>> round(
 796        ...     maker_entry_sim(opens, highs, lows, closes, 0, "long",
 797        ...                     99.0, 102.0, 100.0, 1.0, delta_atr=0.5),
 798        ...     6,
 799        ... )
 800        4.4428
 801        >>> maker_entry_sim(opens, highs, lows, closes, 0, "long",
 802        ...                 99.0, 102.0, 100.0, 1.0, delta_atr=0.5,
 803        ...                 wait_bars=1)
 804        0.0
 805    """
 806    open_arr, high_arr, low_arr, close_arr = _validated_ohlc(
 807        opens, highs, lows, closes
 808    )
 809    sign = _validated_direction(side)
 810    idx = _validated_entry_index(entry_idx, int(open_arr.size))
 811    stop_level = validate_number("stop_price", stop_price)
 812    target_level = validate_number("target_price", target_price)
 813    reference = validate_number("fill_price", fill_price)
 814    atr = validate_number("atr_value", atr_value)
 815    delta = validate_number("delta_atr", delta_atr)
 816    if delta < 0.0:
 817        raise ValueError(f"delta_atr must be >= 0, got {delta_atr}")
 818    bars_wait = validate_int("wait_bars", wait_bars, minimum=1)
 819    limit = reference - sign * delta * atr
 820    zone_width = sign * (limit - stop_level)
 821    if zone_width <= MIN_ZONE_ATR_FRAC * atr:
 822        return float("nan")
 823    n_bars = int(open_arr.size)
 824    for bar_idx in range(idx, min(idx + bars_wait, n_bars)):
 825        touched = (
 826            low_arr[bar_idx] <= limit
 827            if sign > 0
 828            else high_arr[bar_idx] >= limit
 829        )
 830        if touched:
 831            return maker_sim(
 832                open_arr,
 833                high_arr,
 834                low_arr,
 835                close_arr,
 836                bar_idx,
 837                side,
 838                stop_level,
 839                target_level,
 840                limit,
 841                atr,
 842                maker_frac=maker_frac,
 843                hold_bars=hold_bars,
 844                cost=cost,
 845            )
 846    return 0.0

 927    Everything :class:`SimResult` carries (``r_opt`` / ``r_pess`` /
 928    ``exit_idx``, with the same NaN / ``-1`` unresolved convention)

 932

 935        exit_idx: resolved exit bar; ``-1`` when unresolved (no exit

 967    exit_price: float

 971def _intent_exit_details(
 972    highs: np.ndarray,
 973    lows: np.ndarray,
 974    closes: np.ndarray,
 975    sign: float,
 976    *,
 977    fill: float,
 978    stop_level: float,
 979    target_level: float,
 980    exit_idx: int,
 981    denom: float,
 982    cost: CostModel,
 983) -> tuple[str, float, float]:
 984    """Label the exit bar that the shared scan already resolved.
 985
 986    Precondition: ``exit_idx`` is a RESOLVED exit bar returned by
 987    :func:`_exit_scan` (never ``-1``).  The scan decides WHICH bar
 988    exits; this helper only names the branch the scan took at that
 989    bar, in the scan's own branch order (entry-bar gap-through
 990    scratch, then stop, then target, else the time exit), and reports
 991    the exact price the scan's ``r_opt`` formula used for that branch
 992    plus the bundled round-trip ``cost_r`` in R.  Prices mirror
 993    :func:`_exit_scan` line-for-line.
 994
 995    Returns:
 996        ``(exit_reason, exit_price, costs_r)`` with ``exit_reason`` in
 997        ``("sl", "tp", "time")``.
 998    """
 999    cost_r = (2 * cost.comm * fill + cost.gen_slip * fill) / denom
1000    gap_through = (sign > 0 and fill < stop_level) or (
1001        sign < 0 and fill > stop_level
1002    )
1003    if gap_through:
1004        # entry bar opened beyond the stop: market scratch at the fill
1005        return "sl", float(fill), cost_r
1006    stop_hit = (
1007        lows[exit_idx] <= stop_level
1008        if sign > 0
1009        else highs[exit_idx] >= stop_level
1010    )
1011    if stop_hit:
1012        exit_px = float(stop_level * (1 - sign * cost.gen_slip))
1013        return "sl", exit_px, cost_r
1014    target_hit = (
1015        highs[exit_idx] >= target_level
1016        if sign > 0
1017        else lows[exit_idx] <= target_level
1018    )
1019    if target_hit:
1020        return "tp", float(target_level), cost_r
1021    exit_px = float(closes[exit_idx] * (1 - sign * cost.gen_slip))
1022    return "time", exit_px, cost_r

1025def simulate_intents(
1026    intents: Any,
1027    opens: Any,
1028    highs: Any,
1029    lows: Any,
1030    closes: Any,
1031    *,
1032    cost: CostModel = DEFAULT_COST,
1033) -> list[SimIntentResult]:
1034    """Batch-simulate trade intents under the taker cost model.
1035
1036    For every :class:`TradeIntent` this runs THE SAME code path as
1037    :func:`simulate_signal` -- the shared :func:`_exit_scan` exit
1038    mechanics and its cost/pessimism stack, driven through
1039    :func:`simulate_signal` itself -- so SL-first pessimism inside a
1040    bar (a bar touching BOTH levels resolves as a stop) and the
1041    gap-through-stop-at-entry market scratch are identical to the
1042    single-signal sim by construction, not by reimplementation.
1043
1044    This function is the DELEGATION TARGET of the Book layer
1045    (:mod:`atropos.book`, later checkpoint): the equality pin "a Book
1046    trade == a simulated trade" for legs without signal exits is
1047    pinned against THIS public function, not against the private
1048    scan.
1049
1050    Args:
1051        intents: sequence of :class:`TradeIntent` objects; order is
1052            preserved and the output length equals ``len(intents)``.
1053        opens: 1-D finite open prices.
1054        highs: 1-D finite high prices, same length as ``opens``.
1055        lows: 1-D finite low prices, same length as ``opens``.
1056        closes: 1-D finite close prices, same length as ``opens``.
1057        cost: cost model; defaults to :data:`DEFAULT_COST`.
1058
1059    Returns:
1060        One :class:`SimIntentResult` per intent, in input order.
1061
1062    Raises:
1063        ValueError: if the price series are not 1-D finite arrays of
1064            equal length, or an intent's ``entry_idx`` is not a valid
1065            integer inside ``[0, len(opens))`` (the error names the
1066            intent position).
1067
1068    Example::
1069
1070        >>> opens = np.full(6, 100.0)
1071        >>> highs = np.full(6, 100.0)
1072        >>> highs[1] = 101.0
1073        >>> lows = np.full(6, 100.0)
1074        >>> closes = np.full(6, 100.0)
1075        >>> intent = TradeIntent(0, 1, 99.0, 101.0, 4, 1.0)
1076        >>> out = simulate_intents([intent], opens, highs, lows, closes)[0]
1077        >>> (out["exit_idx"], out["exit_reason"])
1078        (1, 'tp')
1079        >>> (round(out["r_opt"], 6), round(out["r_pess"], 6))
1080        (0.75, 0.65)
1081        >>> (out["fill_price"], out["exit_price"])
1082        (100.0, 101.0)
1083        >>> (round(out["costs_r"], 6), out["risk_ref"])
1084        (0.25, 1.0)
1085        >>> # identical to the single-signal sim by construction:
1086        >>> ref = simulate_signal(
1087        ...     opens, highs, lows, closes, 0, "long", 99.0, 101.0, 4, 1.0,
1088        ... )
1089        >>> (out["r_opt"], out["r_pess"], out["exit_idx"]) == (
1090        ...     ref["r_opt"], ref["r_pess"], ref["exit_idx"],
1091        ... )
1092        True
1093        >>> # entry at the last bar: the hold window is cut short, so
1094        >>> # no exit happens at all (same unresolved contract as
1095        >>> # simulate_signal: NaN R, empty reason, no cost)
1096        >>> missed = simulate_intents(
1097        ...     [TradeIntent(5, 1, 99.0, 101.0, 2, 1.0)],
1098        ...     opens, highs, lows, closes,
1099        ... )[0]
1100        >>> (missed["exit_idx"], missed["exit_reason"], missed["costs_r"])

1192def pessimistic_r(
1193    *,
1194    risk_unit: float,
1195    fill_price: float,
1196    sl_price: float,
1197    exit_reason: str,
1198    exit_price: float,
1199    atr_i: float,
1200    r_net: float,
1201    cost: CostModel = DEFAULT_COST,
1202) -> float:
1203    """Pessimistic net R of one labeled panel row (taker cost model).
1204
1205    The pessimism stack mirrors :func:`simulate_signal`: the entry
1206    slippage ``e_mult * gen_slip`` is always charged; a stop exit
1207    adds the extra exit slippage ``(x_mult - 1) * gen_slip`` on the
1208    stop price plus the adverse ``gap * atr`` term; a time exit adds
1209    the extra exit slippage on the exit price; a target exit carries
1210    no penalty beyond the entry slippage.
1211
1212    Args:
1213        risk_unit: intended risk distance (the R denominator); must
1214            be > 0.
1215        fill_price: entry fill price of the trade.
1216        sl_price: stop-loss price level (used by ``"sl"`` exits).
1217        exit_reason: ``"sl"``, ``"tp"`` or ``"time"``.
1218        exit_price: exit price (used by ``"time"`` exits).
1219        atr_i: ATR in price units at the trade's entry bar.
1220        r_net: isolated net R of the row (the optimistic bookkeeping).
1221        cost: cost model; defaults to :data:`DEFAULT_COST`.
1222
1223    Returns:
1224        ``r_net`` minus the pessimism stack.
1225
1226    Raises:
1227        ValueError: if ``risk_unit`` is not a finite positive number,
1228            any price input is not finite, or ``exit_reason`` is not
1229            one of ``"sl"`` / ``"tp"`` / ``"time"``.
1230
1231    Example::
1232
1233        >>> round(
1234        ...     pessimistic_r(
1235        ...         risk_unit=1.0, fill_price=100.0, sl_price=99.0,
1236        ...         exit_reason="sl", exit_price=99.0, atr_i=0.4,
1237        ...         r_net=2.0,
1238        ...     ),
1239        ...     6,
1240        ... )
1241        1.7505
1242    """
1243    risk = validate_number("risk_unit", risk_unit)
1244    if risk <= 0.0:
1245        raise ValueError(f"risk_unit must be > 0, got {risk_unit}")
1246    fill = validate_number("fill_price", fill_price)
1247    sl_level = validate_number("sl_price", sl_price)
1248    exit_px = validate_number("exit_price", exit_price)
1249    atr_value = validate_number("atr_i", atr_i)
1250    net = validate_number("r_net", r_net)
1251    if exit_reason not in _EXIT_REASONS:
1252        raise ValueError(
1253            f"exit_reason must be one of {_EXIT_REASONS}, got {exit_reason!r}"
1254        )
1255    penalty = cost.e_mult * cost.gen_slip * fill / risk
1256    if exit_reason == "sl":
1257        penalty += (cost.x_mult - 1) * cost.gen_slip * abs(sl_level) / risk
1258        penalty += cost.gap * atr_value / risk
1259    elif exit_reason == "time":
1260        penalty += (cost.x_mult - 1) * cost.gen_slip * abs(exit_px) / risk
1261    return float(net - penalty)

1323def _reconstructed_force_close_r(
1324    open_record: dict[str, Any],
1325    close_bar: int,
1326    *,
1327    opens: Any,
1328    highs: Any,
1329    lows: Any,
1330    closes: Any,
1331    cost: CostModel,
1332) -> float:
1333    """Recompute the open trade's pessimistic P&L up to ``close_bar``.
1334
1335    Runs :func:`simulate_signal` from the ORIGINAL entry (fill at
1336    ``decision_idx + 1``, same stop/target) with the hold window
1337    truncated so the time exit lands on ``close_bar``: if the stop or
1338    target was hit earlier the scan returns that earlier exit, which
1339    is the truthful path.  The open row may carry ``atr_entry`` (gap
1340    penalty; defaults to 0.0 when absent) and ``risk_ref`` (R
1341    denominator; optional).
1342
1343    A force-close on a bar BEFORE the fill (``close_bar < decision_idx
1344    + 1``) means the trade never existed at that point: exactly 0.0.
1345
1346    Raises:
1347        ValueError: if the price series were not provided, or a
1348            stop/target/atr/risk value is invalid.
1349    """
1350    if opens is None or highs is None or lows is None or closes is None:
1351        raise ValueError(
1352            "allow_reverse=True needs the opens/highs/lows/closes price"
1353            " series to reconstruct the force-closed trade's P&L; pass"
1354            " them as keyword arguments"
1355        )
1356    fill_idx = open_record["decision_idx"] + 1
1357    if close_bar < fill_idx:
1358        return 0.0
1359    row = open_record["row"]
1360    stop_level = validate_number("stop_price", row["stop_price"])
1361    target_level = validate_number("target_price", row["target_price"])
1362    atr_raw = row.get("atr_entry")
1363    atr_value = (
1364        0.0 if atr_raw is None else validate_number("atr_entry", atr_raw)
1365    )
1366    risk_raw = row.get("risk_ref")
1367    risk_ref = (
1368        None if risk_raw is None else validate_number("risk_ref", risk_raw)
1369    )
1370    result = simulate_signal(
1371        opens,
1372        highs,
1373        lows,
1374        closes,
1375        fill_idx,
1376        open_record["side"],
1377        stop_level,
1378        target_level,
1379        close_bar - fill_idx + 1,
1380        atr_value,
1381        risk_ref=risk_ref,
1382        cost=cost,
1383    )
1384    return result["r_pess"]

1387def run_position_state_machine(
1388    signals_df: pd.DataFrame,
1389    *,
1390    allow_reverse: bool = False,
1391    same_bar_reentry: bool = False,
1392    cooldown: int = 0,
1393    opens: Any = None,
1394    highs: Any = None,
1395    lows: Any = None,
1396    closes: Any = None,
1397    cost: CostModel = DEFAULT_COST,
1398) -> pd.DataFrame:
1399    """Decide which candidate signals become actual trades.
1400
1401    The dataset builder simulates every candidate in isolation; live,
1402    one slot is occupied at a time.  This machine walks the signals
1403    chronologically and labels each one ``"taken"`` or ``"skipped"``.
1404    Transition specification (documented decisions):
1405
1406    * a signal decided at bar ``d`` fills at ``d + 1`` (generator
1407      rule; validated on the input frame);
1408    * while a position is open (until its ``exit_idx``), ALL new
1409      signals are skipped (reason ``"in_position"``), except under
1410      ``allow_reverse``: an opposite-side signal at bar ``d < exit_idx``
1411      force-closes the open trade at bar ``d`` - its row is flagged
1412      with ``force_exit_idx = d`` AND ``force_close_r``, the P&L
1413      RECOMPUTED to bar ``d`` via :func:`simulate_signal` from the
1414      original entry with the same stop/target (the row's isolated
1415      ``r_pess``/``exit_idx`` stay STALE; read ``force_close_r``
1416      instead), then the new side opens at ``d + 1``;
1417    * a same-bar exit + signal (decision bar == exit bar) is skipped
1418      (``"same_bar_after_exit"``) unless ``same_bar_reentry`` - the
1419      SL-first pessimism rule means the position is still held during
1420      that bar; with the flag set the signal TAKES the slot (with
1421      ``cooldown > 0`` the cooldown still applies on the exit bar);
1422    * after an exit, ``cooldown`` further decision bars are blocked
1423      (``"cooldown"``; ``cooldown=0`` keeps equivalence with the
1424      isolated simulator);
1425    * several signals on one bar: highest ``priority`` wins, ties
1426      broken by side then stable input order (deterministic);
1427    * a trade whose ``exit_idx == -1`` (data ended while open) holds
1428      the slot until the end of data (later signals get
1429      ``"data_ended_open"``).
1430
1431    Args:
1432        signals_df: candidate signals; required columns
1433            ``decision_idx`` (int >= 0), ``side`` ("long"/"short"),
1434            ``exit_idx`` (int >= decision_idx + 1, or exactly -1);
1435            optional ``priority`` (finite; default 0.0).  For
1436            force-close reconstruction the open rows also need
1437            ``stop_price``/``target_price`` (required under
1438            ``allow_reverse``) and optionally ``atr_entry``/``risk_ref``.
1439        allow_reverse: let an opposite-side signal force-close the
1440            open trade at its decision bar.
1441        same_bar_reentry: allow a signal decided on the exit bar to
1442            open the next position.
1443        cooldown: decision bars blocked after an exit; must be >= 0.
1444        opens: 1-D finite open prices; REQUIRED for reconstruction
1445            when a force-close actually fires.
1446        highs: 1-D finite high prices (force-close reconstruction).
1447        lows: 1-D finite low prices (force-close reconstruction).
1448        closes: 1-D finite close prices (force-close reconstruction).
1449        cost: cost model for the ``force_close_r`` reconstruction;
1450            defaults to :data:`DEFAULT_COST`.
1451
1452    Returns:
1453        DataFrame of ALL signals in processed (chronological,
1454        priority-sorted) order: the input columns plus ``status``
1455        ("taken"/"skipped"), ``reason`` (empty string for taken rows;
1456        one of ``"in_position"``, ``"same_bar_after_exit"``,
1457        ``"cooldown"``, ``"data_ended_open"`` for skipped rows),
1458        ``force_exit_idx`` (NaN unless the row was force-closed) and
1459        ``force_close_r`` (NaN unless the row was force-closed).
1460
1461    Raises:
1462        ValueError: if required columns are missing, a row violates
1463            the generator rule, ``side``/``priority`` values are
1464            invalid, ``allow_reverse`` is set without the
1465            ``stop_price``/``target_price`` columns, a force-close
1466            fires without the price series, or ``cooldown`` is not an
1467            integer >= 0.
1468
1469    Example::
1470
1471        >>> signals = pd.DataFrame(
1472        ...     {
1473        ...         "decision_idx": [3, 5, 7],
1474        ...         "side": ["long", "long", "long"],
1475        ...         "exit_idx": [10, 12, 14],
1476        ...     }
1477        ... )
1478        >>> replay = run_position_state_machine(signals)
1479        >>> replay["status"].tolist()
1480        ['taken', 'skipped', 'skipped']
1481        >>> replay["reason"].tolist()
1482        ['', 'in_position', 'in_position']
1483    """
1484    cooldown_bars = validate_int("cooldown", cooldown, minimum=0)
1485    if allow_reverse:
1486        for name in ("stop_price", "target_price"):
1487            if name not in signals_df.columns:
1488                raise ValueError(
1489                    f"allow_reverse=True requires the {name!r} column on"
1490                    " signals_df for the force-close reconstruction"
1491                )
1492    records = _validated_signal_records(signals_df)
1493    order = sorted(
1494        records,
1495        key=lambda rec: (
1496            rec["decision_idx"],
1497            -rec["priority"],
1498            rec["side"],
1499            rec["position"],
1500        ),
1501    )
1502    out_rows = _walk_signal_transitions(
1503        order,
1504        allow_reverse=allow_reverse,
1505        same_bar_reentry=same_bar_reentry,
1506        cooldown_bars=cooldown_bars,
1507        opens=opens,
1508        highs=highs,
1509        lows=lows,
1510        closes=closes,
1511        cost=cost,
1512    )
1513    if not out_rows:
1514        return pd.DataFrame(
1515            columns=list(signals_df.columns) + list(_OUTPUT_COLUMNS)
1516        )
1517    return pd.DataFrame(out_rows)

1520def _walk_signal_transitions(
1521    order: list[dict[str, Any]],
1522    *,
1523    allow_reverse: bool,
1524    same_bar_reentry: bool,
1525    cooldown_bars: int,
1526    opens: Any,
1527    highs: Any,
1528    lows: Any,
1529    closes: Any,
1530    cost: CostModel,
1531) -> list[dict[str, Any]]:
1532    """Walk the ordered records and label each one taken/skipped.
1533
1534    One iteration of the documented transition specification; see
1535    :func:`run_position_state_machine` for the contract.  Returns the
1536    output row dicts in processed order.
1537
1538    Raises:
1539        ValueError: when a force-close fires without the price series.
1540    """
1541    out_rows: list[dict[str, Any]] = []
1542    busy_until = _NO_SLOT
1543    busy_side: str | None = None
1544    open_ended = False
1545    open_record: dict[str, Any] | None = None
1546    open_row: dict[str, Any] | None = None
1547    for record in order:
1548        out_row: dict[str, Any] = dict(record["row"])
1549        out_row["status"] = "skipped"
1550        out_row["reason"] = ""
1551        out_row["force_exit_idx"] = float("nan")
1552        out_row["force_close_r"] = float("nan")
1553        decision = record["decision_idx"]
1554        if open_ended:
1555            out_row["reason"] = "data_ended_open"
1556            out_rows.append(out_row)
1557            continue
1558        same_bar_reentry_ok = decision == busy_until and same_bar_reentry
1559        if decision == busy_until and not same_bar_reentry:
1560            out_row["reason"] = "same_bar_after_exit"
1561            out_rows.append(out_row)
1562            continue
1563        if decision <= busy_until and not same_bar_reentry_ok:
1564            reverse = (
1565                busy_side is not None
1566                and allow_reverse
1567                and record["side"] != busy_side
1568            )
1569            if reverse and open_record is not None and open_row is not None:
1570                # force-close the open trade at bar d and RECOMPUTE its
1571                # P&L to d (its isolated r_pess/exit_idx are stale)
1572                open_row["force_exit_idx"] = float(decision)
1573                open_row["force_close_r"] = _reconstructed_force_close_r(
1574                    open_record,
1575                    decision,
1576                    opens=opens,
1577                    highs=highs,
1578                    lows=lows,
1579                    closes=closes,
1580                    cost=cost,
1581                )
1582                out_row["status"] = "taken"
1583                out_rows.append(out_row)
1584                open_record = record
1585                open_row = out_row
1586                busy_until = record["exit_idx"]
1587                busy_side = record["side"]
1588                open_ended = busy_until < 0
1589                continue
1590            out_row["reason"] = "in_position"
1591            out_rows.append(out_row)
1592            continue
1593        if decision < busy_until + cooldown_bars:
1594            out_row["reason"] = "cooldown"
1595            out_rows.append(out_row)
1596            continue
1597        out_row["status"] = "taken"
1598        out_rows.append(out_row)
1599        open_record = record
1600        open_row = out_row
1601        busy_until = record["exit_idx"]
1602        busy_side = record["side"]
1603        open_ended = busy_until < 0
1604    return out_rows

1619        ValueError: on any missing key or non-finite value.

1660def run_admission_policy(
1661    trades: list[dict[str, Any]],
1662    *,
1663    cap: int,
1664    policy: str = "fcfs",
1665) -> dict[str, Any]:
1666    """Replay one portfolio admission policy over a candidate stream.
1667
1668    The policies are A PRIORI rules, not fitted parameters: neither
1669    FCFS nor REPLACE-low/high is tuned on the stream it is judged on,
1670    so the admission layer adds no in-sample contamination to the
1671    verdict it accompanies.
1672
1673    Engine finding (robustness checks): first-come-first-served
1674    capping rejects BETTER trades - on the donor's measured 1040-trade
1675    stream the rejected mean r_pess was +0.484R vs +0.441R for the
1676    accepted, a pure capacity loss whose reject rate drifted 16% -> 24%
1677    as candidate density grew.  The REPLACE policies exist because of
1678    this finding; the test suite carries the executable version of the
1679    proof (a stream where the best candidate arrives second loses it
1680    under FCFS but wins under REPLACE-low).
1681
1682    Policies:
1683
1684    * ``"fcfs"`` - slots full -> reject (reason ``"capacity"``).
1685    * ``"replace_low"`` - slots full -> if the new within-group score
1686      beats the worst open score, close the worst and take the new;
1687      the replaced trade contributes 0 (conservative: a mid-flight
1688      close is assumed to give back).  A candidate not beating the
1689      worst open score is rejected (reason ``"inferior_score"``).
1690    * ``"replace_high"`` - same selection, but the replaced trade
1691      keeps its full isolated ``r_pess`` (optimistic bound).
1692
1693    Realized equity is EVENT-based (R credited at each trade's
1694    ``ts_exit``), so the drawdown is not flattered by daily
1695    aggregation.  Score ties are broken by the secondary key
1696    ``candidate_id`` (ascending; stream arrival position when absent),
1697    so equal-score candidates resolve deterministically.
1698
1699    Args:
1700        trades: candidate trade stream, each a dict with keys
1701            ``ts_entry``, ``ts_exit`` (timestamps in one common unit),
1702            ``s`` (score) and ``r_pess`` (isolated pessimistic R);
1703            optional ``candidate_id`` (int >= 0).  Scores MUST be
1704            WITHIN-GROUP rank-normalized
1705            (:func:`rank_normalize_group`); raw cross-model
1706            probabilities are not comparable.  If a ``CandidateGroup``
1707            frame is used upstream, pass its ``normalized_scores``
1708            column as ``s`` - never the raw ``scores``.
1709        cap: maximum concurrent slots; must be >= 1.
1710        policy: ``"fcfs"``, ``"replace_low"`` or ``"replace_high"``.
1711
1712    Returns:
1713        Dict with keys ``policy``, ``cap``, ``accepted`` (trade dicts),
1714        ``rejected`` (trade dicts + ``reason``), ``replaced`` (trade
1715        dicts + ``reason="replaced"``), ``equity_curve`` (event-based
1716        cumulative R at exits), ``max_drawdown_r``, ``final_equity_r``
1717        and ``summary`` (the compact ``{"n", "ev", "dd", "replaced"}``
1718        report row).
1719
1720    Raises:
1721        ValueError: if ``cap`` is not an integer >= 1, ``policy`` is
1722            unknown, ``trades`` is empty or not a list of dicts, or a
1723            trade dict misses a required key or carries a non-finite
1724            value.
1725
1726    Example::
1727
1728        >>> trades = [
1729        ...     {"ts_entry": 0, "ts_exit": 10, "s": 0.8, "r_pess": 1.0},
1730        ...     {"ts_entry": 1, "ts_exit": 20, "s": 0.9, "r_pess": 0.5},
1731        ... ]
1732        >>> fcfs = run_admission_policy(trades, cap=1, policy="fcfs")
1733        >>> fcfs["summary"]
1734        {'n': 1, 'ev': 1.0, 'dd': 0.0, 'replaced': 0}
1735        >>> swap = run_admission_policy(trades, cap=1, policy="replace_low")
1736        >>> [trade["s"] for trade in swap["accepted"]]
1737        [0.8, 0.9]
1738        >>> [trade["s"] for trade in swap["replaced"]]
1739        [0.8]
1740        >>> swap["summary"]["ev"]
1741        0.5
1742    """
1743    slots = validate_int("cap", cap, minimum=1)
1744    if policy not in _ADMISSION_POLICIES:
1745        raise ValueError(
1746            f"policy must be one of {list(_ADMISSION_POLICIES)}, got"
1747            f" {policy!r}"
1748        )
1749    if not isinstance(trades, list) or not trades:
1750        raise ValueError("trades must be a non-empty list of trade dicts")
1751    normalized = [
1752        _validated_trade(trade, position)
1753        for position, trade in enumerate(trades)
1754    ]
1755    open_slots: list[dict[str, Any]] = []
1756    entered: list[dict[str, Any]] = []
1757    rejected: list[dict[str, Any]] = []
1758    replaced: list[dict[str, Any]] = []
1759    for item in normalized:
1760        admitted, rejected_out, displaced = _admit_item(
1761            item, open_slots, slots=slots, policy=policy
1762        )
1763        if admitted is not None:
1764            entered.append(admitted)
1765        if rejected_out is not None:
1766            rejected.append(rejected_out)
1767        if displaced is not None:
1768            replaced.append(displaced)
1769    events = _realized_events(entered, replaced, policy)
1770    return {
1771        "policy": policy,
1772        "cap": slots,
1773        "accepted": [dict(item["row"]) for item in entered],
1774        "rejected": rejected,
1775        "replaced": [
1776            dict(item["row"]) | {"reason": "replaced"} for item in replaced
1777        ],
1778        "equity_curve": events["equity"],
1779        "max_drawdown_r": events["drawdown"],
1780        "final_equity_r": events["final_equity"],
1781        "summary": {
1782            "n": len(entered),
1783            "ev": events["final_equity"],
1784            "dd": events["drawdown"],
1785            "replaced": len(replaced),
1786        },
1787    }

1790def _admit_item(
1791    item: dict[str, Any],
1792    open_slots: list[dict[str, Any]],
1793    *,
1794    slots: int,
1795    policy: str,
1796) -> tuple[
1797    dict[str, Any] | None, dict[str, Any] | None, dict[str, Any] | None
1798]:
1799    """Admit one candidate against the currently open slots.
1800
1801    Frees expired slots, then applies the policy.  Returns ``(admitted,
1802    rejected, displaced)``: exactly one of admitted/rejected is set;
1803    ``displaced`` is the worst open holder only when the candidate took
1804    its slot under a REPLACE policy.  Score ties never displace (a
1805    candidate must STRICTLY beat the worst open score); the worst
1806    holder itself is the lowest ``score``, ties broken by the stable
1807    ``tie_key`` (candidate_id ascending, else arrival position).
1808    """
1809    open_slots[:] = [
1810        held for held in open_slots if held["ts_exit"] > item["ts_entry"]
1811    ]
1812    if len(open_slots) < slots:
1813        open_slots.append(item)
1814        return item, None, None
1815    if policy == "fcfs":
1816        return None, dict(item["row"]) | {"reason": "capacity"}, None
1817    worst = min(open_slots, key=lambda held: (held["score"], held["tie_key"]))
1818    if item["score"] > worst["score"]:
1819        open_slots.remove(worst)
1820        open_slots.append(item)
1821        return item, None, worst
1822    return None, dict(item["row"]) | {"reason": "inferior_score"}, None

1825def _realized_events(
1826    entered: list[dict[str, Any]],
1827    replaced: list[dict[str, Any]],
1828    policy: str,
1829) -> dict[str, Any]:
1830    """Event-based equity of the accepted stream (R credited at exits).
1831
1832    Replaced trades contribute 0 under ``replace_low`` (a mid-flight
1833    close is assumed to give back) and their full isolated ``r_pess``
1834    under ``replace_high`` (optimistic bound).
1835
1836    Returns ``{"equity", "drawdown", "final_equity"}`` with an honest
1837    all-zero scaffold when nothing was entered.
1838
1839    Peak convention: a 0.0 baseline is PREPENDED to the equity curve,
1840    so an opening loss registers as drawdown -- deliberately distinct
1841    from ``atropos.backtest_metrics.trade_curve_stats``, whose peak
1842    starts at the first trade (both conventions are test-pinned).
1843    """
1844    replaced_ids = {id(item) for item in replaced}
1845    events: list[tuple[float, float]] = []
1846    for item in entered:
1847        if id(item) in replaced_ids:
1848            contribution = 0.0 if policy == "replace_low" else item["r_pess"]
1849        else:
1850            contribution = item["r_pess"]
1851        events.append((item["ts_exit"], contribution))
1852    events.sort(key=lambda pair: pair[0])
1853    if not events:
1854        return {
1855            "equity": np.zeros(0, dtype=np.float64),
1856            "drawdown": 0.0,
1857            "final_equity": 0.0,
1858        }
1859    equity = np.cumsum(
1860        np.asarray([pair[1] for pair in events], dtype=np.float64)
1861    )
1862    peaks = np.maximum.accumulate(np.concatenate([[0.0], equity]))
1863    return {
1864        "equity": equity,
1865        "drawdown": float(np.max(peaks[1:] - equity)),
1866        "final_equity": float(equity[-1]),
1867    }

162def bucketed_sharpe(r_net: Any, ts_ms: Any, bucket_days: int = 7) -> float:
163    """Annualized Sharpe from calendar-bucketed R sums.
164
165    The honest annualization for trade-R sequences: aggregate R per
166    time bucket (default week), then
167    ``mean_bucket / std_bucket * sqrt(buckets_per_year)``.  Bucketing
168    absorbs intra-bucket overlap (one slot per asset) and cross-asset
169    pooling, which otherwise inflate a naive ``sqrt(n)`` annualization
170    by an order of magnitude.
171
172    Bucket boundaries follow ``floor((ts - ts_min) / bucket_ms)``: a
173    trade stamped exactly on a boundary falls into the NEWER bucket.
174    Interior buckets with no trades contribute a 0.0 sum (a genuine
175    flat week that the dispersion must see); trailing empty time after
176    the last trade creates no bucket.  Contrast
177    :func:`atropos.evaluation_metrics.sharpe_ratio`, which annualizes a
178    fixed-grid per-period stream by ``sqrt(periods)`` and takes no
179    timestamps at all.
180
181    NaN policy: fewer than two finite (trade, timestamp) rows, fewer
182    than two buckets, or zero bucket dispersion yields NaN (honest,
183    not 0).
184
185    Args:
186        r_net: net R per trade; non-finite entries are dropped.
187        ts_ms: trade timestamps in milliseconds, aligned positionally
188            with ``r_net``; non-finite stamps drop their rows.
189        bucket_days: bucket width in days, integer >= 1.
190
191    Returns:
192        The annualized Sharpe ratio, or NaN.
193
194    Raises:
195        ValueError: if ``bucket_days`` is not an integer >= 1; raised
196            before the data is touched.
197
198    Example::
199
200        >>> day = 86_400_000
201        >>> stamps = np.arange(10) * day
202        >>> stream = np.array([1.0, 1, 1, 1, 1, 1, 1, 2, 2, 2])
203        >>> round(bucketed_sharpe(stream, stamps), 6)
204        66.400974
205        >>> math.isnan(bucketed_sharpe([1.0], [0.0]))
206        True
207    """
208    bucket_days = validate_int("bucket_days", bucket_days)
209    trades, stamps = align_inputs(r_net, ts_ms)
210    if trades.size < 2:
211        return math.nan
212    bucket_ms = float(bucket_days) * _DAY_MS
213    bucket_idx = np.floor((stamps - stamps.min()) / bucket_ms).astype(
214        np.int64
215    )
216    # bincount keeps interior empty buckets as 0.0: a flat week is a
217    # real observation for the dispersion, not a hole to skip
218    bucket_sums = np.bincount(bucket_idx, weights=trades)

224        return math.nan
225    per_year = 365.25 / bucket_days
226    return float(bucket_sums.mean() / spread * math.sqrt(per_year))
