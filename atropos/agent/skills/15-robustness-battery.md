# SKILL 5: ROBUSTNESS BATTERY — батарея 7 тестов (Stage 5 of 7)

> Самостоятельный протокол: агенту нужен только этот файл + данные.
> Таксономия: FRAMEWORK.md (корень репо) §4 (ROBUSTNESS/FRAGILE-DEATH); шаблон:
> TEMPLATES.md (корень репо) шаблон 3; пороги: PREREG_OFI §7 + candidate_shelf_battery.

## PURPOSE (цель)

Живёт ли эффект при независимых возмущениях (independent perturbations):
порог, окно, субпериод, состав панели, плацебо, кластеризация, лестница
знака. Эффект, живущий в одной точке параметров или одном периоде, —
артефакт. Гейтов нет: вердикт из измеренных чисел, не из нарратива.
Запускается ПОСЛЕ инкрементали (14-incremental-test), не вместо.

## INPUTS (входы)

1. Кандидат, прошедший 14-incremental-test (инкрементальный t ≥ 2), с исходной
   спецификацией (базовый порог/окно).
2. Якорь [0]: репродукция исходного сплита бит-в-бит ДО тестов.

## PROCEDURE — 7 тестов, пороги фиксированы (PREREG_OFI §7)

1. **THRESHOLD SENSITIVITY:** порог {0.5x, 1x, 1.5x, 2x} базового.
   Смена эффекта > 2x при сдвиге порога = DEAD (щель одного параметра).
2. **WINDOW SENSITIVITY:** окно {0.5x, 1x, 2x}. Жив только на базовом
   окне = подгонка окна (Amihud 60d: Sharpe 0.03).
3. **SUBPERIOD THIRDS:** трети выборки (или годы). Жив (знак + CI) во
   ВСЕХ трёх = ROBUST; жив в одной трети = режим-артефакт
   (Amihud: +83 / +55 / −38; BAC: 76% EV из 2021-22).
4. **LEAVE-ONE-OUT:** дроп по одному символу/активу. Дроп «носителя»
   убивает = не эффект рынка (Friday-13th: min z +1.74 — весь эффект =
   один день 2021-08-13).
5. **PLACEBO NULL:** 200 прогонов, seed зафиксирован; разрушается
   выравнивание сигнал×исход. Реал обязан сесть выше 95-го перцентиля.
6. **DE-CLUSTERING:** дроп топ-1% наблюдений + cluster-SE по датам/месяцам
   рядом с naive t (naive завышен; GLM v2: t 3.09 → 2.70).
7. **SIGN STABILITY:** монотонная лестница квантилей q1 < q2 < q3 < q4.
   Зигзаг = эффект несёт только крайний бакет = шум (Ex-kurt: строго
   убывающих блоков 2/27 — tail-артефакт).

**ВЕРДИКТ-СБОРКА:** таблица [1]-[7] с True/False из измеренных чисел;
FINAL: ROBUST | NOT ROBUST — перечисление, без объяснительных фраз.

## KILL CRITERIA (критерии убийства)

- **≥ 2 сломанных теста = ROBUSTNESS-DEATH** (по умолчанию).
- **≥ 1 сломанный тест И систематический паттерн в фейлах** (всё хорошо,
  кроме одного периода/символа) = FRAGILE-DEATH / режим-артефакт.
- Живёт ровно в одной конфигурации-источнике = FRAGILE (ETF flows:
  walk-forward decay 0.46x, «условное ДА» отозвано).

## PASS CRITERIA (критерии прохода)

**≥ 5/7 тестов прошли И нет систематического паттерна в фейлах**
(единичные фейлы объясняются измеренными числами, не нарративом).
Пороговые гейты живого пререга (PREREG_OFI §7) — знак стабилен по
терцилям, инвариантность к нормализатору — миниатюры тестов [1] и [7].

## REAL EXAMPLE (shelf battery — три вердикта одной батареи)

`runs/candidate_shelf_battery.log` (якорь [0]: все три rebuilt MATCH):
- **BAB — ROBUST:** трети +107/+23/+19 (все +), 90d Sharpe 1.30, monthly 1.46
  beats-all, LOO +35/+41/+39, placebo p0.5 [LOW=good] → survivor (PREREG_BAB_TIER2).
- **BAC — CONCENTRATED:** pctl 99, механика здорова (LOO чист, monthly
  живёт) — НО 2021-22 несёт 76% EV, 2025-26 −11%/год → не кандидат,
  только conditional с признанным decay.
- **Amihud — FRAGILE:** база +33.8%/год (pctl 98!), трети +83/+55/−38,
  60d Sharpe 0.03, monthly −9.4 → FRAGILE-DEATH: placebo-перцентиль не
  спасает от немонотонности третей.

## COMMON MISTAKES (типичные ошибки)

- Батарея ДО инкрементали: CVD прошёл 6/6 и умер на контролах — порядок
  фиксирован (инкременталь — старт, батарея — после).
- Спасать кандидат нарративом: 2 фейла + «но это объясняется тем-то» =
  NOT ROBUST; объяснение пишется в post-mortem (шаблон 4), не в вердикт.
- Нет якоря [0]: батарея на невоспроизведённой спеке измеряет воздух;
  считать подмножество тестов: de-clustering [6] и лестница [7] — самые
  частые убийцы tail-артефактов (Ex-kurt, каскады).
- Subperiod-фейл «переживёт walk-forward» — нет: трети и WF ловят одно; фейл третей = приговор.
