# SKILL 6: WALK-FORWARD + CALENDAR CONTROL (Stages 6-7 of 7, финальные)

> Самостоятельный протокол: агенту нужен только этот файл + данные.
> Таксономия: FRAMEWORK.md (корень репо) §2 этапы 6-7, §3 ЗАКОН 5; запреты: CASES_AND_FLAGS.md (корень репо) флаг 7 + CASE 5.

## PURPOSE (цель)

Переносится ли эффект на данные, которые не участвовали ни в подгонке
порогов (walk-forward), ни в выборе года (calendar control). Годовой
режим в фиче/весе/рубрике = подгонка календаря: крипто-годы гетерогенны,
и «сигнал» с годовым термом — метка режима, masked momentum (флаг 7).

## INPUTS (входы)

1. Кандидат, прошедший 15-robustness-battery, с известной точкой discovery (сырое
   значение эффекта для сравнения сжатия).
2. Панель с датами; полный список параметров/порогов/весов кандидата.

## PROCEDURE (порядок)

1. **ROLLING TRAIN -> TEST (не expanding).** Фиксированные окна: train
   (например 180d) -> заморозка порогов (p25/p50/p75) -> test (30d);
   сдвиг, повторить. Expanding-окно запрещено: подмешивает будущее.
2. **THRESHOLD FROZEN ON TRAIN (порог заморожен).** НОЛЬ параметров
   пересматривается после данных (флаг 3); правка порога после рана =
   новая версия, старый тест аннулирован.
3. **SHRINKAGE CHECK (сжатие).** OOS-эффект vs discovery: кратное сжатие
   (Ex-kurt: −0.024 → −0.00457, **~5x shrink**, t −0.57) = overfit.
4. **YEAR DUMMIES IN REGRESSION.** Спец-кривая с year fixed effects:
   t сигнала с year-dummies падает < 2 ИЛИ бета флипает знак по ячейкам =
   **календарная контаминация**. ETF flows: каждая year-dummy спека флипает
   знак беты; полносемпловый t 2.96 существует только при пулинге годов без
   FE (5/20 спек с |t|≥2 — ровно ячейки без годовых дамми).
5. **FRESH-DAYS REPLICATION.** Репликация на днях, которых не видел ни
   скор, ни автор: единственный тест, ловящий годовой prior.
6. **CALENDAR TERMS FORBIDDEN IN SCORING (запрет календарных термов).**
   В скоринге/рубрике не должно быть year/regime-членов (явные дамми,
   мульти-летний lookback, «знание автора»); GLM v2: календарные термы
   запрещены полностью. Календарный класс (праздники, часы, сессии,
   Friday-13th) похоронен — не запускать без нового механизма.

## KILL CRITERIA (критерии убийства)

- **WF t < 2** — OOS-эффект не реплицирован.
- **Кратное сжатие против discovery** (≥ ~2-5x без CI) — overfit.
- **Эффект в одном субпериоде** — режим-артефакт (дубль теста [3] батареи).
- **Calendar-dependent:** t < 2 с year-dummies или знак беты флипает с
  фиксированными эффектами годов = календарный prior, не сигнал.

## PASS CRITERIA (критерии прохода)

WF t ≥ 2 на замороженных порогах; сжатие ограничено и CI исключает 0;
эффект живёт в нескольких субпериодах; инкременталь держится с
year-dummies; репликация на свежих днях воспроизводит пилот.
→ Красная нить (FRAMEWORK.md (корень репо) §5): один прогон, один вердикт —
graveyard или датированный прereg; переживший всё = conditional survivor
с гейтами, НЕ leg системы.

## REAL EXAMPLE (GLM v1 — календарная контаминация)

**GLM v1-рубрика (tombstone 118, страйк S2):** пилот SPOT30 **+0.53
(t +5.50)**, dir hit положителен в каждом годе (64/75/73/76/77/58%).
Затем 189 СВЕЖИХ дней: **+0.053 (t +0.73)**, dir hit 52% при базе 56%,
2026-флаг hit 42%. Диагноз: пилот = селекция 80 стратифицированных дней +
член рубрики «годовой режим» (2023-25 up / 2022+26 bear), признанный
календарным prior в §2 её собственного пререга. Итог: 3 страйка —
permanent close, календарные термы в v2 запрещены. Рядом: Ex-kurt WF —
in-sample спред (t −4.54) сжался ~5x в walk-forward (t −0.57) → GRAVEYARD.

## COMMON MISTAKES (типичные ошибки)

- Expanding-окно вместо rolling — прошлое участвует в подгонке теста;
  пересмотр порога после первого WF-блока («слишком жёсткий») = майнинг.
- Проверять только WF и не проверять годовые дамми: t 2.96 full-sample
  существует только через пулинг годов (ETF flows) — WF без year-FE
  пропустит календарный сигнал.
- Пилот на стратифицированных днях считать валидацией: годовой prior ловит
  только forward-репликация на днях вне пилотной выборки.
- Держать «годовой режим» в рубрике как «контекст» — это член скоринга;
  запрет абсолютен (GLM v2 §6).
