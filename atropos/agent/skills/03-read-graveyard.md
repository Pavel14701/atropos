# SKILL 03: READ GRAVEYARD — могильник до мышления

> Core-скилл агента Atropos. Graveyard check идёт ПЕРВЫМ, до пререга:
  гипотеза, умершая на могильнике, стоит 0 запросов к данным.
  Кладбище append-only: надгробия не редактируются и не удаляются.

## PURPOSE (цель)

Не выдвигать то, что уже опровергнуто. Идентичность определяется
предсказанием (prediction) и kill-критерием, а не заголовком:
«mom30-эхо с порогом 1.5σ» и «momentum-перенос с сигмой 1.5» — одна
гипотеза.

## PROCEDURE (порядок)

1. **Найти реестр.** `hypotheses/INDEX.csv` (h_id, title, tags,
   verdict) и `hypotheses/graveyard/H-NNNN.md`. Нет реестра в проекте —
   считать кладбище пустым и создать его при первом вердикте.
2. **Искать по механике, не по названию.** Теги/prediction/kill-критерий;
   структурный дубликат = совпадают prediction и kill-критерий.
3. **Прочитать надгробие целиком.** Обязательные поля: причина смерти
   (один первичный термин таксономии), ключевые числа, kill-критерий,
   при котором умерла, и **resurrection conditions** — условия
   воскрешения (новый аргумент / новые данные / новый инструмент;
   «нет известных» = честно).
4. **Решение.** `KILLED`-дубликат без новой механики → не выдвигать,
   это майнинг. Есть новая механика ИЛИ снимок данных стал шире →
   переоткрытие: новый датированный пререг, раскрывающий закрытую
   историю (skill `01-preregister.md`).
5. **3-strikes.** Три kill-механики по одной семье = permanent close:
   преемники допускаются с prior <= 20% и одним прогоном.

## ЗАПИСЬ В МОГИЛЬНИК (когда вердикт получен)

Каждая гипотеза заканчивается надгробием и строкой в `INDEX.csv`,
включая собственные неудобные: без tombstone гипотеза считается
открытой. В надгробие: h_id, prediction, kill-критерий, вердикт,
ключевые числа из отчёта (`overall_verdict`, `killed_by_stage`,
`kill_reason`), resurrection conditions, дата.

## NEVER (запреты)

- Не полагаться на память: «я помню, что не проверяли» — не результат
  graveyard check; фиксируй, что искал и по каким тегам.
- Не редактировать и не удалять надгробия.
- Не выдвигать `KILLED`-гипотезу повторно без новой механики.
