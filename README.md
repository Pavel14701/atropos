# СИСТЕМА УБИЙСТВА ГОВНОНИПОТЕЗ
## Фреймворк проверки гипотез в крипто-кванте

> Проверь могилы → прогони pipeline → один прогон → один вердикт → graveyard или прereg.

## Файлы

| Файл | Что внутри |
|---|---|
| FRAMEWORK.md | Философия + Pipeline 7 этапов + 6 законов + таксономия смерти (18 терминов) |
| TEMPLATES.md | 5 шаблонов: прereg, скрин, батарея робастности, post-mortem, брифинг агента |
| CASES_AND_FLAGS.md | 8+ красных флагов + 5 case studies (глубокий разбор) + чек-лист агента (7 пунктов) |

## Правило

**Любая гипотеза** → открой FRAMEWORK.md → проверь graveyard → прогони pipeline (7 этапов) → один прогон → один вердикт → graveyard или прereg. Ноль параметров после данных. Ноль календарей в скоринге. Ноль «может быть пригодится».
